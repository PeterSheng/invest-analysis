## 1.5 同业批量估值快照（2026-10 海底捞实战新增）

一个请求拉全行业对比：`https://qt.gtimg.cn/q=hk06862,hk09922,hk00520,hk02190,hk02105,...`（GBK，逐票 `v_XXX="..."`）。适合"板块语境"段落——海底捞实战一轮拿到九毛九/呷哺/百胜/颐海/达势/特海全部现价+PE+52周区间。

- **批量模式下字段漂移是逐票的**：海底捞 [39]=PE 11.64（可对拍 ✓）、[44/45]=522.0 亿市值（价格×股本验证 ✓）、[47]=8.13 恰为 TTM 股息率%（0.761/9.365 精确吻合）；但同一批里特海 02799 输出全面失真（0.585 / PE 3.82）。**批量结果必须逐票跑验证公式，只采信能对拍的票**，对不上的宁弃勿用。**PE 字段的"TTM vs 静态FY"口径也逐票不定**（2026-10 泉峰 02285 实战：[39]=22.30 对拍后实为静态 PE——市值 169.4 亿 HKD ÷ FY2025 净利折 HKD 7.6 亿，而自算 TTM PE 仅 20.1x）：引用前一律用 `市值 ÷ 自算净利` 定口径，标明 TTM 或静态，勿直接采信 API 字段名。
- **TTM DPS 快捷式** = 最新中期息 + 上一财年末期息（海底捞：2026 中期 0.377 + 2025 末期 0.384 = 0.761 HKD → 股息率 8.13%）。分红全历史含**特别分配**（如 2022 每 10 股派 1 股特海股份的实物分派），`ak.stock_hk_dividend_payout_em` 一表拿全。
- 板块叙事纪律：亏损成员（呷哺/达势）PE 为负是数据不是噪音；"板块内唯一低估值+高股息+正净利"这类结论必须全部用自算数字支撑。

## 2.2 ★ 东财港股 F10 报表 API（最新中报三表全量，2026-09 龙湖实战新增）

**akshare 的港股报表接口有明显滞后**：`stock_financial_hk_report_em(indicator="报告期")` 在 2026-09-17 查询时最新只到 **2025-12-31**（2026 中报已披露近 3 周仍无数据）；`stock_financial_hk_analysis_indicator_em` 有 2026-06-30 的汇总指标（营收/净利/毛利率/ROE/BPS/负债率），但**没有科目级的资产负债表与利润表明细**。此时走东财 F10 datacenter API，可拿到最新中报的**完整中文科目明细**。

```python
import urllib.request, json, pandas as pd
H={"User-Agent":"Mozilla/5.0 Chrome/120","Referer":"https://emweb.securities.eastmoney.com/"}
def jget(u): return urllib.request.urlopen(urllib.request.Request(u,headers=H),timeout=30).read().decode("utf-8","ignore")

# 可用的 type：RPT_HKF10_FN_BALANCE（资产负债表）/ RPT_HKF10_FN_INCOME（利润表）
# ⚠️ RPT_HKF10_FN_CASHFLOW 及所有变体均返回 0 行 —— 现金流表暂无此接口，改用 akshare 年报序列或新闻
for rpt in ["RPT_HKF10_FN_BALANCE","RPT_HKF10_FN_INCOME"]:
    u=(f"https://datacenter.eastmoney.com/securities/api/data/get?type={rpt}&sty=ALL"
       f"&filter=(SECUCODE=%2200960.HK%22)&p=1&ps=500&sr=-1&st=REPORT_DATE&source=F10&client=PC")
    df=pd.DataFrame(json.loads(jget(u))["result"]["data"])
    piv=df.pivot_table(index="ITEM_NAME",columns="REPORT_DATE",values="AMOUNT",aggfunc="first")
```

实测特性（龙湖 00960.HK）：
- **返回中文科目名**（`ITEM_NAME`：投资物业/存货/长期贷款/短期贷款/股东权益/少数股东权益/合同负债…直接可用，无需对照英文字段表），附 `AMOUNT` / `YOY_RATIO`（同比%，已算好）/ `CURRENCY`（显示"人民币"）
- **一次覆盖 10 个报告期**（2017-06 至 2026-06），pivot 后即得全历史三表矩阵
- **有息负债的精确口径**：`长期贷款 + 短期贷款 + 应付票据 + 应付票据(非流动)` —— 与公司公开披露的"综合借贷总额"**完全吻合**（龙湖 2025 末模型算得 1,528.0 亿 vs 披露 1,528.1 亿；2026H1 算得 1,471.2 亿 ✓）。**不要用"总负债"或"银行贷款"等模糊科目代替**，也不要漏掉非流动应付票据。若需含租赁口径另加 `融资租赁负债(流动)/(非流动)`（龙湖此项约 116 亿）
- **利润表可直接看到污染项**：龙湖 2026H1 的 `重估盈余 30.16 亿` 独立成行，与归母 19.61 亿对比即得"利润有 154% 来自重估"——这是双口径利润分析最直接的证据
- **在手现金口径**：`现金及等价物 + 受限制存款及现金`（部分年份记在 `短期存款`，如龙湖 2023/2025H1——口径逐年变化，看年份取）

> ⚠️ 配套注意：同一公司的 `股东权益` = 归母权益，`总权益` = 归母 + 少数股东权益。做任何资产端调整（NAV 重估、减值测试）时，**必须按 `1 − 少数股东权益/总权益` 折算成归母影响**（龙湖：少数股东占 29.7% → 调整项 × 70.3%），否则会高估或低估每股价值 30% 以上。

## 2.3 上市以来含分红全收益计算（"算上分红 N 年收益多少"标准解法，2026-09 滨江服务实战）

用户高频问题「算上分红，上市 X 年收益有多少」。港股复权数据不可靠，**全部手算**：

**① 腾讯 fqkline 的坑**：
- 月K线 `param=hk03316,month,,,120,qfq` 的 qfq 参数对港股**无效**——返回 key 永远是 `month`（不复权）→ 分红再投必须手算，别信复权因子
- 日K线单次上限 **640 根**；count 给 2500 或日期范围过宽时 `data` 返回**空 list**（不报错）→ 分段拉（3 段 × 640 根覆盖 7.5 年），段间日期衔接
- **⚠️ 代码错一位=静默返回假数据（2026-10 老铺黄金实战）**：`param=hk00618`（06181 打错）不报错，返回形状完整的 K 线但价格量级全错（0.15-0.48 vs 实际 274-884）——拉完第一步对拍最新收盘价 vs 行情 API 现价，量级不符整批丢弃重拉
- 结构：`json["data"]["hk03316"]["day"]`，每根 `[date, open, close, high, low, volume, ...]`

**② 分红序列一次拿全**：`ak.stock_hk_dividend_payout_em(symbol="03316")` —— 全历史每股派息＋除净日＋类型（年度/中期/特别）。⚠️ **该接口对部分蓝筹严重滞后（长和 00001 2026-10 实战：只返回到 2019 年，缺 6 年分红）**——翻尾部确认最新一笔是否贴近当前财年，滞后的改走东财 datacenter 分红接口：`reportName=RPT_HKF10_MAIN_DIVBASIC&filter=(SECUCODE="00001.HK")&sortColumns=NOTICE_DATE`（返回 NOTICE_DATE/EX_DIVIDEND_DATE/DIVIDEND_DATE/YEAR/PLAN_EXPLAIN，PLAN_EXPLAIN 形如"每股派港币0.7455元"，需自行解析数值）。现金流时点用**除净日**（持有人实际落袋日），区分"所属财年"与"除净日"。已宣派未除净的股息单列（滨江 2026 中期息 0.922 HKD，除净 2027-01-12），报告里作第四口径。

**③ 再投模拟（除净日收盘买回）**：`shares=1.0`，每笔 (除净日, DPS) 用 bisect 找除净日当天或之后首个交易日收盘价，`shares += DPS*shares/price`；期末 `total = shares*last_close/ipo_price - 1`。输出**三口径**：纯价格 / 含分红落袋（DPS 累加不再投）/ 含分红再投。滨江实测：+197.1% / +305.2% / **+328.9%**（年化 21.4%），再投贡献约 40%。

**④ IPO 发行价获取**：东财 F10 INFO_ISSUE* 系列 type 全部返回空（不可用）。可靠路径 = HKEXnews 搜上市年份**年报** PDF（配方见 related-party reference §7）→ `pdftotext -layout` → 正则搜"發售價"上下文——年报超额配发段必写"按每股 X 港元（即全球發售項下每股發售股份的發售價）"。⚠️ pdftotext 繁中字符间会插空格，正则必须写 `r"發\s*售\s*價"`。

**⑤ 交付结构四件套**：①实际上市 N 年三口径表（IPO→现价）；②不足 10 年**诚实标注**，年化外推仅作示意；③**母公司/同集团 A 股真实 10 年对照**（A股前复权一拉即得；"子公司 7.5 年 4.3 倍 vs 母公司 10 年 1.45 倍"信息量极大）；④未来 10 年三情景分红再投模拟（每年 DPS 按当年末价买回、PE 线性过渡到期末值）＋敏感性矩阵。

**⑥ 建模陷阱**：衰退公司的 DCF 终值 g 必须压到 ≤0%——对净利 CAGR -1.8% 的公司用 g=3% 算终值会凭空造出 13% 上行空间（滨江悲观情景实测教训）。

**⑦ 中报公告可能没有现金流量表**：滨江服务 2026 中期业绩公告只有资产负债表＋损益表 → 年度 OCF 用 akshare `PER_NETCASH_OPERATE`（每股OCF×总股本）反推，中报 OCF 缺失时明示"年度口径"。

## 2.4 港股中报/年报 PDF 结构化提取路线（2026-10 滨江服务三轮实战沉淀）

pdftotext 拿到全文后（4,000+ 行）不要顺序通读，按**五遍提取法**按行号窗口定位打印，一遍一个主题：

1. **损益表 + 附注 5（除税前利润扣项）**：搜「除税前利潤」「一般及行政」→ 拿分项明细（减值/员工成本/存货成本/其他开支）——应收减值增速与拨备计提是盈余质量第一信号
2. **应收附注（贸易应收）**：搜「貿易應收」的第二处出现（正文在前几页，附注在后半）→ 账龄表 + 第三方/关联方应收拆分 + 拨备率（拨备率环比方向 = 「技术性放松」检验，巴菲特拨备还原法直接用此表）
3. **关联方附注 20**：(a) 清单略读（上市规则%/独立股东批准要求）、(b) 交易金额表逐行加总（直接付款口径）、(c) 余额表逐行看半年变动（关联应收膨胀 = 治理渗漏点）
4. **现金流量表 + 现金附注（附注 13 类）**：搜「經營活動」「定期存款」→ 定期存款/受限现金/理财逐项加总=类现金合计；有息负债单独确认（借款+票据）
5. **MD&A「財務回顧」**：搜「財務回顧」→ 分部收入/毛利率同比表（中文字段最全）+ 管理层归因原话（「上游费用标准下调」等，可引作定价权证据）

姿势：每遍用行号切片打印 ±60 行窗口；繁中字符间空格是常态（搜「物業管理費」失败就试「物業管理服務費」或去空格正则）；数字列可能被中英夹行，**对拍子报告正文数字校验后再入库**。配套：PDF 下载配方见 related-party reference §7；中报缺现金流量表时年度 OCF 用 §2.3⑦ akshare 反推。

## 6. 高派息现金牛专节（2026-10 海底捞实战，跨市场适用）

**⚠️ 高派息低净资产陷阱——PB 与 PE/ROE 一律禁作估值锚**：TTM 派息率 ~96% 的公司净资产不积累（海底捞归母权益长期停在 ~100 亿 RMB），ROE 40%+ 是**结构产物**而非经营杠杆恶化。此时 PB 4.9x 与 PE/ROE 0.30 看似"低估"实为分母失真的假信号。估值主线必须切到：PE(TTM)、EV/EBITDA、FCF Yield、股息率、DCF 三情景；报告中 PE/ROE 须加注"高派息低净资产型"。同型标的（双汇、康师傅、烟草等）一律适用。

海底捞 6862.HK 的可复用配方：
- **TTM 净利构造**：`TTM = 2025A − 2025H1 + 2026H1`（40.50 − 17.59 + 17.67 = 40.58 亿，F10 中报三表直出）。自算 `市值RMB ÷ TTM净利 = 11.8x` 与腾讯 [39]=11.64 对拍 ✓ 才采信。
- **RMB 报告 × HKD 交易双币建模**：模型全程 RMB（股价×汇率 0.9175、市值×汇率），输出再折回 HKD。akshare CURRENCY 列显示 "HKD" 但实为 RMB 报告——CURRENCY 陷阱第三次命中（归创通桥/百胜中国/海底捞），**每次必跑 PE 对拍**。
- **净现金双口径**：不含租赁 = 现金+受限 − 短贷（35.1 亿）；扣融资租赁负债（流动+非流动 33.5 亿）后 ≈ 净中性。两口径都要进报告，EV 用不含租赁口径并脚注。
- **短贷异动 = 派息前置信号**：短贷 0.98→3.99→25.62 亿 + 现金 -6.7 亿 ≈ 中期息 21 亿 HKD——"借钱分红"红旗直接从 BS 结构读出，比新闻快。
- **DuPont 之"温和的坏下降"**：ROE 47.4→40.1% 的分解 = 净利率 -1.5pct（坏）× 周转率升（关店瘦身，好）× 杠杆微升（中性）——高 ROE 下滑方向比幅度重要。
- **运营指标（翻台率/人均/客流/门店）F10 与 akshare 均无**：web_search 机构研报转述（国元月度跟踪/花旗/美银），必须标注"约数/研报口径"，媒体互斥读数（春节+5% vs M5-M6 转负）并列呈现不裁决。
- **模型杂项**：①DDM 每股价值 = `DPS0×(1+g)/(Ke−g)`，**勿再除以股本**（本会话踩过，0.70/9.5%=7.37 元/股才是对的）；②scipy 缺失时现价隐含增速用二分法 80 轮即可收敛（brentq 的手工替代）；③正常化 FCF 基数取"OCF−CapEx 与 年化净利×修正系数"两法交叉，标注"估"。

## 综合企业双轨口径陷阱（2026-10 长和实战新增）

综合企业/多重组公司的中报普遍有**三套利润**：①呈报盈利（含处置收益/重估/减值全部噪音）；②基本/核心盈利（管理层剔除一次性项与已终止业务后的"经常性"口径，中报主席报告直接给出）；③剔除 IFRS16 影响的第三轨（长和同时列 IFRS16 前/后）。规则：**估值建模一律用②基本口径年化**，①只用于解释同比暴涨暴跌（长和 2026H1 归母 +3046% 全是 UKPN/UKRails 处置收益 177.5 亿撑的），③仅当租赁影响巨大时参考。TTM PE 快捷式 `2025A − 2025H1 + 2026H1` 对综合企业会同时混入两期一次性项，必须先对各期做基本口径还原再算。配套地缘/重组事件多、新闻碎片化的公司，**公司公告 PDF 原文 > 一切媒体报道**（长和"巴拿马被强制接管+国际仲裁索赔$15亿"只有公告原文完整，中文搜索全被"长实 01113"污染）。

## 6. 官方业绩新闻稿的镜像域收集法 + 旧报告序列审计（2026-10 创科实业 0669 实战）

**美通社官方稿全文镜像在 SEO 农场域名上，可直接抓**：TTI 的 H1'26/FY25 官方新闻稿（含财务摘要表、净现金、分部数据）在 prnasia.com 本站有（story/542881-1.shtml），但雪球全文版有 WAF、搜索索引页常 404。破解姿势：用**精确标题短语**搜（如 `"创科实业" "二零二五年" 业绩`、`创科实业 2025年 销售额 153亿美元`——把冲突数字直接放进 query，官方稿摘录会出现在 description 里），然后抓镜像域名：`hotelmomcbeijing.cn/newsdetail-*.html`、`fourpoints-*.sheratons.cn`、`ramadaplaza*.wyndhamhotel.cn` 等酒店农场站——内容与美通社原文**逐字一致**（含表格），plain urllib + Accept-Encoding: identity 可直抓，无需浏览器。财华 finet.com.cn、网易 dy/article 也是高质量镜像。

**同业行情快照同场拉齐**：`qt.gtimg.cn/q=usSWK,usSNA,jp6586,hk02285` 可一次拉美股/日股/港股同行（SWK PE[39]、SNA PE 18.8、Makita 收盘价、泉峰 PE[44]），同业对比表一个代码块搞定。

**旧报告历史序列必须做官方源审计（创科实业教训）**：202606 旧报告 FY17-25"亿 HKD"绝对值序列实为美元数错挂 HKD 单位（FY25 营收写 1,072.6 亿 HKD，官方 US$15.3B ≈ 1,201 亿 HKD，低估 11%）。**重析/首轮前，把旧报告的营收/净利绝对值逐年对拍官方业绩新闻稿**——旧报告的增速百分比与官方一致（可用），绝对值不可用。数据包内必须写"旧报告禁用条款"（哪些列禁、哪些可作定性对照），否则子代理会把错误数字带进四份报告。
