# M&A 收购/提价事件驱动的存量报告更新评估

> 2026-08 PayPal-Stripe 提价实战沉淀。适用于：用户引用历史报告（"找到202607的XX文档"）+ 新事件（收购报价、提价谈判、财报）→ 评估"真实价值"。与全新四大师分析的区别：不重做子报告，产出单份更新评估。

## 1. 工作流总览

1. 定位存量报告（`reports/{YYYYMM}/{公司名}/`），读综合报告 + 事件专项 + 巴菲特/芒格子报告——DCF 假设、评分依据、概率预测全在子报告里
2. 构建事件时间线（见 §2）
3. 当日重拉价格（腾讯 `us{ticker}` 行情，字段解析见 `us-stock-data-sources.md`）
4. 财报实际 vs 旧报告假设对照（见 §3）
5. 重跑估值：旧方法 + 独立方法交叉（见 §4）
6. 收购概率反推（见 §5）
7. 概率加权期望值判断（见 §6）
8. 评分维护纪律（见 §8）
9. 写入 `reports/{YYYYMM}/{公司名}-{事件}更新评估/` + 推 GitHub

## 2. 事件时间线构建

- **多源交叉**：Reuters（首发报价）、WSJ（谈判进展/提价）、TechCrunch（汇总）、分析师评论（如 Cantor 预测 $70）
- **关键节点类型**：首次接洽 → 正式报价 → 董事会拒绝 → 财报（抬高/降低门槛）→ 谈判/提价传闻 → 反垄断 → 竞标方变动
- **财团历史必查**：PayPal 案例中 Block 4 月与 Stripe/Advent 联合接触后退出——竞标方进出直接改变提价预期与最终价上限
- 每条新闻标注日期 + 股价影响（跳涨幅度是市场对事件概率的即时定价）

## 3. 财报 vs 旧报告假设对照表（模板）

| 指标 | 旧报告假设 | 实际 | 偏差 | 解读 |

- **必须分离的增长结构指标**：总 TPV 增速 vs Branded Checkout 增速。PayPal Q2'26：TPV +9%（回升）但 Branded 仅 +4%、nonGAAP margin -248bps → "增长回来了≠结构变好"，增长靠低利润未品牌业务
- 经营 margin 同比变化（而非仅看水平值）
- 活跃账户环比（4.39亿，-20万 = 轻度流失）
- 指引方向：上调 = 盈利下限抬升 = 拒绝低价报价的底气

## 4. 估值重跑规则

- **方法论必须与旧报告一致**（PayPal 旧报告用 EPS 路径法：EPS 2029E × 退出PE），否则新旧口径不可比
- **再加一个独立方法**（标准 10 年两阶段 FCF DCF）交叉验证
- **两法分歧 = 市场恐惧的量化**：PayPal 案例 FCF DCF 基准 $123 vs EPS 路径 $88——市场以 8.1x P/FCF（12.3% 收益率）定价 = 隐含假设 FCF 每年缩水 3-5%。若 Take Rate 见底于 1.7-1.8% FCF DCF 才对；滑向 1.5% 则 EPS 路径悲观情景才对
- **情景可独立修正、方向可相反**：悲观 DCF 下修（$63→$50，Q2 margin 恶化证实 Take Rate 见底后移）、基准微调（$85→$88，TPV 回升利好）
- **分析师共识目标价 < 现价 = 市场定价收购溢价**的交叉验证信号（PayPal：共识 $55.7 vs 现价 $61.66）
- 标准 DCF 参数教训：永续价值直接折现到 7 年而非完整 10 年会让 IV 虚高（第一版基准跑出 $142 后修正）——必须完整 10 年预测期或固定退出倍数

## 5. 收购概率反推（核心公式）

```
p = (现价 − 无收购价) / (成交价 − 无收购价)
```

- **无收购价假设**（多组）：分析师共识 / 共识打折 / DCF 悲观情景
- **成交价假设**（多组）：分析师预测（Cantor $70）/ 旧报告提价预测（$68-72）/ 竞标升级价（$75+）
- 输出概率矩阵，与旧报告概率估计对比 → 判断市场是否消化了新信息
- PayPal 案例：$61.66 隐含 42-58% 成功概率 vs 旧报告 ~50% → 无新信息偏差，市场定价精确，不是错价

## 6. 概率加权期望值判断

```
EV = Σ p_i × V_i   （成交价 / 竞标升级价 / 破裂回落价 / 僵持独立价）
```

- **EV ≈ 现价 → "公平定价的事件套利"**：不是价值投资机会也不是套利机会，结论应明确写出
- **风险收益不对称检查**：上行 = 收购价天花板（+14~22% 封顶，成交后无戴维斯双击）；下行 = 无保护（破裂后回落到共识价甚至更低，-9~-27%）。期望值掩盖了分布的偏度，必须单独呈现

## 7. M&A 事件更新要点清单

1. **收购价是上行天花板**——成交价即股价上限，不存在"成交后继续涨"的逻辑
2. **财报 beat 抬高收购门槛**（winbuzzer: "earnings beat raises the bar"）——盈利指引上调 = 董事会拒绝低价的底气，报价方被迫提价
3. **分析师共识目标价低于现价 ≠ 分析师看空**——是市场已定价收购溢价（该信号用于校准"无收购价"假设）
4. **财团成员变动**：Block 退出财团 → 竞标升级概率下降但提价谈判仍可能
5. **反垄断始终是最大尾部风险**：合并后份额 >50% 时审查概率必须 ≥40% 计入破裂情景

## 8. 评分维护纪律

- 评分维持/调整必须列**正面证据 vs 负面证据清单**后决定（PayPal：TPV 回升+指引上调 vs margin -248bps+账户流失 → 维持 3.00/5）
- 情景估值可独立于评分修正（悲观下修、基准微调）
- 报告头双日期必须一致（分析日期 = 价格截至日期），当日重拉价，禁止沿用旧价
- 更新评估同样必须写盘 + 推 GitHub（commit hash 报给用户）
