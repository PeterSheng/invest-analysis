# 综合医药集团分析框架（2026-09 华东医药 000963.SZ 实战）

## 触发条件

分析"医药商业 + 医药工业 + 消费医疗/医美 + 创新药"混合体公司：华东医药、上海医药、国药一致、白云山、复星医药、华润医药等。判别信号：营收体量大（300 亿+）但净利率低（<10%）、分部含低毛利商业板块、合并报表 ROE 被稀释。

## 一、分部拆解先行（第一步，不可跳过）

混合体公司的合并报表意义有限——必须先拆分部：

| 板块 | 华东医药 2025 实测 | 分析要点 |
|------|------|------|
| 医药商业 | 286.97 亿（65.8%），净利 4.79 亿（1.7%） | 通道业务：垫资搬运工，应收高企是胎记；两票制/集采/零加成政策持续压缩毛利 |
| 医药工业 | ~145 亿（~33%），净利 27-28 亿（~19%） | **利润主体**：所有估值锚定于此 |
| 医美 | 18.26 亿（4.2%），微亏/微利 | 高毛利但失速 → 第二曲线证伪风险 |
| 工业微生物 | ~10 亿（2%） | 小体量期权 |

**核心洞察公式（稀释剪刀差）**：`低毛利板块收入占比 ÷ 净利贡献占比` = 公司真实盈利质量的稀释度（华东医药：65.8% 收入只贡献 ~14% 净利 → ROE 13.8% 被商业板块压扁；"百亿应收悬顶" 是这门生意的胎记）。此公式直接支撑"四线作战的辛苦生意"式段永平结论。

## 二、利润主体识别与估值锚

- 分部数据最全来源：年报新闻稿/深度文章（正经社、投资者网等），搜索词 `"{公司}" "年报" "医药商业" "净利润" "亿元"`；中报分项用 `"{公司}" "{年份}" "半年报" "医美" "收入" "同比"`
- 混合体估值用 SOTP 或分部 PE 交叉验证整体 PE：医药商业按净利×5-10x、医药工业按属性 15-30x、医美按成长 15-25x（华东医药整体 PE 13.9x vs 历史中枢 22x——先拆解再判断"便宜"是哪个板块的便宜）
- 研发投入占工业收入比是"利润被压制"的核心解释变量（华东医药 29.82 亿研发 ≈ 工业收入 20%，持续压低净利率——写进巴菲特"一美元留存收益检验"与芒格"研发黑洞"路径）

## 三、独家大单品专利战风险链条（百令胶囊案例）

**链条**：独家大单品（30 亿）→ 竞品仿制获批打破独家 → 专利侵权诉讼 → 一审二审败诉 → 上诉最高院（改判率低）→ **集采才是真杀手**（独家进集采价格 -50%+）→ 单品 3 年内或腰斩。

分析要点：
1. 专利战败诉 ≠ 立即崩盘，但"独家"地基被司法程序抽走 = 估值中枢下移的确定性事件；市场给低 PE "已经闻到了水泥开裂的味道"
2. 时间线推演模板：终审判决（当年）→ 竞品进院放量（次年）→ 集采（2-3 年内）→ 单品腰斩
3. 芒格视角固定句式："我从不与法律程序对赌，尤其当对方已经赢了两轮"——两连败后赌翻盘赔率极差
4. 跟踪信号：最高院判决书、竞品进院/放量数据、是否纳入集采目录、和解/授权费模式可能性（"独家"变"双雄"但避免集采血拼 = 反转路径）
5. 体量映射：30 亿单品占工业收入 ~20% → 腰斩即利润支柱 -15~25%

## 四、GLP-1 类似药红海判定（司美格鲁肽案例）

- 专利到期（2026-03-20）后申报队列：至少 8 家（华润双鹤/石药/九源基因/华东等）
- **无先发优势判定法**：受理时间 vs 竞品（华东 2026-04-14 才受理 = 落后数月）；类似药无差异化 → 终局拼价格，"利润率向商业板块看齐"
- 双重挤压框架：原研降价 + 创新分子技术代差（礼来替尔泊肽/口服司美/恒瑞信达）= "减肥药剩饭"论
- 管线对比表必须覆盖全谱系：利拉鲁肽类似药（已上市首个）、司美格鲁肽类似药（受理）、口服小分子、双靶点、三靶点、宠物减肥药——"管线热闹 ≠ 壁垒深厚"
- 估值影响：GLP-1 是第二增长曲线叙事核心，红海化 → 研发/产能投入变沉没成本 → 净利率持续受压（芒格失败路径概率给最高档）

## 五、医美第二曲线证伪信号

连续 3 个报告期收入下滑 + 商誉减值计提 = 第二曲线证伪中：
- 少女针 Ellansé 案例：2021 上市高增长 → 2025 -21.5% → 2026H1 -10.4%（国内/国际双降）→ Sinclair 计提减值 7811 万
- 判断句式："高毛利一旦失速，说明护城河是潮流而非壁垒——潮流会退，壁垒不会"
- 行业维度：医美进入调整期（供给过剩+价格战+监管趋严），对标爱美客/华熙/四环同步承压，区分公司特有问题 vs 行业周期问题

## 六、混合体公司四大师适配与"低分共识"呈现

混合体公司天然触发低分共识（华东医药 2.50/3.25/2.50/2.75，极差 0.75）：
- 段永平：四线作战辛苦生意（好生意❌/好管理⚠️/好价格⚠️）——"看得懂的部分不值得买，值得买的部分看不懂"
- 巴菲特：PE 低分位但 DCF 保守情景无安全边际（现价 ≈ 保守 IV）；理想买区 = 零增长锚（FCF/WACC+净现金）附近
- 芒格：专利战+医美失速+GLP-1 红海三线承压；能力圈稀释论（"用资本买增长而非用能力长增长"）
- 李录：赛道长坡（老龄化/GLP-1 渗透率）但公司雪不厚（非第一位置）；"行业趋势确定性 ≠ 公司命运确定性"

**呈现规则**：分差 ≤ 1.5 且整体低分时，"低分共识"本身即结论——四大师从不同框架殊途同归给出"不重仓"，须呈现共享判断（确定性受损的折扣未给够）与唯一分歧（谁愿意为低估值/净现金/股息付等待溢价：巴菲特/李录 vs 段永平/芒格），结论语言："共识性平庸：可观察、可小仓位、不可重仓"。

## 七、混合体公司关键数字清单（华东医药实测，可作对标模板）

- 净现金 = 货币资金 − 有息负债（华东：56.1 − 21.5 = 34.6 亿；有息 = 短借 17.15 + 长借 2.5 + 一年内到期 0.72 + 租赁 1.17——东财接口逐字段加总）
- 应收 88-90 亿（占总资产 22.5%）——商业板块胎记，写进芒格失败路径（"应收爆雷"概率 35%）
- 商誉+无形资产 66.6 亿（28.4+38.0），海外并购子公司减值先例（Sinclair 7811 万）
- 全年股息率 = (年报 DPS + 中期 DPS) ÷ 股价（华东 0.58+0.35=0.93 元 → 3.4%，分红率 48%）
- 盈利质量：OCF/EPS 五年均值 1.2x、CapEx/Rev <3%（轻资产）——与"商业垫资+应收高企"并存，现金流质量评"良好但有阴影"
