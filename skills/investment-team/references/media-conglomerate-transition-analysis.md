# 媒体集团 linear→DTC 转换期分析框架（2026-10 迪士尼 DIS 实战）

> 适用：DIS/WBD/PARA/CMCSA/FOX 及任何「线性电视衰退 × 流媒体爬坡 × 线下体验/IP 变现」多引擎并存的媒体集团。
> 与既有框架的分工：`tech-disruption-analysis.md` 管「外部技术颠覆路径」；`serial-acquirer-analysis.md` 管「连续收购机器」（本文的商誉双口径与其同构，但来源不同）；本文管**公司自身的业务模式转换期**——利润引擎定位、口径、估值锚。

## 1. 分部拆解先行（合并报表必然误导）

- 媒体集团典型三分部处于完全不同的生命周期：**内容娱乐（线性频道+流媒体）/ 体育（ESPN）/ 体验（乐园+邮轮+消费品）**
- 第一步定位利润引擎：分部 OI 及占比（DIS：Experiences 为最大利润引擎，利润率与稳定性最高；线性电视 OI 逐年萎缩是**结构性**而非周期性，勿等「周期回升」）
- **分部 OI vs GAAP OI 的差**：TFCF/Fox 类历史收购产生的无形摊销把 GAAP 营业利润与净利率系统性压低——GAAP PE/净利率仅存档，估值用调整后 EPS 口径（与 WM/Stericycle 的 M&A 摊销双口径同理，两口径差 >10% 时双标注）
- 内容资产+商誉占资产比重高 → 有形净资产被压制甚至为负 → ROE/PB 失效（同 `negative-equity-buyback-machine-analysis.md` 的识别逻辑）

## 2. 一次性项目识别（内容集团高发）

- 高发清单：税收优惠（Hulu 并表优惠）、资产/业务出售（Star India）、重组减值、内容减记、竞购退出补偿
- **季度页识别法**：`?p=quarterly` 净利率骤变的季度必查当季新闻（DIS FY25Q3：净利率 22.25% 异常高 = Hulu 税收优惠 + Star India 出售一次性 $5,262M）
- 处理：GAAP TTM 净利仅存档；正常化/调整后 EPS 为估值主锚；TTM YoY 剧烈波动先查上年同期基数（多为 lapping 而非经营恶化），再下结论

## 3. 53 周财年口径

见 `us-stock-data-sources.md` §2.10。DIS FY2026 = 53 周：指引含/剔双口径并读（前瞻 PE 14.7x 含 / 15.3x 剔），跨年比较与 DCF g1 用剔除口径；FY27 外推反向声明高基数。

## 4. 回报率分裂诊断（与 TMO 同构、来源不同）

- **含商誉 ROIC < WACC**（DIS 7.11% < 8.75%，$74.7B 商誉未覆盖资本成本、一美元留存检验未通过）vs **有形回报极高**（DIS 有形 ROE ~38.8%，喜诗级本体回报）=「赚运营的钱、亏溢价的钱」
- 与 serial-acquirer 的关键区别：TMO 类商誉**持续滚入**（增量检验看收购纪律），媒体集团商誉多为**历史收购存量**（TFCF/Fox）——增量检验改看**当前 capex/内容投资纪律**（乐园扩建峰值后的 FCF 弹性）
- ROE/PB/PE-ROE 三件套全部禁用；质量锚 = 有形回报率 + FCF 质量（OCF/NI 五年区间）+ EV/EBITDA

## 5. linear→DTC 转换的对冲数学（核心变量）

- 转换期估值的关键不是「DTC 还亏多少」，而是**利润增量是否盖过 linear 损失**：DTC 利润率爬坡（每 +1pct ≈ 订阅收入 × 1pct 的增量）× 订阅基座 vs linear OI 年降幅度
- **「转换完成」判据**：DTC 分部利润增量 > linear 分部利润损失（集团 OI 重新加速）——在此之前 DCF g1 假设要保守
- Sports 是独立变量：ESPN 的 DTC 化与股权结构重组（联盟入股）单独建模，不与娱乐分部混算
- 体验分部（乐园）是转换期现金流压舱石——**capex 峰值（新园区）回落后的 FCF 弹性**是 DCF base FCF 的关键假设（DIS：FCF0 用正常化 ~$9.0B 而非 capex 峰年值）

## 6. 估值锚与现价情景定位

- 主锚：调整后前瞻 PE（FY N+1 EPS）+ EV/EBITDA + FCF Yield；PB 仅对照、禁作锚；GAAP PE 仅存档
- DCF：FCF0 用正常化值，三情景 + 概率加权（25/50/25）+ 现价隐含 g1 反推。**乐观侧定价样本**：DIS 现价 $102.36 隐含 g1 8.78% ≈ 乐观情景 g1 9%，DCF 加权 IV $84（-18%）——与 ADBE 的「悲观侧定价」（现价 ≈ 悲观 IV）相反，赔率结构完全不同：乐观侧定价 = 下行空间大于上行，须等估值或催化
- 零增长锚（FCF/CoE）作下限参照（DIS $55/股）

## 7. 治理与交棒（媒体集团特有风险项）

- **CEO 交棒失败史是独立风险项**（DIS：Iger 三次交棒失败后的第四次）：新 CEO 的**出处板块**是运营聚焦 vs 财务聚焦的信号（DIS：D'Amaro 出自利润引擎 Experiences = 正面信号）
- 交棒期内资本配置承诺（回购/股息节奏/去杠杆目标）是最可验证的治理指标，写入跟踪清单首位
- 芒格视角必含「交棒再失败」路径的概率加权（DIS 案例：35% 路径为最大单项）
