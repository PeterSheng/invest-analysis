# AIDC 数据中心电源设备公司分析框架（2026-09 潍柴动力 000338.SZ 实战）

> AI 数据中心电力缺口 → 备电/主用电源产业链，A 股标的持续增加（潍柴动力、科泰电源、济柴动力、应流股份/豪迈科技燃气轮机零部件、麦格米特/欧陆通电源等）。本框架给出需求结构、竞争格局、估值适配与一个通用诊断装置：**第二曲线点火期的"分部业绩率裂缝"**。

## 1. 需求结构（为什么是真需求）

- **备电是物理刚需**：每 MW IT 负载需 ~2,000–3,000kW 柴发备电（N+1 冗余，Tier IV 要求），断电即灾难 → 需求与 AI capex 同步但弹性更大（数据建成后柴发即锁定）。
- **技术路线变化风险（芒格必查）**：① 燃气轮机/燃气内燃机转"主用电源"（柴发退居备电）；② SOFC（Bloom Energy/博世/斗山/Ceres 合作方）直供主电；③ BBU+超级电容缓冲削峰减少柴发依赖。跟踪 SOFC 样机节点与超大规模厂商电源架构声明。
- 需求周期性：AIDC 柴发当前供不应求（交付排期数月），但本质是强周期设备——供给扩产后必然回落，不可把"订单排满"年化成永续。

## 2. 竞争格局

- 全球柴发四大家：康明斯、卡特彼勒、MTU（罗罗）、沃尔沃遍达；国产：潍柴（大缸径高速机技术同源）、科泰电源、济柴。
- AIDC 供不应求期 = 国产替代窗口：海外大厂交付周期长 → 国内厂商凭交付速度切入。判断"替代是窗口期行为还是能力跃迁"看认证周期（大客户认证一旦通过不易更换）。
- 燃气轮机零部件（应流/豪迈）受益逻辑不同：绑定 GE/西门子/索拉尔供应链，看铸件认证进度。

## 4. ★ 核心分析装置：第二曲线点火期的"分部业绩率裂缝"诊断

新业务放量期公司**不单独披露其毛利**，唯一窗口是母分部（潍柴=发动机分部）的剪刀差：

> 潍柴 2026H1：发动机分部收入 373.10 亿（**+14.9%**）但分部业绩 54.37 亿（**−2.1%**），业绩率 17.11%→14.57%（−2.54pct），且公司未解释。

**诊断三问**（每问一个归因，各自对应的暂时性/结构性判断）：
1. 新业务爬坡期毛利低于主业？（AIDC 柴发从 0 起量，早期毛利天然低 → **暂时性**，看后续季度毛利率修复）
2. 为扩产能进行的折旧/费用前置？（新产线投产爬坡 → **暂时性**，看产能利用率）
3. 老主业价格战/产品结构下移？（重卡行业竞争、大缸径占比变化 → **结构性**，看同业毛利率对照）

**证伪规矩（写进报告的硬条款）**：连续两个报告期分部业绩率续降 = 结构性确认 → 综合评分强制下修一档（潍柴案例：3.69 → 3.25 以下），不再听"爬坡期"解释。

**通用化**：适用于任何"多元化公司第二曲线放量期"——新曲线的收入并进母分部，掩盖了母分部自身的定价权变化。利润表整体增速失真时，分部业绩率是唯一诚实指标。

## 5. 估值适配（AIDC 第二曲线的定价纪律）

- **先做周期归一化**：重卡是强周期（8 年销量历史呈 90→170→60 万辆锯齿），DCF 基准 FCF 必须用 3 年归一化均值（潍柴 2023-2025 OCF 均值 274 亿 → 归一化 FCF 起点），不能用当年值。
- **免费期权判定**：现价反推隐含可持续 FCF 贴悲观情景（潍柴：反推 ~101 亿 vs 3 年实际均值 203 亿）时，市场对 AIDC 定价≈0 → 新曲线是免费期权，**不给它单独的高倍数，只作为安全边际的加分项**。
- DCF 三情景用 FCF 起点区分（悲观 100/中性 140/乐观 170 亿），AIDC 兑现度决定落在哪个情景，而不是给 AIDC 单独建 SOTP 期权块（期权重叠在主业内部，拆不干净）。

## 6. 跟踪清单（季度）

1. 大缸径/柴发季度销量与在手订单排期
2. **发动机分部业绩率**（裂缝装置——最重要的单一指标）
3. 行业月度重卡销量（中汽协/第一商用车网：潍柴 2026-08 实测 9.16 万辆 +47%、1-8 月 71.57 万辆 +14.5%）
4. SOFC/燃气轮机主用电源的客户架构声明（技术路线证伪信号）
5. 汇率（海外收入 51% 企业的汇兑损益，恒立模式：剔汇兑还原经营增速）
