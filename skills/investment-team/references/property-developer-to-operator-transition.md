# 开发商 → 运营商转型期公司分析框架

> **适用场景**：正在从"住宅开发"被迫或主动转型为"商业地产运营/服务"的混合体公司。典型标的：龙湖集团（00960.HK 实战，2026-09）、华润置地、万科、新城控股，以及任何"开发航道萎缩 + 持有型资产增值"双轨并存的公司。
>
> **与已有框架的关系**：`property-management-commercial-ops-analysis.md` 处理**纯轻资产运营商**（华润万象生活）；`reit-analysis-guide.md` 处理**纯持有型 REIT/收租股**；`cyclical-business-modeling.md` 处理**纯开发商**。本文件处理**三者混合、且处于转型中间的资产**——这是最难估值的一类，因为估值语言必须整体切换。

---

## 一、核心矛盾：一个资产负债表里装着两个生意

转型期公司最典型的报表形态：**新生意（运营/服务）已经能赚钱，老生意（开发）正在失血，两者共用一个资产负债表和一套债务。**

龙湖 2025 年实证：
- 运营及服务业务核心利润 **79.2 亿**（毛利率 >50%、净利率约 30%）
- 集团整体核心溢利 **-17.0 亿**（上市以来首次核心亏损）
- **反推开发航道单独亏损约 -96 亿**

**第一条铁律：分析这类公司，第一步永远是分部拆解 + 反推亏损分部。** 合并报表的任何一个数字都是两个生意的加权平均，单独看会完全误导。

```
开发航道隐含核心利润 = 集团核心溢利 − 运营及服务核心利润
龙湖 2025：-17.0 − 79.2 = -96.2 亿
```

## 二、估值语言切换：PE 何时失效，用什么替代

### 2.1 PE 失效的判据（三条满足其一即失效）

| 判据 | 龙湖实证 |
|---|---|
| **TTM 归母净利为负**（不论是否含一次性项） | TTM = 2025 全年 10.2 − 2025H1 32.16 + 2026H1 19.61 = **-2.35 亿** |
| **TTM 核心溢利为负**（剔除重估/处置后） | TTM ≈ -17.0 − 10.5 + 0.64 = **-26.9 亿** |
| **ROE 极端低位**（<3%）导致 PE/ROE 失真 | 2026H1 年化 ROE **1.67%** |

> ⚠️ **PE/ROE 排名表必须整体禁用**（分子为负）。报告中要显式声明"本标的 PE 无定义"，而不是填一个荒谬数字。

### 2.2 替代估值工具箱：三法并行（必须同时给，且要呈现三法分歧）

| 方法 | 做法 | 龙湖结果 |
|---|---|---|
| **① NAV**（自下而上调整归母权益） | 从归母权益出发，对投资物业按 cap rate 重估、存货按可变现净值折价、应收/合联营按回收率折价；**每项调整按归母分摊比例（1 − 少数股东占比）计入** | 保守 8.86 / 中性 15.55 / 乐观 21.69 HKD（归母分摊 70.3%） |
| **② SOTP**（分部估值 − 负债） | 运营业务按 NOI ÷ cap rate；服务业务按核心利润 × PE；开发业务按净存货（存货 − 合同负债）× 实现率；其余资产折价加总；减全部负债；**结果再乘归母比例** | 8.65 / 11.66 / 14.85 HKD |
| **③ 经常性业务稳态 DCF** | 稳态利润 ÷ (WACC − g) − 净债；**不计开发残余价值**（这是"下限价值"的刻画） | 多数格低于现价，部分格为**负值** |

**三法分歧本身就是结论：**
- 若 NAV/SOTP 远高于现价、但经常性稳态 DCF 趋近于零或为负 → **股权价值几乎全部来自"开发存货变现"，而不是来自公司正在转型成为的"运营商"身份**。
- 龙湖实证：EV 2,260 亿中，若经常性业务按 cap 5.5% 值 1,364 亿，则**开发业务 + 其余全部资产市场仅给 196 亿，隐含实现率约 8%**。
- **报告语言**：不要写"低估 60%"，要写"现价隐含开发资产实现率 8%"——后者让读者理解定价逻辑，前者只是情绪。

### 2.3 最直观的量级锚：市值 ÷ 年租金

```
龙湖：市值 338.2 亿 RMB ÷ 商业租金 112.1 亿 = 3.0x
对照：投资物业账面 2,271.9 亿 = 20 年租金
```
**"市场给整个公司的估值只相当于 3 年租金收入"这句话，比任何 PB 数字都更有冲击力。** 但必须紧接着追问：扣掉有息负债后的股权价值还剩多少。（龙湖：净债 1,222 亿 vs 经常性利润 79–110 亿 → 常被人忽略的死结。）

## 三、双口径利润表：重估污染是默认状态，不是例外

持有型资产占比高的公司，**投资物业公允价值重估**会系统性污染归母净利。特征：

| 特征 | 龙湖实证 |
|---|---|
| 归母净利 > 核心溢利，且差额逐年稳定存在 | 2024 差额 +34.3 亿；2025 **+27.2 亿**；2026H1 **+18.97 亿** |
| 差值是"非现金、主观、方向不可控"的 | 2026H1 重估收益 **30.16 亿**（税前）撑起归母 **19.61 亿**（覆盖度 **154%**） |
| 重估率看似温和但杠杆巨大 | 30.16 / 2,271.9 = **1.33%** 的重估率 → 但 cap rate 挪 100bp 就会从"+30 亿"变"−315 亿" |
| 表观 ROE / PE 全部失真 | 2025 表观净利 +10.2 亿 vs 核心 −17.0 亿，**符号相反** |

**处理规则：**
1. **一切估值模型（DuPont/DCF/PE）用核心口径**，表观口径仅作披露对照。
2. 报告中**必须双口径并列成表**，并单独说明差值来源。
3. 芒格视角必问：**"如果明天规定不许重估，这家公司还剩多少利润？"**——龙湖答案是接近零（2026H1 核心 0.64 亿）。
4. ⚠️ 相反方向也要查：**若重估转负**，表观利润会瞬间击穿（龙湖：cap rate +100bp → 减值约 315 亿，超过全部归母净利历史总和）。

## 四、现金流："收缩释放"陷阱的开发商版本

> 通用版见 `cyclical-business-modeling.md`；开发商版本有独有的会计路径。

**开发商 OCF 中的"存货减少"是最大的幻觉来源：**

| 口径 | 龙湖 2025 |
|---|---|
| 报表 OCF | **+218.8 亿** |
| 其中存货减少贡献 | **+483.0 亿** |
| 剔除存货减少后 | **约 -264 亿（估）** |
| 集团口径"含资本性支出的经营性现金流" | **仅 +58 亿** |

**判定三步：**
1. **看存货减少的绝对额与趋势**：龙湖存货 4,054.9 亿（2021）→ 1,575.6 亿（2026H1），五年减少 2,479.3 亿、年均约 496 亿。
2. **算管道剩余年限**：剩余存货 ÷ 年均变现速度 = **约 3 年（估）**。**这是这类公司最关键的单一数字——它把"资产安全边际"变成了"有到期日的期权"。**
3. **对比集团自定义口径**：管理层往往披露一个更保守的"含资本性支出的经营性现金流"（龙湖 +58 亿）。**用这个数字做 FCF 起点，而不是报表 OCF。**

**结论语言**："可持续 FCF 落在 0–58 亿（估），对应权益的 FCF 收益率 0%–3.5%；管道约剩 3 年。"

## 五、少数股东权益与合联营穿透（开发商专属复杂性）

开发商普遍通过合作项目开发，导致：

| 项目 | 龙湖 2026H1 | 分析含义 |
|---|---|---|
| 少数股东权益占比 | 699.1 / 2,350.7 = **29.7%** | **每 100 元净资产，只有约 70 元归上市公司股东** —— 所有资产端调整必须按 70.3% 折算 |
| 应收关联方款项 / 归母权益 | 661.2 / 1,651.6 = **40.0%** | 合作方往来款，回收率高度不确定 |
| 合联营权益 / 归母权益 | 288.5 / 1,651.6 = **17.5%** | 不合并项目的投资，透明度低 |
| **"信任型资产"合计占比** | 应收关联方 + 合联营 + 递延税项资产 + 商誉无形 = **1,132.1 亿 / 68.6%** | **净资产的三分之二是"别人欠我的 + 未来才能抵的"** |

> **芒格式拷问**：当净资产的主要成分是"别人欠我的钱"时，PB 不再像便宜，而像"市场对这个数字打了 8 折后再打 4 折"。

**操作要点**：NAV 计算中，应收关联方与合联营权益必须单独设折价率（保守 70–80%），不能按面值计入。

## 六、价值释放的制度通道：消费基础设施 REITs

**这是本类公司最重要、也最容易被忽略的催化剂。** 中国消费基础设施公募 REITs 于 **2023 年 11 月首批获批**并常态化发行，商业地产首次获得"募投管退"闭环。

**为什么重要：**
- 持有型资产（账面 2,271.9 亿）在清算视角下被市场按"厕所价"定价，因为**没有退出通道**；
- 一旦 REITs 通道打通，资产可以被"资本化"为现金流证券，价值释放不再依赖 20 年收租；
- **这也解释了为什么市场给同一批资产两种价格**：轻资产运营商（华润万象生活）20x PE，重资产持有者（龙湖）0.205x PB —— 差别在于**是否有退出通道 + 是否有杠杆**。

**跟踪要点**：目标公司是否已申报/发行消费 REITs、发行规模与定价、扩募节奏。**REIT 申报公告是这类标的最强的重估催化剂。**

## 七、四大师视角适配

| 大师 | 本类标的的切入角度 |
|---|---|
| **段永平** | "三问"逐条：好生意？（分部拆解——新生意赚不赚钱、老生意还剩什么）；好管理？（还债纪律、Stop Doing List：停止拿地/停止供应链融资/停止加杠杆）；好价格？（PB + 市值/租金 + "便宜的来源是看不清还是被错杀"） |
| **巴菲特** | DuPont ROE 归因（区分"坏下降=净利率压缩" vs "好下降=主动去杠杆"，用序贯分解 + 对数分解双验证）；现金流"收缩释放"诊断；三类安全边际（资产/盈利/护城河）分开评估；**核心结论语言 = "格雷厄姆式资产博弈，而非巴菲特式复利买入"** |
| **芒格** | 利润的"评估师依赖度"（重估覆盖度）；净资产中"信任型资产"占比；6 条失败路径必含"存货继续减值""销售崩塌致现金流入枯竭""重估转负""再融资"；概率加权期望值 vs 现价（**若两者接近，结论是"精确的公允定价，无认知优势"**） |
| **李录** | 两条相反方向的文明曲线（售🔻 文明级退潮 vs 租🔺 文明级上升）；20 年置信度多维度表；TAM/SAM/份额（**份额小 = 成长约束是资本不是容量**）；20 年回报测算（三情景年化回报）；**"资产价值是真的，变现时间是未知的"** |

## 八、跟踪指标体系

| 频率 | 指标 | 门槛/信号 |
|---|---|---|
| 月度 | 合同销售同比 | 降幅收窄至 −20% 内 = 现金流入拐点 |
| 半年度 | **核心溢利（剔除重估）** | **连续两期转正 = 最重要的单一验证信号** |
| 半年度 | 商业租金 / 出租率 / 同店增速 | 出租率 ≥96%、同店 ≥5% |
| 半年度 | 应收关联方回收 | 连续两期净回收 = 净资产真实性验证 |
| 半年度 | 在手现金 / 净负债率 | 现金止跌回升 |
| 年度 | 运营+服务收入占比 | 是否超过开发收入（转型完成判据） |
| 事件 | **消费基础设施 REITs 申报/发行** | 最强的重估催化剂 |

## 九、常见错误

| ❌ 错误 | ✅ 正确 |
|---|---|
| 用 PE 或 PE/ROE 排名给转型期公司估值 | 判据三条满足其一即声明"PE 无定义"，改用 NAV/SOTP/经常性稳态 DCF 三件套 |
| 用归母净利判断盈利能力 | 必须双口径（表观 vs 核心），并说明重估覆盖度 |
| 资产负债表调整项不按归母比例折算 | 必须先算少数股东占比（龙湖 29.7%），调整项 × 归母分摊比例（70.3%） |
| 把报表 OCF 当可持续现金流 | 剔除"存货减少"贡献；用集团自定义的保守口径（含资本性支出的经营性现金流）做 FCF 起点 |
| 报"低估 60%" | 报"现价隐含开发资产实现率 8%"——让读者看见定价逻辑 |
| PB 0.2x 即判"极端低估" | 先做资产减值压力测试（投资物业 cap rate 上移、存货减值、应收关联方折价），看减值后的真实 PB（龙湖：0.205x → 0.40x） |
| 忽略 REITs 通道 | 消费基础设施公募 REITs（2023-11 开闸）是本类公司价值释放的核心制度变量，必须单独跟踪 |
| 把"未违约"读成"安全" | 惠誉上调展望至稳定 ≠ 股东安全；"不违约"与"不亏钱"是两件事（龙湖：评级上调的同一年股价 −56%） |
