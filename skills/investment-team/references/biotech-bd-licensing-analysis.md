# 创新药 BD 授权（license-out）收入分析框架

> 2026-08 三生国健（688336.SH）实战沉淀。适用：任何有对外授权收入（首付款/里程碑/销售分成）的创新药企——恒瑞、百济、康方、三生系、信达、科伦博泰等。

## 触发场景

分析对象出现以下任一信号时激活本框架：
- 新闻/公告含"BD 授权 / license-out / 首付款 / 里程碑 / 对外许可 / 出海"
- 营收同比暴增数倍（>100%）且毛利率同步跳升（如 75%→92%）
- 报表 PE 突然变得"便宜"（<15x）但公司产品并无相应放量

## 一、交易结构核查（建模前必须做）

| 核查项 | 三生国健 707 案例 | 为什么重要 |
|--------|------------------|-----------|
| 签约主体 | 三生国健联合三生制药、沈阳三生三方签约 | 收入可能只在部分主体确认 |
| 权益分配比例 | 三生国健 30% / 沈阳三生 70% | 决定上市平台确认多少收入 |
| 确认口径 | 12.5 亿美元首付 × 30% ≈ 28 亿 RMB 一次性确认 | 首付款是一次性，里程碑才分期 |
| 后续里程碑 | 总交易 60.5 亿美元，剩余 ~48 亿不确定 | 芒格失败路径的核心 |
| 中国内地权益 | 辉瑞追加 1.5 亿美元，仍按 30/70 分配 | 关联方利益划分线索 |

**验证公式**：确认收入 ≈ 首付款外币金额 × 权益份额 × 汇率。三生国健 28.9 亿 ≈ 12.5 亿美元 × 30% × ~7.7，完全吻合 → 说明确认的是份额收入而非全额。

## 二、盈利正常化（核心步骤）

1. **拆分一次性 vs 内生**：授权收入（首付款份额）从营收中剔出，剩余才是医药制造/产品销售真实规模。三生国健 2025：营收 41.99 亿 - 授权收入 31.13 亿 = 内生 ~10.9 亿（同比还下滑，因集采+控费）。
2. **连续污染检查**：不止看当年。三生国健 2024 年净利 7.05 亿也含投资收益 3.96 亿等非经常 4.59 亿——**连续两年被非经常污染**时，历史 ROE 全部失真，必须逐年拆分。
3. **正常化锚点**：券商一致预期（同花顺 F10 盈利预测页有 2026E 净利 6.7 亿、EPS 0.75 元）优先；次选 2026H1 扣非年化。
4. **ROE 口径**：报表 ROE 34.5%（一次性推高）vs 正常化 ROE ~7.7%——综合报告排名表必须双标注，禁止让报表 ROE 进 PE/ROE 排名。

## 三、估值：SOTP 管线期权框架（DCF 失效时的替代）

DCF 用正常化 FCF 跑会全线 -50%~-80%（三生国健：11.1/14.2/22.7 元 vs 现价 47.65）——**这不是模型错，而是 DCF 无法定价未兑现的管线期权**。改用 SOTP 分部：

| 分部 | 估值方法 | 三生国健中性值 |
|------|---------|:---:|
| 现有产品（已上市药） | 正常化净利 × 25-30x | 105 亿 |
| 各在研管线（608/611/613...） | rNPV：峰值销售 × 成功率折现 | 45+55+12+20 亿 |
| BD 授权期权（707 里程碑+分成） | 概率加权，临床失败归零 | 45 亿 |
| 净现金（货币资金+理财-负债） | 账面直接加 | 50 亿 |

输出三情景（悲观/中性/乐观）→ 判断现价落在哪个位置。三生国健：现价 47.65 在 SOTP 中性 37.0 与乐观 53.0 之间 = 市场已 price in 大部分管线成功。

**现价 ↔ 情景对照是核心估值语言**：现价 ≈ 悲观 → 赔率不对称；现价 ≈ 乐观 → 无安全边际，赌的是全胜。

## 四、风险清单（芒格视角必查）

- **临床失败路径**：BD 产品的全球临床失败 → 里程碑归零 + 分成泡汤（概率给 35-40%）
- **权益分配不均**：大股东占 70% 分成 → 小股东"二等公民"治理折价（无法用 DCF 消除）
- **关联交易**：低价把管线授权给关联方（三生国健 612/708 授权沈阳三生，首付仅 1.02 亿）——掏空嫌疑信号
- **现金流背离**：一次性收入次年 OCF 可能为负（三生国健 2026H1 OCF -0.66 亿 vs 净利 3.71 亿，背离 4.4 亿——税费时点+应收/存货吞噬，需在报告中标注）
- **散户化信号**：股东户数半年翻倍（1.2 万→2.06 万，+72%）+ 股价大涨后 → 筹码结构脆弱，10jqka F10 holder 页有序列数据

## 五、转增股本口径陷阱（BD 暴利后常见）

BD 一次性收入 → 公司大手笔分红+转增（三生国健 2025：10 派 4.5 元 + 10 转 4.5 股，总股本 6.18→8.96 亿股）：
- 判别：`EPS × 当前总股本 ≠ 净利` 即存在转增/送股/回购
- 历史 EPS/BVPS 全部换算到当前股本口径：`复权 EPS = 净利 ÷ 当前总股本`
- 腾讯行情 PE 用当前股本算，同花顺历史每股数据用当时股本——混用必错

## 六、数据源

- 券商一致预期 + 历史财务序列：同花顺 F10 `basic.10jqka.com.cn/{code}/worth.html`（GBK 乱码但内嵌 JSON 可解析，见 a-share-data-collection.md）
- 股东户数序列：同花顺 F10 holder 页内嵌 JSON
- 交易细节：公司公告 + 新闻（"首付款 X 亿美元 / 总金额 Y 亿美元"句式）
- 现金流/资产负债表：akshare 东财 report 接口（注意数值列是字符串，需 to_num 转换）
