# 数字银行/直营银行分析框架（2026-09 Nu Holdings/NU 实战）

> 适用：Nu Holdings (NU)、Nubank 类新兴市场数字银行，以及任何"技术公司做银行业务"的成长期银行（拉美/东南亚数字银行、上市后的 Chime/Revolut/Monzo 类）。
> 与 `financial-institutions-modeling.md` 的分工：该文件管传统银行/券商/资管（ROTE/P-TBV/权益乘数），本文件补数字银行特有三件套——**银行口径三禁、"好上升"判别、无 FCF 可用的估值五件套**。

## 1. 银行口径三禁（子报告必须统一遵守，否则数据包口径打架）

1. **"净现金"叙事禁用**——客户存款 $45B 是负债不是现金；P/Deposits 可以列（Nu 130%），但"净现金占市值 X%"句式对银行无意义。
2. **OCF/FCF 禁用**——银行 OCF 被贷款投放扭曲（放贷多 OCF 好看），TTM OCF $3.8B 对 Nu 无估值意义；DCF/FCF Yield 全套工具不可用。
3. **ROE/ROA/EM 三件套为主锚**：ROE 用平均权益口径（Nu 31.63% TTM），ROA 期初/期末双口径并列（趋势一致才采信），EM（权益乘数）6-7x 视为"银行中的低杠杆"（传统银行 8-12x）——**低杠杆下的高 ROE = 质量证据**。

## 2. ROE"好上升"判别（DuPont 银行版）

| 形态 | 特征 | 判定 |
|---|---|---|
| **好上升** | ROE 上升 + EM 下降（ROA 驱动） | Nu：ROE 18.2%→31.6% 全由 ROA 2.81%→4.96% 驱动，EM 6.77→6.25 |
| 坏上升 | ROE 上升 + EM 上升（杠杆堆出） | 信贷扩张期银行常态，周期反转时双杀 |
| ROA 高息差幻象 | ROA 4-5% 在 Selic 15% 肥息差实现 | 巴菲特扣分点：**利润率本身含周期成分**，降息时须问"ROE 随息差收缩到多少" |

ROTE（剔商誉无形后 ROE）作质量锚；TBVPS 五年 CAGR（Nu ~22%，留存率 ~100% 无分红）作复利证据——**银行复利看 TBVPS 增速，不看 EPS 增速**（股本变动干扰小）。

## 3. 无 FCF 可用的估值五件套

| 工具 | 用途 | Nu 输出（$，2026-09-28 现价 $12.23） |
|---|---|---|
| **ROE→P/B 静态矩阵**（公允 P/B = ROE/Ke） | **无增长下限锚**——现价溢价全部是"增长的定价"；若现价 > 矩阵全线，即"增长是估值的全部" | Ke10/12% × ROE 12-35% → $2.74-9.59，全线 < 现价 |
| **RI 剩余收益模型**（BVPS 起点 + ROE fade 15 年 + 终值 ROE 收敛） | 保守交叉验证锚，含"信贷周期+ROE 滑坡"悲观臂 | 悲观 $4.56 / 基线 $9.98-14.80 / 乐观 $16.26-24.62 |
| **EPS 路径法**（EPS fade 10 年 + 退出 PE） | 中性锚 + 显式 IRR（9.4-11.9% 基线） | 悲观 $10-12 / 基线 $30-38 / 乐观 $49-59（2036） |
| **5 年情景概率加权**（25/50/25） | 主输出 | $10.9/$21.0/$37.0 → 加权 **$22.47（+84%）** |
| **现价反推**（要求 IRR 10-12% + 退出 PE） | 判断市场定价了多大减速 | 隐含 NI CAGR 11.6-13.6% vs 实际 ~40% = 减速已计入大头 |

**现价落点判读范式**：现价 ≈ EPS 路径悲观情景 但 >> RI 悲观情景 = 市场按"浅悲观（饱和/减速）"定价、未按"深悲观（信贷周期反转）"定价——**两个悲观情景之间的差就是尾部风险敞口**（Nu：$10-12 vs $4.56）。

## 4. 运营 KPI 与资产质量红线

- **ARPAC vs 成熟客群 ARPU**：当前月收入/活跃客户（Nu $15）vs 成熟客群（$25.90）= 货币化挖掘空间（+60-70%）；⚠️ ARPAC 口径历史上变过（$11.20 旧口径），多源冲突时用官方最新并标注。
- **效率比**（成本/收入）：数字银行 <25% vs 传统银行 40-50% = 成本结构代差核心证据。
- **NPL 季节性 vs 周期性之辨**：Q1 +89bp 是典型季节性；**周期反转触发器 = 90+ NPL 连续两季 >35bp 上行 + 15-90 突破 5.5%**。⚠️ 降息期违约通常滞后改善，但宽松期放贷标准放松埋雷——"本轮周期的雷种在降息最欢时播下"（芒格必写）。
- **降息双刃剑**：Selic 15%→12.5% = 存款成本↓+信贷需求回暖+估值修复 **vs** ROE 随息差收缩均值回归——终极一问的标准模板。

## 5. 收购方传闻事件树（Nu/Monzo 实战，与 ma-takeover-update-analysis.md 互补）

> ma-takeover-update-analysis.md 管的是"**被收购方**"（溢价套利）；本节管"**收购方**"——自家公司被曝出价买人、单日暴跌 10% 场景。

**五步法**：
1. **交易数学四倍数 vs 自身**：P/S、P/adjPBT、P/Deposits、每客户价，全部除以收购方自身倍数。Nu/Monzo：付 6.2-7.7x 毛收入（自身 2.3-2.9 倍）、61-76x adjPBT（自身 16.4x）、每客户 $689-862（自身 $451）——"**贵在收入、便宜在存款**"（Monzo P/Deposits 41-51% vs NU 自身 130%）的双面解读 = 多空各拿一半证据。
2. **融资方式数学**：全现金 = 耗尽流动资金池（含监管受限现金）；发股 = 稀释 ~18-22%；混合 = 两头各挨一半。
3. **被购方备选项**：IPO/私募融资 = 并非待价而沽，面临价格竞争，成交概率打折。
4. **事件树概率加权**：不成交/低价成交/高价成交三臂各给概率与隐含股价，**加权期望 ≈ 现价 = 市场已公允定价交易风险 = 掷硬币，无事件套利空间**（Nu：40/35/25 → $14.0/$11.5/$10.5 → $12.25 ≈ $12.23）。
5. **真正的风险在成交后**：高 ROE 资产买 10% 利润率资产的稀释数学（Monzo adjPBT 利润率 10% vs NU 40%+）→ 巴菲特资本配置分、芒格"整合恶化信号"（成交后效率比回升、被购方管理层流失）。

## 6. 四大师视角适配

- **段永平**：成本结构代差（效率比 19.9% vs 40-50%）+ 创始人在台 + 回购启动 = 模式/管理层高分；银行周期+监管+支付基础设施天花板（Pix）抹不掉 → 价格维度单独压分。
- **巴菲特**：回报率 4.75（ROE 质量）与下行保护 2.5（P/TBV 4.89x 无账面地板 + RI 悲观 -63%）同票并存是数字银行常态——**"业务质量顶级 × 价格纪律未达标"**。
- **芒格**：失败路径须含 ①信贷周期反转（Selic 降息后放贷标准放松）②核心市场饱和+ARPU 挖掘失败 ③本地对手正面进攻（Mercado Pago"高频打低频"）④第二市场烧钱陷阱（美国 CAC 战场）⑤大额收购毁值 ⑥监管与汇率。注意**路径互相咬合**（尾部深于独立路径公司）。
- **李录**：文明级赛道 = 现金社会→数字银行（中国/巴西双证据链）；货币化已验证段 vs 尚未验证段（墨/美）分开打分。
