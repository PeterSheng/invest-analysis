# SaaS/订阅软件公司 AI 叙事冲击分析框架

> 2026-09 Intuit (INTU) 四大师实战沉淀。适用：Adobe（2026-08）、Intuit（2026-09）、Salesforce/Datadog/ServiceNow 等"AI 叙事压估值"的订阅软件公司。与 `tech-disruption-analysis.md`（技术颠覆专项三层防御）互补：本文聚焦**财务口径甄别与估值锚选择**，彼文聚焦颠覆路径推演。

## 1. EPS 指引口径变更甄别（本类公司最高频陷阱）

公司把 EPS 指引从"剔 SBC"改为"含 SBC"时，表观指引 vs 共识 miss 可达 15%+，实为口径变更而非经营恶化。

- **Intuit 实例**：FY27 指引 EPS $22.88–23.12（含 SBC 新口径）vs 共识 $27.32（旧口径）→ 表观 miss ~16%；新口径含 ~$7.7/股 SBC。
- **叠加重组出清陷阱**：裁员重组费用计入当期 GAAP 后，次年 GAAP EPS 增速表观虚高（Intuit 表观 +40% vs 经营性 +12–15%）——**引用 EPS 增速必须双口径标注**。
- **检测信号**：①指引 EPS 与共识差距远大于营收指引差距；②电话会/新闻稿出现 "guidance convention" / "includes stock-based compensation" 字样；③EPS 指引 ÷ 营收指引隐含利润率异常跳变。

## 2. "AI 应用方 vs AI 旁观者"定位检验

| 层 | 检验项 | Intuit 实测 |
|---|---|---|
| 威胁面 | genAI agent 降低 DIY 门槛 | 报税/记账/营销均可被 agent 化；Mailchimp 已被侵蚀（"Mailchimp化"=SMB 软件链先例） |
| 威胁面 | 涨价引擎熄火 | 客户 +3% vs ARPC +15%；CEO 原话"price is now the number one reason customers leave" |
| 应对面 | ①是否 AI 应用方 | Intuit Intelligence agentic 平台（虚拟AI团队）+ $100M OpenAI 合作 + Anthropic |
| 应对面 | ②数据所有权 | 7年税务历史+账簿交易数据 = 训练财务 agent 的独家燃料，**AI 时代反而增值（与多数 SaaS 相反）** |
| 应对面 | ③责任承接 | 报税法定责任+审计保险——**AI 可替代劳动，不可替代责任** |

**芒格"报纸类比"检验**：分发层被替代（TurboTax 表单向导 UX = 分类广告，**半成立**）vs 数据+责任层被替代（账簿系统 of record，**不成立**）→ 结论形态："半只脚踩进坟墓，半只脚踩在堡垒" = "增长结束但世界没终结"的结构性原因。

## 3. "裁员 + 涨价到顶同季出现" = 增长见顶公关替身

- 两个独立信号指向同一方向，很少撒谎：17% 裁员（3,000人）与 CEO 承认涨价是流失第一原因**同季**出现。
- 先例：Klarna/Salesforce 裁员潮都发生在"AI 效率"叙事与增长见顶交汇处——**"AI 转型"经常是"增长见顶"的公关替身**。
- 判别法：裁员与定价权流失信号是否同期；"与AI无关"式否认是否与涨价到顶同时发生。
- 估值含义：主要打压**管理层维分**（Intuit 芒格维度 2.25、段永平维度 3.75），而非商业模式维分。

## 4. 估值锚（SaaS 专属三件套 + 零增长锚）

- **PB 禁用**：并购型 SaaS 商誉+无形常占权益 90%+（Intuit：$18.6B vs 权益 $19.0B = 98%），PB/ROE 口径失真。
- ROE 20–30% 若**全由净利率驱动**（DuPont 验证周转/杠杆贡献小）则真实可用，但仍不作估值锚。
- **主锚**：FCF Yield / **股东盈余 Yield**（(FCF−SBC)/市值）/ Forward PE（对齐口径）/ EPS 路径法（起点用指引 EPS×对应口径）。
- **零增长锚 = 股东盈余 ÷ WACC**：现价贴锚 = 市场定价"永续零增长且无任何增长期权"。Intuit：$6,607M ÷ 9% = $73.4B → $275/股 ≈ 现价 $269.40。
- **EV×WACC 反推**：隐含永续 FCF 与实际 FCF 差值 = 市场定价萎缩幅度（Intuit：$6,589M vs $8,663M = **-24%**）。
- **现价打穿悲观情景 DCF** = 市场把悲观情景当 100% 定价还在打折 → 不对称赔率成立（向上正常化即翻倍，向下需 AI 颠覆 5 年内摧毁 40%+ FCF）。
- **SBC 校验线**：SBC > 净利 40% 时，DCF base 必须用股东盈余口径做下限校验（Intuit SBC $2.06B vs 净利 $4.57B ≈ 45%）。股息逆势 +15%/年提息 vs 市场定价 FCF 萎缩——"要么市场错，要么管理层撒谎提息，两者不能同时成立"（芒格式矛盾检验）。

## 5. Intuit 实测数据包要点（口径可直接复用）

- FY26（截至7/31）：营收 $21.45B +13.9% / 毛利率 81.0% / 营业利润率 28.8%（5年 +8.1pt）/ EPS $16.46 / FCF $8.66B（40.4%）/ OCF/NI 1.94x；5年 CAGR：营收 13.9%/FCF每股 24.2%
- DuPont：21.3% × 0.58 × 1.91 = ROE 23.6%（全净利率驱动）；ROIC 22.9%（FY23 12.0% → 三年翻倍）
- 净债务 $1.2B（0.14x EBITDA）；股本年 -4.2%（回购注销）
- 分部：QBO Accounting $5.05B +22.6% / Online Services $4.87B +16.4% / TurboTax ~$5.3B（FY27 指引仅 +2–3%）/ Credit Karma +11–13%
- DCF 三情景（base FCF $8.0B 正常化，WACC 9%）：悲观 g1-3% **$314** / 中性 g1+8% **$643** / 乐观 g1+12% **$887** / 概率加权(35/40/25) **$589**
- EPS 路径法（FY27E $23.00 起点）：5%增速+15x退出 = 年化 7.6%；7%+18x = 11.7%
- 事件时间线：2026-05-20 裁员 3,000 人(17%)+Anthropic/OpenAI 合作同日宣布（-3.95%）→ 2026-08-25 FY27 指引（-11.2%）→ 2026-09-17 Investor Day"AI中心增长重置"下调长期目标（-4.9%）→ 9/21–28 AI 替代质疑续跌（-13%/周）；TTM 股价 -47.6%，市值 $219B→$72B
- 集体诉讼：10(b)/20(a) 证券欺诈，class period 2025-08-22 ~ 2026-05-20，被告含 CEO Goodarzi/CFO，未定案
- 系列评分：段 4.00 / 巴 4.25 / 芒 3.00 / 李 3.75 = **综合 3.75**（介于 Copart 3.88 与华润万象 3.69 之间）
