# 征信局 / 数据租金公司分析框架（2026-09 TransUnion/TRU 实战）

> 适用：TransUnion (TRU)、Equifax (EFX)、Experian (EXPN/EXPGY) 等个人征信局；可类推至任何"行业强制使用 + 数据租金 + 政治监管"型公司。
> 与 `financial-infrastructure-companies.md`（评级/指数/终端公司）的区别：征信局按次/按订阅计费而非纯订阅、CapEx 强度 6%+ 营收非 <2%、三寡头 + 上游评分层结构、**政治监管是第一估值变量**。

## 1. 行业结构：三层博弈

| 层 | 玩家 | 经济学 |
|---|---|---|
| 数据层 | 三大征信局（EFX/EXPN/TRU） | 40 年数据积累 + 银行报送生态 + FCRA 合规牌照 = 事实垄断；按次/按订阅出售 |
| 评分层 | FICO（算法）+ VantageScore（三大局各持 1/3） | FICO 在按揭评分近乎垄断；VantageScore 是三大局的"备胎"兼政治筹码 |
| 监管层 | CFPB / FHFA / 国会 / 州 | 定价与"数据使用许可"的规则改写者——**第一变量** |

关键产业事实（2026 语境）：
- 美国按揭报告惯例 = **tri-merge（三局全拉）**；监管若推行 **bi-merge（只拉两家）**，第三名（TRU）最可能被剔除——同业中处境最差。
- VantageScore 全面放行对三大局数据销售**中性偏正**（评分钱从 FICO 流向 VantageScore，三大局按股分成）；真正受伤的是 FICO（2026-09-04 单日 -21%）。
- "免费查分"政治化直接打击消费者互动分部（信用监测订阅，TRU 该分部连年下滑 = 商业模式短板明牌）。

## 2. 分部结构与数据获取

- 分部（TRU 口径）：US Markets = **US Financial Services**（按揭/车贷/信用卡按次查询 = 周期引擎）+ **US Emerging Verticals**（保险/电信/租房等非金融场景渗透）；**International**（加/英/印/拉美/非洲）；**Consumer Interactive**。
- **stockanalysis.com 利润表页自带地理分部行**（Revenue 之下分列，US Financial Services / Emerging Verticals / Canada / LATAM / UK / India / APAC…），一次拿全，TTM 列 vs FY 列对比即分部最新趋势——无需另找分部表。
- 分部突变 → 查并购新闻，三表互证：**年度商誉跳增 ≈ 年内收购完成**（TRU 2026 TTM：商誉 +$552M ↔ 现金收购 -$604M ↔ 净举债 +$444M）；分部收入跳增（拉美 TTM +59%）= 控股 JV 并表时点。

## 3. 必须做的会计调整（建模前）

1. **有形净资产为负**（商誉+无形资产 > 权益；TRU -$4.3B，商誉+无形资产 $9.3B = 权益 1.9 倍）→ **PB / P/TBV 全部失效**；ROE 被商誉摊薄（15.6%）、ROIC(GAAP) ~7% 均失真。估值锚 = Fwd adj PE / EV-EBITDA / FCF Yield；质量锚 = FCF 利润率轨迹 + 调整 EBITDA 利润率（管理层中期框架常含"利润率年扩 100bp 向 40%"类目标）。
2. **调整 EPS 的"摊销加回水分"**：GAAP 与调整 EPS 常年差 $1.5/股/年（收购无形资产摊销 + 股权激励 + 一次性项）——管理层"+10-12% 调整 EPS 增速"部分是收购+摊销正常化的产物。**报告必须 GAAP/调整双口径呈现**；DCF 必须用 FCF（现金是真相），禁止用调整 EPS 外推。
3. **CapEx 强度 6%+ 营收**（数据/云基础设施）——不是 SPGI/MCO 式 <2% 轻资产；"维持竞争地位的成本"显著更高，巴菲特式批判点。
4. **信贷周期联动**：美国金融服务业收入随按揭/车贷发放量波动（利率敏感）；用季度页（`?p=quarterly`）检测周期位置（TRU FY22 营收 +3.3%、FCF≈0 是前车之鉴）。OCF/NI >1.4x 是常态（GAAP 净利被摊销压低所致），勿当异常。
5. **历史大额一次性项污染年度净利**：TRU FY21 净利率 47%（$1,390M）= 出售医疗业务 $1.74B 利得；FY23 亏损 = 减值重组 $414M——年度表必须标注，勿当经营常态。

## 4. 新闻稿 Schedule 反推一次性利得（2026 TRU 实战技巧）

公司新闻稿（如 newsroom.transunion.com，urllib 可直接抓取全文）附带"Adjusted Net Income 对账表"（Schedule 3/4）。**用相邻期调整项相减可定位被剔除的一次性项**：
- Q2'26 调整项 $120.3M、H1'26 合计仅 $3.6M → Q1'26 调整项 ≈ **-$116.7M**（负数 = GAAP 计入、调整剔除的一次性利得，通常为分步收购重估收益）。
- 配合季度页 GAAP 净利尖峰（Q1'26 $397M vs 常态 ~$100M）交叉确认 → 建模/对比一律用调整口径，GAAP 尖峰标注"一次性"。
- 分步收购（控股 JV 并表）一石三鸟解释：分部收入跳增（并表）+ 商誉增加 + 净举债增加。

## 5. 监管/政治风险 = 第一变量

- 尾部事件名单（写芒格报告必备）：① bi-merge 落地（按揭少拉一家局，第三名先出局）；② FCRA 改革立法（prescreen 营销名单需消费者同意、背景调查限制）；③ 医疗债务禁报扩散（州级先例）；④ "免费查分"强制化。
- **估值纪律**：现价 ≈ 中性 DCF 且隐含增速已到管理层框架上沿 = 市场未给监管留折扣 → 无安全边际；政治股应要求额外折价（芒格式概率加权：监管情景 20-35% 概率 + 重锤情景 -40~-50% 时，EV 低于现价 15-25% 不出手）。
- **跟踪纪律**：政客/监管者表态（X 帖、声明）比财报更重要——列入每日监控清单（"Pulte 的推文现在比 TRU 的财报更重要"）；基准情形 = "租金再分配而非行业消灭"（征信局已穿越 40+ 年监管与科技周期），但租金系统性压缩概率须量化写入。
- **股价单日 >5% 先查监管新闻再查财报**（2026-09-04：FICO -21%/TRU -5.9%/EFX 齐跌，由 FHFA 局长 Pulte 的 VantageScore 放行 + bi-merge 言论触发——本事件即本框架的诞生场景）。

## 6. 估值语言

- 三情景 DCF：杠杆 FCF 贴现至股权，贴现率取 CoE **9.5-11%**（Beta ~1.5 的周期联动股，勿用 SPGI 式 8%）；典型结论 = "现价≈中性公平值（WACC 9.5% 档）、安全边际≈0、市场把管理层框架上沿 price in"；击球区常落在中性 IV 下方 10-15%。
- 同业表必含 EFX（直接同业）+ FICO（评分上游）：TRU 常是三大局中前瞻估值最低一档（Fwd adj PE 16.7x vs EFX 19.3x）——但"便宜"可能反映第三名在 bi-merge 下的最差处境，**勿自动判错杀**。
- 隐含增速反推（现价隐含前 5 年 FCF 增速 vs 管理层有机指引）用于判断市场是否已给监管留折扣。
- 报告范式：三寡头"第三名 + 同质化 + 监管可一键改写规则" → 段永平 3.25/巴菲特 3.00/芒格 2.25/李录 3.75（TRU 实战，综合 3.06）；分歧核心 = 监管租金重定价（3-5 年政治周期）vs 文明级确定性（20 年）——分差 1.5 贴阈值时把分歧本身写成独立小节。

## 7. FICO 重析轮（2026-09-29，4.25→2.50）：评分层垄断被行政令拆除的完整案例

FICO 是本框架的"评分层"，其 FHFA 事件重析轮给出四条可迁移结论（适用任何"监管性行政垄断"型公司）：

1. **行政垄断的拆除速度以周计**：法律护城河（GSE 强制使用 20+ 年）2.5 个月内被 FHFA 局长两道行政令拆掉（9/4 Pulte 令全面放行 VantageScore → FICO -21%；9/28 统一定价网格"完全相同定价待遇"→ -21.75% 至 $658，两日累计 -49% 距 52 周高 -67%）。**"监管性行政垄断"的护城河强度 = 行政令的改写成本，不是法律文本的存续年限**——芒格视角必须把"规则改写者的一纸公告"列为第一失败路径而非尾部事件。
2. **提价激进化 + 借债回购 = 双向锁死**：FICO 在政治风险积累期把 royalty $4.95→$10（+100%）、债务 $1.3B→$5.6B（4.39x EBITDA）、权益转负（-$0.7B）、~$640M/年回购全部砸在股价高位。结果：跌 67% 后"便宜的回购反而买不动"（净债/FCF 5.4x）。**涨价越激进 → 政治催化越猛；跌得越深 → 回购弹药越少**——资本配置与监管风险的交互项是芒格必查项，而非两个独立扣分。
3. **重析轮审计表增加"威胁来源错押"判定行**：首轮押"AI 越强→可解释性监管越严→FICO 受益"，实际威胁来自华盛顿政治而非 AI——错押的不是方向而是**变量**。审计表除"论断兑现与否（✅/🔴）"外，必须加一列审计"首轮押的是哪个变量"，防止下次在正确赛道上押错风险源。
4. **价格减分项兑现 ≠ 基本面修复**：$658 / 16.3x fwd（vs 首轮 32x）说明"独占权溢价"已跌掉，但反向 DCF 显示现价隐含终值增速 ~5% + 按揭收入零衰减——四大师概率矩阵认为这个定价仍太乐观（量价双杀矩阵 vs FICO 自身 $4.95+资金费选项与迁移惯性的对冲未决）。共识语言："**被没收的收费站：可观察、可等待、不可重仓**"。
