# 全量 DCF 估值排名方法论

## 何时触发

当用户要求"整理所有公司的排名"、"按DCF估值排序"、"更新README排名"时触发。

## 数据提取策略

### 从综合报告中提取的字段

| 字段 | 正则模式 | 优先级 |
|------|---------|:------:|
| PE | `PE[^:：\n]{0,10}[:：]\s*~?\*?\*?\s*(\d+\.?\d+)` | P0 |
| ROE | `ROE[^:：\n]{0,10}[:：]\s*~?\*?\*?\s*(\d+\.?\d+)` | P0 |
| 股价 | `(?:股价|当前股价)[：:]` | P1 |
| 买入区间 | `(?:合理|共识)?买入[区价间][：:]\s*(\d+\.?\d*)\s*[-~至]\s*(\d+\.?\d*)` | P1 |
| 低估/高估% | `(?:被)?(?:低估|高估)[约]?\s*(\d+\.?\d*)\s*%` | P1 |
| DCF安全边际 | `安全边际[：:]\s*([+-]\d+\.?\d*)` | P2 |
| 综合评分 | `(?:综合评分|共识度)[：:]\s*[★☆]*\s*[\(（]?(\d+\.?\d*)` | P2 |

### PE/ROE 代理指标

当报告没有显式 DCF/买入区间时，使用 **PE ÷ ROE** 作为估值效率代理：

- PE/ROE < 0.5 → 每一单位ROE付出的估值极低 → 可能严重低估
- PE/ROE 0.5-1.0 → 合理偏低估
- PE/ROE 1.0-2.0 → 合理偏贵
- PE/ROE > 2.0 → 估值较贵

> ⚠️ 这是一个粗糙代理，不能替代真正的DCF，但适合快速排序。

## 排名文件结构

`reports/全量DCF估值排名.md` 包含三个部分：

### 一、DCF/内在价值排名
只有明确估值判断的公司（有买入区间 or 低估/高估百分比 or DCF安全边际）。
按 `overval_pct` 排序，负值（低估）在前。

### 二、全量PE/ROE排名
所有有PE和ROE数据的公司，按 PE/ROE 排序。

### 三、关键发现
从排名中归纳的结构性洞察（如"港股比A股便宜"、"好生意≠好价格"）。

## README 同步更新

`README.md` 中新增三张表：

1. **四大师综合评分排名** — 段永平/巴菲特/芒格/李录各自评分 + PE + ROE
2. **巴菲特估值视角排名** — 按巴菲特评分排序 + 低估/高估判断
3. **低估程度排名** — 按DCF溢价排序 + 核心逻辑

表格式：
```markdown
| # | 评分 | 公司 | 代码 | PE | ROE | 估值判断 |
```

## 去重规则

同一公司在不同月份可能有重复报告，保留信息最丰富的一份（优先选择有评分/估值的）。
