# 光模块/AI 光互连公司分析框架（2026-10 新易盛 300502 + 中际旭创 300308 双雄实战）

> 适用：新易盛、中际旭创、天孚通信、联特科技、剑桥科技、华工正源、源杰科技等"AI 算力光互连"链公司，及任何"云厂 capex 驱动 + 技术代际 2-3 年洗牌"的 B2B 元器件公司。与 `aidc-power-equipment-analysis.md`（AIDC 电源设备）互为姊妹篇——同一条 AI capex 曲线上的两类"卖铲人"。
> **双数据点提示**：§1-§6 以新易盛为基准样本、§5 表含双雄对照列、§6bis 为旭创样本与**双雄对比表**——分析任何一家光模块公司时，先把双雄（+天孚）放进同一张对比表再下结论。

## 1. 行业本质：周期放大器，不是品牌消费品（四大师第一判断）

- **形态像好生意**：毛利率 31-48%（历史区间内摆动）、CapEx <6% 营收（轻资产）、净现金、扣非干净
- **内核是周期放大器**：净利随云厂 capex 剧烈摆动（新易盛 2023 年 -23.7% → 2025 年 +236%）；毛利率同一区间 31%→48% 双向摆动
- **护城河是"窗口"非"壁垒"**：1.6T 先发 ≠ 竞争优势——旭创 1.6T 份额 50-70% 反超新易盛（800G 份额 >40% vs 25-30%）；代际每 2-3 年一次重新洗牌（李录判语："永远在高考的学生"）
- 定性模板：「形态像好生意、内核是周期放大器」

## 3. 财务判读五要点

1. **净现比"单季看规律、累计看真相"**：备货先行（存货领先营收 1-2 季度）+ 云厂账期 → 单季净现比 0.2 属常态；但**累计净现比（3-5 年）<0.6 是硬红旗**（新易盛 22-26H1 累计 0.56x：净利 215 亿只收回 120 亿现金）
2. **存货+应收占比是扩张期体温计**：新易盛 192 亿 = 总资产 52%（存货半年 +61%、应收 +70%）——上行期是拿单证据，capex 见顶后立刻变减值弹药；DCF 的 FCF0 必须剔除这批"预付的增长"占用
3. **ROE 三因子周期共振判别**：净利率×周转×乘数同向跳升 = 周期顶部特征（新易盛 22%→38% × 0.5→1.3 × 1.2→1.45 → ROE 72.6%）；PE/ROE <1 在此处是**顶部温度计**而非低估信号，均值回归路径（ROE 回落 30% → 净利腰斩 → 股价 -70% 级）必须写进报告
4. **汇兑诊断照走 SKILL.md 恒立三步法**（海外收入占比 ~88% 的公司必查 FINANCE_EXPENSE 符号反转；新易盛 2026H1 汇兑损失 6.4 亿 vs 2025 全年汇兑收益）
5. **研发费率横向对比是模式判别器**：新易盛 2.1% vs 旭创显著更高——"快反工厂"（成本效率租）vs "自研纵深"（技术租金），直接映射李录框架的商业模式适应性分

## 4. 估值语言

- **主锚不是 PE**：DCF 三情景，FCF0 用正常化 FCF（OCF − CapEx，剔除存货/应收膨胀占用）；终值 PV 占比 50-67% 属轻资产长周期模型常态，须标注"伪精确"
- **FCF Yield 过滤器**：< 无风险利率 = 等待无补偿、持有收益 100% 依赖股价（新易盛 1.94% vs 国债 2.1-2.3%）
- **现价反推隐含 g1 是最强语言**（新易盛：隐含前 5 年 FCF 增速 19-32% = 市场定价"高增长再续 5 年"）
- **周期记忆检验**：隐含增长 vs 公司近 5 年最差年份（新易盛 2023 年 -23.7%）的对话必须呈现
- **击球区共识法**：各大师出手区收敛 + FCF Yield 4-5% 对应价格带（新易盛共识 210-260 元，较现价 -30%~-43%）

## 6. 新易盛实测数据包（2026-10-09，同业对比复用）

- 五年财务（亿元）：营收 32→31→86→248（2025）；净利 9→6.9→28→95→2026H1 75.3（+358%）；详见 `reports/202610/新易盛/00-数据包.md`
- DCF 三情景：保守 136 / 中性 386 / 乐观 1,105 元，概率加权(30/45/25) **491 元** vs 现价 370.20；芒格版权重(45/40/15) ≈381 元
- 四大师评分：段 3.25 / 巴 2.50 / 芒 2.25 / 李 3.25 → 综合 **2.81**（系列锚点下沿，与恒立液压同档）
- **李录锚定执行记录**：FCF Yield < 无风险利率触发估值保护封顶，锚从赛道叙事的 4.0 档压到 3.25 派发——光模块公司定李录分时**先跑过滤器再定锚**

## 6bis. 中际旭创实测数据包（2026-10-10，双雄对比基准）

- 2026H1：营收 417.78 亿(+110.6%) / 归母 136.51 亿(+157.3%) / 毛利率 46.25%；2025：营收 459.36 亿(+92%) / 归母 107.97 亿 / ROE 41.6%。净现比：2024 0.61 / 2025 1.01 / 2026H1 **0.18** / 累计 **0.56**（与新易盛累计 0.56 完全同值——备货先行是行业共性，非公司个性）；存货 317.91 亿(+151%)+应收 170.68 亿=总资产 47%。汇兑：H1 损失 5.62 亿
- 估值（价格截至 2026-10-09，A 股 775.29 / H 股 974.5 港元，距高点 -43.9%）：DCF 三情景 **166/371/768**、概率加权 **409 元**（-47%）；**现价高于乐观 IV 1%**（不在任何情境内，比新易盛"贴近中性侧"更极端）；隐含前 5 年 FCF 增速 **40.1%/年**；PE(TTM) 50.3x / PB 15.7x / FCF Yield **0.89%**（双雄最低=价格最贵）
- 四大师评分：段 3.00 / 巴 2.25 / 芒 2.25 / 李 3.25 → 综合 **2.69**（系列新锚点下沿，低于新易盛 2.81）
- **A+H 混合口径**：旭创 H 股已发行，市值 = A 股价格×A 股本 + H 股价格×H 股本（混合口径 ≈9168 亿 RMB）；DCF 净现金起点须**计入 H 股募资净额**（旭创 +500 亿含此）；对尚在递表的新易盛则不适用
- **CPO 威胁论平衡表**（旭创报告核心论证，写任何"卖铲人"都适用）：威胁面——Rubin CPO 配比 1:4→1:1、英伟达 40 亿美元战投 Lumentum/Coherent；缓冲面——硅光占高速产品 ~70% 自研（CPO 本质是硅光集成度延伸）、三支柱技术卡位（2.4T/3.2T/NPO）、35% H 股募资投前沿。**结论语言：CPO 是"路线概率 20-50% 的选项"而非"已定局"，但第一大客户（英伟达）即路线主导者 → 客户集中 × 技术路线共振是本行业独有的复合尾部**

## 6ter. 双雄对比表（同一条 AI 光互连曲线的两种定价，2026-10-09/10 快照）

| 维度 | 中际旭创（全球第一） | 新易盛（全球第三） |
|------|---------------------|-------------------|
| 综合/极差 | **2.69**（极差 1.00） | 2.81（极差 1.00） |
| PE(TTM)/FCF Yield | 50.3x / 0.89% 🔴 | 33.5x / 1.94% |
| 现价 vs DCF | 高于乐观 IV（-47% vs 加权） | 贴近中性侧（+33% vs 加权 491） |
| 累计净现比 | 0.56 | 0.56（行业共性） |
| 治理 | 高位合规套现（28.7 亿单轮） | 立案+七折甩卖+易主（已兑现型恶化） |
| 研发费率 | 显著更高（自研纵深/技术租金） | 2.1%（快反工厂/成本效率租） |
| 输赢点 | 输在价格、赢在治理下限+规模地位 | 输在治理、赢在估值相对便宜 |

- **核心迁移结论**：同行业双雄在同一框架下都落 2.7-2.8 档、极差同为 1.00（分歧都在"价格"维度）——**行业评分有"带"（周期顶部+客户集中+净现比 0.56 三重共振把整个行业压进 2.5-2.9 档），公司间差异只决定带内排名**。分析第三家（天孚/联特）时先定行业带、再给公司相对分
- **价格极端度谱系**：旭创（现价>乐观 IV，四锚三红灯）＞新易盛（隐含 g1 19-32%）＞"击球区共识价"（旭创 371-409 / 新易盛 210-260）——同业对比时用"现价在 DCF 情景谱系中的位置"替代绝对 PE，两地市场情绪差 ≠ 基本面差
