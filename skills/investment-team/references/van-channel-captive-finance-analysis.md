# 自有渠道 + 附属金融子公司（van channel + captive finance）分析框架

> 2026-10 快扣 Snap-on（SNA）实战沉淀。适用：Snap-on Financial Services、Caterpillar（Cat Financial）、Deere（John Deere Financial）、PACCAR Financial、Textron Financial——任何「路线式自有渠道 + 附属信用/金融公司」混合体。渠道无 FS 的同类（Cintas、Vestis）只适用 §3 渠道竞争法。

## 1. 模式识别

- 自有 van/路线车队每周触达客户工位（非卖场、非电商、非分销商）
- 分部报表含 FS/Financial Services 段：客户应收 + 净利息收入
- 段永平定义：「一家开上公路的信用社」——卖工具是获客，放贷款是利润率来源

## 2. 报表三大失真（比价前必还原）

| 失真 | 机制 | 处理 |
|---|---|---|
| **ROE 含 FS 杠杆** | SNA 乘数 ~1.4x、CAT 权益乘数 4.6x 被 Cat Financial 融资债抬高 | 质量锚换主业 ROIC（SNA 18.4%、CAT ME&T 口径）；PE/ROE 仅作参考并注明 |
| **净现金叙事失效** | FS 现金 = 客户贷款资金池，不是可分配现金 | 禁用「净现金占市值」托底论证 |
| **营收-应收剪刀差** | FS 应收增速 > 工具销售增速 = 渠道信用宽松保收入，非需求旺盛 | 必查两者增速差，>5pct 即红旗 |

## 3. 渠道竞争「钱包重叠」分析法

- **判词**：渠道不重叠，钱包重叠——van 不与 Home Depot 抢货架，但技师年度工具预算是同一个钱包。
- **侵蚀表现形态**：不是份额流失（SNA 有机增长未失速），而是**利润率挤压**——毛利率守住（产品组合强）但 opex 被迫加码（防御性人员/运费投入）。SNA Q2'26 Tools Group 利润率 −120bp（毛利率仅 −30bp、opex +90bp）。
- **诊断四步**：①分部毛利率 vs opex 增速拆解，压力在哪一层；②直接冲突类目占营收比（SNA <1/3，现金牛在诊断设备/举升而非电动工具）；③反面证据（C&I 有机 +11% 补位）；④裁决变量 = 分部利润率轨迹连续性——**续降 = 钝刀确认（结构性），企稳 = 一次性投入**。连续两期续降触发评分强制下修（同 aidc 第二曲线裂缝规则）。

## 4. 估值语言：「公允价格的复利机器」三件套

当概率加权 DCF ≈ 现价（安全边际 ±2% 内）但公司是正利差复利机器时，DCF 安全边际语言失效，切换：

1. **第一道过滤器**：FCF Yield vs 无风险利率正利差（SNA 5.82% vs 10Y ~4.2% = +1.6pp；负利差如 CAT −2.9pp 直接一票否决持仓级结论）
2. **主估值语言：EPS 路径法总回报分解** = EPS 增长 + 股息率 + 倍数变动（SNA：g7%/20x 退出 → 年化 ~12.3%；同 MTD 5.3%、LAMR IRR 11.0% 家族）
3. **股东收益率**：股息 + 回购净额（SNA 3.70%），高派息连增记录（16 年）作下限证明

结论模板：「完美的复利机器 × 公允的价格」——与 MTD「伟大的复利机器 × 平庸的买入价格」、潍柴「悲观侧定价」构成三象限。

## 5. SNA 实测数据包（2026-10-16，价格 $368.84/市值 $19.1B）

- TTM：营收 $5,275M（+4.0%，有机+3.0%）；营业利润率 **25.2%**（+60bp，行业第一）；净利率 19.6%；ROE 17.9%；ROIC 18.4%；FCF $1,109M（Yield 5.82%，净现比>1）
- FS：应收 $1.9B、净息收入 ~$110M/年；净债务 ~$1.4B（1.8x EBITDA）
- 股东回报：季息 $2.36（+14%，16 年连增）、回购 1.05%
- Q2'26：营收 $1,336.6M 创纪录 beat、EPS $5.31 beat、C&I 有机 +11%（航空/车队/教育=第二曲线信号）、Tools Group 利润率 −120bp
- DCF 三情景：悲观 $219（芒格侵蚀路径）/ 中性 $363 / 乐观 $533；概率加权 $370（+0.2% ≈ 现价）
- 同业四强（TTM）：TTI 营收 15,718/利润率 9.1%/PE 23.4x（Milwaukee+数据中心期权）；SWK 15,248/8.5%/22.9x（FCF Yield 9.14% 反转期权）；Makita 5,317/13.7%/16.2x（ROE 8.6% 折价）——SNA 是四强唯一「质量顶级 × 价格公允」组合
