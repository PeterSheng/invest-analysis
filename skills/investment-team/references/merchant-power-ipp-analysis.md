# Merchant Power / IPP / 独立发电商分析框架（2026-08 Vistra 实战）

适用：Vistra(VST)、Constellation(CEG)、Talen、NRG、AES 等以批发市场售电为主的独立发电商（IPP），及竞争性电力零售。核心特征：电价是外生变量，盈利高度周期化。

## 1. 商业模式本质

- 发电商是批发市场（ERCOT/PJM/MISO/NYISO）的**价格接受者**——盈利由外生电价决定
- 典型盈利轨迹（Vistra）：FY21-22 亏损（-$1.3B/-$1.4B）→ FY24 大赚 $2.5B → FY25 腰斩至 $0.75B → FY26 复苏——5 年净利在 -$1.4B~+$2.5B 间摆动
- 结构性改变盈利质量的三要素：①核能/零碳基荷稀缺资产（AI 数据中心 PPA 锁定 20 年现金流）；②零售客户稳定器（TXU 类，营收占比可高达 78%，低毛利但稳定）；③对冲组合管理（锁价能力）

## 2. GAAP 三大陷阱（Vistra 2026-08 实战验证）

| 陷阱 | 表现 | 处理 |
|------|------|------|
| 营收失真 | 衍生品会计让营收剧烈波动：Q2'26 营收 $4.02B vs 共识 $5.73B（-19% miss），但 adj EBITDA 实际 +30.8% beat | 营收 miss ≠ 基本面恶化；用 adjusted EBITDA / FCF 判断 |
| 净利被对冲 MTM 污染 | FY25 GAAP NI $752M 含未实现对冲损失 $808M；Q2'26 GAAP EPS $0.76 vs adj $1.68 | 必须同时报 GAAP 与 adjusted 双口径并写明对账；GAAP PE 与 adj PE 差距大时双标注 |
| OCF 与净利背离 | OCF/NI 2.5x+ 是常态（D&A 重 + 对冲非现金项）；FY25 NI $752M 但 OCF $4,070M | 现金流远强于账面利润——OCF/FCF 才是估值锚，勿当异常信号 |

## 3. 对冲覆盖率 = 核心跟踪指标

- 公司披露分年度对冲覆盖率（Vistra：2026 98% / 2027 89% / 2028 65%）
- **含义**：近 2-3 年现金流高度可见（盈利确定性接近合约化），但封顶电价上行；GAAP 利润被对冲 MTM 反复污染
- **估值含义**：现价便宜与否，赌的是对冲到期后的现货电价水平。报告必须显式写出"对冲滚动时间表"，把投资论点锚定在到期后情景（Vistra：2028 覆盖率降至 65% = 暴露开始）。管理层的对冲策略激进度（FY25 -$808M MTM 损失）也是治理判断素材

### 3.5 核电 IPP 双口径：对冲覆盖率 vs 核能 PPA 化率（CEG 2026-09 实战补充）

> 纯核资产（CEG 22GW）与气电混合资产（Vistra）的跟踪指标要分开：Vistra 有大量气电，靠**对冲覆盖率**（3 年窗口）；CEG 类纯核资产靠**长协 PPA 化率**（15-20 年窗口，对手方是 hyperscaler）。CEG 2026-09 时点：微软三里岛 835MW + Meta Clinton 1,121MW + 2026-08 再签 920MW（Walmart 176MW）→ **hyperscaler PPA 锁定核电产出 ~30%**，公司称"most output contracted through 2050+"（含对冲与零售合同，口径宽于纯 PPA）。**PPA 化率 30%→60% 是"周期股→准公用事业"重估的主线叙事**——综合报告的分歧呈现（芒格 2.25 vs 李录 3.75）即围绕此变量：段永平/芒格拒绝为"未来可能发生的 PPA 化"预付 23.8x 调整 PE，李录把 PPA 化当作 10 年确定方向。
>
> **重启/新增核电项目的第三重时间风险：电网互联队列**（CEG 三里岛/Crane CC 2026-03 实战）：即使 NRC 燃料许可 + FERC 容量互联权（CIR）转移都获批、PPA 已签（微软 20 年）、$1.6B 已投，**PJM 互联研究仍可能把并网排到 2031（公司目标 2027）**——"机组 ready ≠ 能上网"。分析任何核电重启/新建/SMR 项目必须查互联队列状态（PJM/MISO/ERCOT 各自队列 4-5 年起步），这是芒格失败路径的固定一条，也是 FERC/NRC 之外被市场低估的第三道审批。
>
> 估值启示（CEG）：FCFbG yield 4.1%（vs Vistra 9.5%）+ Forward adj PE 23.8x（vs 14.6x）的 63% 溢价 = 市场为核纯度+PPA 对手方质量付的成长溢价——**溢价能否维持取决于 PPA 化率爬坡，而非当期电价**。GAAP EPS 被对冲 MTM 污染时（Q2'26 GAAP $1.42 vs adj $2.55，差额含 $340M 税后对冲浮亏）用调整口径，但芒格视角要显式质疑"调整后增长 vs 账面真金"的长期背离（FY25 GAAP 净利 -38% 为先例）。

## 4. 估值锚（正确 vs 错误）

| 指标 | 判断 |
|------|------|
| ✅ EV/EBITDA（forward adjusted EBITDA） | Vistra 2026E 9.5x / 2027E 9.0x |
| ✅ FCF Yield（adjusted FCF before growth 指引） | Vistra 2026E FCFbG 中点 $4.325B / mcap = 9.5%；悲观情景也有 7.7% |
| ✅ Forward adjusted PE | 2026E adj EPS $9.30 → 14.6x |
| ❌ PE/ROE | 回购压缩普通股权益（$3.0B）+ 优先股 → ROE 42.96% 是统计假象，PE/ROE 0.54 无意义（同 Apple/NVDA 性质，须 ⚠ 标注） |
| ❌ 归一化 PE（3 年均值 EPS） | 结构已变（收购 + 核能 PPA 增厚），Vistra 3 年均值 $4.25 → PE 32x 严重失真；用 forward adjusted EPS 替代（2026E $9.30, +77% YoY） |
| ⚠ PB / BVPS | BVPS $8.95 / PB 15.2x 无估值意义（权益被回购压缩），DCF 里勿用 PB 锚 |

## 5. DCF 建模要点

- **Base FCF 用"adjusted FCF before growth"（FCFbG）指引**，不是 GAAP FCF（含增长 capex：Vistra GAAP FCF TTM $2.26B vs 2026E FCFbG $4.33B）
- **⚠ 债务口径：先查公告收购的现金流出是否已入表再扣减**。Vistra 实战教训：首版模型把 Cogentrix $4B（2026-01 宣布、H1'26 已完成、已反映在净债务 $20.1B）重复扣除，股权 IV 低估 ~$13/股。正确口径 = 当前报表净债务 + 未来现金流出（Vision 买断 $3.25B 分 5 期付款，取 PV ~$2.9B）
- **WACC 敏感性极大**（Beta 1.43 + merchant 暴露 → WACC 8-9%）：中性情景下 9%→IV $162 vs 7%→$268（±30%），必须输出 WACC×永续g 矩阵
- **现价反推隐含永续 FCF 增速**：`g_implied = WACC − FCF0/EV`。Vistra 现价隐含仅 2.2%（WACC 8.5%）vs 指引增速 6%+ → 市场在定价"AI 叙事证伪 + 电价均值回归"，未为增长付钱
- 三情景 FCF0 围绕指引中点做 ±20% 摆动（悲观取指引低端再打折）

## 6. 关键跟踪指标清单

- ERCOT/PJM **远期电价**（管理层电话会常提示走软/走强——Vistra Q2'26 承认 ERCOT 远期走软是 -38% 回撤元凶之一）
- **容量拍卖结果**：PJM 2026/27 清出 $329.17/MW-day 创纪录（需求侧验证，直接影响 East 分部）
- **核能/数据中心 PPA 签约**：MW 数、合同期（20 年）、对手方质量（AWS 1.2GW Comanche Peak、Meta 2.6GW 三座核电站）、占核电容量的比例（Vistra 3.8GW/6.4GW ≈ 60%）
- **对冲覆盖率逐年滚动表**（2026/27/28）
- 核电站 NRC 许可证延期（Comanche Peak 延至 2050/2053）——核电 = 不可复制稀缺牌照
- 监管：德州 PUCT/ERCOT 互联审查截止（2026-12-10）、电价上限/市场设计讨论、behind-the-meter 数据中心交易的政治阻力
- 内部人交易方向（Vistra 6 个月 9 卖 0 买）
- 极端天气双刃剑（2021 德州寒潮巨亏 vs 2026-08 热浪机组可用率 97%+）

## 7. 四大师视角适配

- 段永平：核能稀缺资产（护城河）vs 商品化电价（坏生意）——"好资产 × 中等生意"典型样本；管理层对冲策略激进度 + 内部人交易 = "本分"判断素材
- 巴菲特：现金流（OCF/NI 2.5x）> 账面利润；FCF Yield + DCF 三情景 + 隐含增速反推；ROE 统计假象必须拆穿
- 芒格：失败路径 = 对冲到期 × 低价现货 × 高杠杆（净债/EBITDA 3x+）的"完美风暴"；"利润由外生变量决定 = 能力圈外"；大额 M&A 现金流出（Cogentrix $4B + Vision $3.25B）挤占 FCF 分配
- 李录：电气化 + AI 双引擎（美国电力需求 20 年首现结构增长 0.5%→2-3%），竞争性核电全球仅 3 家（Vistra/CEG/Talen）= 稀缺牌照；数据中心电力 TAM 2025 $200B+ → 2030 $400-600B/年
- **评分分歧 > 1.5 分时**（Vistra：芒格 2.25 vs 李录 4.25），综合报告把"分歧本身"作为核心结论呈现——分歧即标的核心矛盾（需求确定性 vs 商业模式脆弱性）
