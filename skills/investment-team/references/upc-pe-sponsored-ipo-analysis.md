# PE 控股的 up-C 结构次新股分析框架（IPO 后首年）

> 适用对象：2018 年后由 PE（Blackstone / Carlyle / KKR / H&F / Bain）主导的大型 LBO-IPO，
> 财报出现 **Class A / Class B 双类股 + Up-C + TRA（应收税款协议）+ 数十亿美元 NCI**。
> 实战原型：**Medline Inc.（NASDAQ: MDLN，2025-12 IPO @ $29，2026-11 首轮覆盖，综合 3.3/5 中性）**。
> 与 `references/ipo-analysis.md`（打新/S-1 阶段）分工：彼文管"要不要申购"，本文管"上市后第一年怎么估值"。

---

## 0. 触发信号（命中任一即加载本文）

- 招股书/10-K 出现 "Up-C"、"Tax Receivable Agreement"、"Class A common stock"、"Class B units"
- 资产负债表 NCI > 股权价值 10%，且 NCI 对应"PE 卖方持有的 LP units"
- 上市时间 < 24 个月，且 Sponsor（PE）仍持股 > 30%
- GAAP PE 与券商/行情显示的 PE 相差 2 倍以上，Adj. EPS 与 GAAP EPS 相差 2 倍以上

---

## 1. 股本与市值口径（最高频错误，先立后算）

| 项 | 正确做法 | 错误做法 |
|---|---|---|
| 总股本 | **Class A + Class B 全部计入**（Class B 与 LP units 1:1 配对） | 只取 Class A → 市值低估 30-50% |
| 市值 | 全股本 × 价格 | 用流通股（float） |
| NCI | **不扣**（经济权益已含在总股本内） | 在 EV→股权价值环节再减 NCI = **双重扣减** |
| 校验 | `总股本 × 价格 ÷ 归属净利` 是否与券商 PE 一致 | 差 2 倍 = 只用了单一类别股本 |

Medline 实测：Class A 8.79 亿 + Class B 4.37 亿 = **13.16 亿股** → 市值 521.7 亿美元；NCI 75.85 亿**不再扣减**。

---

## 2. TRA（Tax Receivable Agreement）的三档处理

**定义**：Up-C 上市时，公司把未来税盾（无形资产摊销 + NOL）实现额的 **85%** 以现金支付给 PE 卖方，账面单列负债。

| 处理 | 逻辑 | 适用 |
|---|---|---|
| 全额计入净负债 | 视为 100% 实现 | 极度保守，通常过度惩罚 |
| **按可实现比例计入（推荐）** | 税盾实现需未来应税利润，按协议归属比（Medline **85%**）折算 | 基准情景默认 |
| 忽略 | 视为非负债 | 错，会高估 IV |

Medline：账面 TRA **44.03 亿** → 建模取 **26 亿**（85% × 44.03，简化归属 PE 部分）。**所用比例必须写进 `00-数据包.md` 的模型规格节**，否则下轮无法复现 IV。

配套检查：TRA 余额**下降速度**若远超税盾实现节奏 = 现金在大量外流给 PE（证伪线之一）。

---

## 3. 三件套口径对账（GAAP / Adjusted / 剔一次性）

LBO 后的报表被三重噪音污染，必须并列呈现，禁止择一：

1. **GAAP 归属净利**（含 LBO 无形资产摊销 ≈ 每年 7 亿美元、SBC、NCI 分摊）
2. **Adjusted**（公司口径，加回摊销/SBC/一次性）
3. **剔一次性后的 Adjusted**（真正可持续）

Medline 实测（9M26 / FY26E）：

| 口径 | EPS | 对应 PE | 说明 |
|---|---|---|---|
| GAAP 归属 | $0.65 | **61x** | 含 5.29 亿摊销 + NCI |
| Adjusted | $1.55 | **25x** | 公司口径 |
| 剔 IEEPA 退税 | $1.32 | **30x** | 可持续口径 |

**硬规则：三口径 PE 并存时，估值主锚用 DCF，倍数只作辅证（0.3 权重上限）。** 单一 PE 在这类公司上没有定义。

---

## 4. 一次性项：方向、规模、同向对冲

- 列出全部一次性项并**标注符号**：Medline 关税退款 **+3.24 亿**（正）、Tracy 火灾 **-3.16 亿**（负）
- **两项近似对冲 ≠ 可忽略**：它们分别落在不同季度的 Adj. EBITDA，会同时扭曲"同比增速"与"利润率"
- **铁律：Adj. EBITDA 增速一律做"剔一次性"双算**——
  Medline 9M26 报 +5.0%（利润率 10.8% vs 12.9%），**剔除退税后 -7.1%**。"增收不增利"只在剔除后可见。
- 判据：`剔一次性增速 − 报表增速` 差值 > 3pct 时，报告必须单列一节说明口径差，并在评分中按剔后口径打分。

---

## 5. 分部引擎错配：利润引擎 vs 增长引擎不同速

必做三列表（收入占比 / 利润占比 / 利润率及其变动），并明确"增长来自哪个分部"：

| 分部 | 收入占比 | 利润占比 | 利润率 | 增速 |
|---|---|---|---|---|
| Brand（自有品牌） | 46.5% | **82.8%** | 26.1%（+70bp） | +6.5% |
| SCS（分销服务） | 53.5% | 17.2% | **4.7%**（-80bp） | +15.1% |
| Corporate（未分配） | — | -18.0% | — | 费用 +18.6% |

结论语言模板：**"增长引擎在低毛利分部运行，混合利润率 10.7%→13% 的修复是全部多头逻辑的命门"**。
数学化：混合利润率 = Σ(权重 × 分部利润率)，只调权重即可推演修复路径（每 1pct 权重从 SCS 转向 Brand ≈ +21bp 混合利润率）。

---

## 6. PE 剩余股权悬顶：三个可量化温度计

1. **二次发行价 = 机构定价锚**：Medline 2026-05 增发 7,255 万股 @ **$37**（PE 套现 28.4 亿）vs 现价 $39.64 → 一级市场愿意出的价就在 $37
2. **13G/A 减持轨迹** = 聪明钱温度计：GIC 13.0% → 8.5% → 6.8%
3. **剩余持股比例 × 转换条款**：Class B 4.37 亿股（33%）1:1 可转 → 转换即增量抛压

**估值含义**：赞助人减持期内（通常 12-18 个月）估值被系统性压制，**直接决定"何时是击球区"**——把"PE 减持窗口结束"写进跟踪日历，而不是只写进风险清单。

---

## 7. 估值栈与击球区

```
目标价 = DCF@WACC10%/tg3%（0.4）+ EV/EBITDA(FY+1) × 行业中枢（0.3）+ PE(正常化)（0.3）
```
- **反向 DCF 反解现价隐含 IRR**（`brentq`）是最锋利的单图：Medline 现价 $39.64 隐含 IRR 仅 **8.1%** = 零安全边际
- 三情景概率加权（25/50/25）给出"赔率不对称"判断：Medline 熊 19.2 / 基准 31.5 / 牛 49.3 → 加权 32.9
- **击球区定义**：`≤15x FY+1E EBITDA`（Medline → ≤$30）而非"跌 X%"
- **减持区**：`≥ 牛市 IV × 0.95`；泡沫区单独设档（≥$55）

---

## 8. IPO 后首年的四条专属证伪线

1. 低毛利分部（SCS）利润率**连续两季**跌破阈值（Medline <4.2%）→ 混合利润率修复论破产
2. **剔一次性后 Adj. EBITDA 同比仍为负** → "关税/成本一次性"解释失效
3. TRA 余额下降远快于税盾实现 → 现金外流给 PE
4. 二次发行价被后续增发**下破** → 机构定价锚下移

## 9. 数据源与抓取要点

- **SEC EDGAR 为唯一一手源**：`company_tickers.json` 绑 CIK → submissions → 10-Q 正文 + **424B4 招股书** + 8-K（自定义 User-Agent 必填）
- 招股书必抓九项：配送中心数 / SKU 数 / 自有工厂数（及北美占比）/ 供应商数 / 核心客户留存率 / 前十大客户占比 / 创始人-股东受益所有权表 / 长期财务目标（调整后 EBITDA 利润率区间）/ 自有品牌 SAM 与渗透率
- **上市首年 K 线**：stooq 对新 ticker 常返回空 → 腾讯 `us{TICKER}.OQ` 日 K（可回溯上市以来全部交易日）
- 上市首日收盘价也是锚（Medline $41 vs 现价 $39.64 = 破发后横盘），用于判断"IPO 溢价是否已消化"

## 10. 常见误判清单

| 误判 | 后果 |
|---|---|
| 只取 Class A 股本 | 市值/EV 低估 30-50%，PE 虚高一倍 |
| EV 已用全股本仍减 NCI | 股权价值双重扣减，IV 系统性偏低 |
| TRA 全额或完全不减 | IV 偏差 10-15% |
| 只看 Adj. EBITDA 增速 | 把 -7.1% 读成 +5.0%，"增收不增利"完全错过 |
| 用 GAAP PE 判"贵/便宜" | 61x vs 25x，结论方向可能反转 |
| 把"自有品牌毛利率高"直接当护城河满分 | 需同时看分销分部的锁客作用（入口 vs 变现） |
