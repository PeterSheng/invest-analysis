# 专利悬崖 / LOE 大药企分析框架（2026-10 辉瑞 Pfizer/PFE 实战）

> 适用：面临**集中专利到期（LOE wall）**的大型制药公司——PFE/MRK/BMY/GSK 类纯大药企。
> 区别于：`comprehensive-pharma-conglomerate-analysis.md`（华东医药类商业+工业混合体）、`biotech-bd-licensing-analysis.md`（创新药 BD 授权首付款污染）、`serial-acquirer-analysis.md`（TMO 类收购机器——本框架只借用其 ROIC≈WACC 语言）。

## 一、核心语言：「有到期日的护城河」

专利 = **10-12 年倒计时租约**，不是消费品牌式无期限护城河。分析起点是把"悬崖"量化成一张表：

| 要素 | 量化口径（PFE 实测） |
|---|---|
| LOE 墙 | 2026-28 每年 **$17-18B（≈营收 28%）** 失去美国独占权 |
| 硬日期 vs 政策日期 | Eliquis 美国仿制药 **2028-04-01（和解锁定死日期）** vs IRA MFP（Eliquis $231/30天 2026-01 已生效、Ibrance/Xtandi 2027 谈判 2028 生效）——和解日期不依赖政治，IRA 日期可滚动扩围，两类日期必须分列 |
| 悬崖中唯一地板 | Vyndaqel（专利豁期 2031，~$5.5B+，~9%）——每次都要找出"没裂缝的那块地板"并给占比 |
| 倍数端 vs 增速端定价分离 | PE 9.2x 已部分定价悬崖，但现价反推隐含 FCF 增速 6.5%/yr vs 现实 0-3%——**倍数端定价了、FCF 增速端没定价**，两句话必须同时说 |

**悬崖前正增长窗口判别（PFE Q1'26 +5.4% / Q2'26 +2.6%，ex-COVID 首次转正）**：正增长出现在 LOE 墙之前≠拐点——它是**卖点窗口不是安全垫**。判据：增长能否延续到墙后。

## 二、「洞 vs 铲子」时间差框架（本框架核心增量）

把悬崖写成"洞"、对冲手段写成"铲子"，**时间差本身就是风险**：

| 洞（流失） | 铲子（回填） | 时间差 |
|---|---|---|
| 2027-28 塌方 $17-18B/yr | ① Seagen ADC $3.3B→$8B/2030（公司口径） | 2030 才挥到最大 |
| | ② Metsera 减肥组合（月度给药差异化） | 2027+ 才有数据 |
| | ③ 成本削减 ~$7.7B 至 2027 跑满 | 省出来的是流量不是收入，一次性 |

粗算铲子最多填 $10-13B（估）vs 洞 $17-18B/yr——**回填速度 < 流失速度的年数 = 报告的"现金流债"**。EPS 悬谷年（PFE 2028 $2.45）就是洞-铲缺口的会计表达。

## 三、会计陷阱：IPR&D 费用化 + 连续减记 → TTM PE 废锚

与 M&A 摊销污染（WM/Stericycle 案例）**同族不同种**：买的是 Ph1/Ph2 管线资产时，对价按会计规则**必须 IPR&D 费用化**（不是摊销，不可资本化）：

- PFE 实测：Metsera（总对价最高 ~$10B）→ Q4'25 IPR&D 费用化 **$4,433M**（单季亏 $1.65B）→ Q2'26 再减记 **$4.4B**（科目待 10-Q）→ TTM GAAP EPS $0.76 vs 调整后 ~$3.15 = **2.3 倍差距** → TTM PE 36.2x = **废锚**
- 检测触发器：**大额管线收购交割季单季巨亏** + 新闻含 "IPR&D" 关键词；连续两个 $4B+ 级减损项 = 第二红旗
- 处理：GAAP 用于 DuPont（标注污染年），估值主锚换 **PE(调整指引中值)**；"摊销+重组"是并购战略的**内生经常性成本**，不是噪音（真实盈利能力在 GAAP 与调整后之间）

## 四、CVR 市价 = 里程碑兑现率的实时市场定价（免费概率仪表）

- PFE 实测：Metsera CVR 面值 $20.65，交割前夜市价 **~$5.27 → 市场定价兑现率 ~25%**
- 用法：管线成功概率不拍脑袋——**CVR 市价 ÷ 面值** 就是市场给的实时期权概率；CVR 市价向 $0 靠拢 = 预警指标
- 附带审计：竞价战溢价——Metsera 终价较原协议（$47.50+$22.50）为对 Novo 竞价**加价 ~35%**，"为赢拍付的溢价，市场不认"（段永平/芒格共用扣分点；CVR 折价+加价溢价 = 市场对同一笔交易的双重否定）

## 五、股息贴线诊断（衰退-FCF 收息股红线）

- 覆盖率三档并排：FY25 104% / TTM 83% / 2026E ~92%（估）——**贴着盈亏线走**
- 缺口填补来源必须拆开：**资产处置收益（一次性，PFE TTM $1.87B）+ 小幅举债** = "可持续但不宽裕"；处置收益填股息 = 把未来的自己卖给现在的股东
- 红线：**覆盖率连续两年 <85% 或增息幅度归零**（PFE 已只 ~2.4%/yr）= 削减前兆 → 收益型资金踩踏触发器，评分强制下修
- 长支付记录（PFE 346 季）= 资产也是枷锁："没人敢先停，直到市场替你停"

## 六、估值锚：大药企 PE 带 + 双口径鸿沟

- **PE 带参照（约数，估）**：BMY ~7x / GSK ~8x / MRK ~9-10x / PFE 9.2x / JNJ ~14x / AZN ~15x / LLY 30x+——**旁边有 BMY 摆着，"便宜"在这类资产里不是稀缺品**；低倍数 = 行业性折价，非个股 alpha
- **EPS 路径法 vs FCF DCF 的鸿沟 = 报告核心语言**（PFE：路径法 ~14%/yr vs 加权 DCF $16.19/-41%，差 ~$14/股）——分歧本质 = 盈利修复叙事 vs 现金流现实（利息 $4.3B + 股息 $9.8B 的"隐形租金"）；20 年口径下现金流可信
- **有形 P/B 幻象**：商誉+无形 $69.3B 占权益 72% → 账面 P/B 1.63x 是幻象，有形 ~5.8x；ROE 34%→8% 判"双重稀释"（收入崩塌 + 并购膨胀分母），禁用均值回归框架
- 击球区语言：三锚（加权 IV / 乐观 IV / 分析师 PT）→ 四段动作表（观察 ≥$26 / 试探 $22-24 / 主建 $17-20 / 用桶接 ≤$16，PFE 实测）

## 七、政策层：IRA/MFN 是定价权的政治重置

- IRA 逐品种时间表（MFP 生效日 / 谈判年 / 生效年）必须列表；MFN/TrumpRx 框架 = 全行业立标，立法化是尾部
- 关税豁免 3 年（PFE：$70B 美国投资换豁免）= **可撤销的政治让步**，到期不续进尾部清单

## 八、四大师适配要点（PFE 落地样本）

| 大师 | 框架适配 | PFE 评分 |
|---|---|:---:|
| 段永平 | 专利租约 vs 品牌护城河对比表；"好生意浓度"分层（🟢层宽度 <15% 却要填 28% 的洞）；管理层"为赢拍加价"审计 | 3.25 |
| 巴菲特 | ROIC≈WACC + 商誉墓碑 + 股息覆盖三档；击球区四段 | 3.25 |
| 芒格 | 六条失败路径（悬崖 35%/股息 20%/管线失败 40%/政策 30%/诉讼 15%/再并购 45%）；"体面地失血"判词；风险度→吸引力反转并注明转换逻辑 | 2.50 |
| 李录 | **赛道/位置分离打分**（赛道 5/5 × 位置 3/5）；安全边际开关制：加权 DCF ≤-30% → 总分锚 ≤3.25，赛道高分只进锚定依据不进总分 | 3.00 |

综合 = 等权 3.00；极差 0.75 ≤1.5 → 无方向性分歧，唯一分歧 =「便宜的定性」（估值地板 vs 半价买悬崖）。
