# 收租型地产 / 投资物业公司：股息持续性 + 在建项目增长测算框架

> 2026-11 太古地产（1972.HK）实战沉淀。适用：太古地产、恒隆地产（00101）、希慎兴业（00014）、九龙仓置业（01997）、嘉里建设（00683）、领展（00823，REIT 口径另见 `reit-analysis-guide.md`）、置富（00778）、阳光房地产基金等**以持有投资物业收租为主业**的公司。
>
> **与相邻框架的分工**：`property-developer-to-operator-transition.md` 管「开发萎缩 + 持有型增值」的转型期房企（龙湖/华润置地），那里的核心矛盾是**两个生意混在一张表里**、PE 失效、清算管道剩余年限；本文管**已经是收租主业、但仍有在建/待落成项目作为增长引擎**的公司，核心问题是**股息能不能持续、在建项目能不能接上**。两者都要求先做分部/口径拆解，但估值锚不同：前者 NAV+SOTP+稳态 DCF，后者 P/NAV 历史区间 + DDM + 市值÷年租金。

## 0. 三套利润口径：先拆清，再谈股息

香港收租型地产的利润表普遍有三层，**用错一层，股息持续性结论直接反转**：

| 口径 | 常见名称 | 含什么 | 能不能用来判断股息持续性 |
|------|---------|--------|------------------------|
| ① 报表归母 | 股东应占溢利 / Profit attributable | 含**投资物业公允价值重估**（可正可负、非现金） | ❌ 禁用（重估年景好时能把股息覆盖率虚增一倍） |
| ② 基本溢利 | 基本溢利 / Underlying profit | 剔重估、剔一次性，但**往往仍包含物业买卖（住宅销售/交付）** | ⚠️ 半可用，需再拆一层 |
| ③ 经常性基本溢利 | 经常性基本溢利 / Recurring underlying | 剔重估+剔出售收益，**但部分公司仍把物业买卖的经常性贡献留在里面** | ✅ 主口径，但必须做下面这一步 |

**必做拆解（纯租金口径）**：

```
纯租金/收租口径净利 = 经常性基本溢利 − 物业买卖贡献（住宅销售毛利+交付）
                     − 酒店/其他亏损（若公司单列，注意酒店通常是负贡献，剔除它会"改善"分母）
```

- **增长率幻觉（太古地产 2026H1 实测）**：经常性基本溢利同比大幅增长（+30% 量级）的表象，主要来自**物业买卖（住宅交付/出售）**，不是租金收入。若直接把这个增速外推成"股息可持续增长"，等于把一次性交付当成永续年金。
- **酒店/餐饮常是负贡献**：剔除亏损分部会让"租金覆盖股息"看起来更好——报告里两个口径都要列，不能让读者以为租金本身很赚钱。
- 交付节奏带来的跨期摆动：物业买卖收入按交付确认，**年份间可归零**，所以「纯租金口径」才是唯一可外推的分母。

> 写进 `00-数据包.md` 的桥接表（固定格式）：

| 项目 | 金额 | 说明 |
|------|------|------|
| 报表归母溢利 | X | 含投资物业重估 Y |
| − 投资物业公允价值变动 | −Y | 非现金，剔 |
| − 一次性（出售子公司/减值回拨） | −Z | 剔 |
| = 基本溢利 | A | 公司披露口径 |
| − 物业买卖（住宅交付）贡献 | −B | **股息持续性的关键在于这一行** |
| + 酒店/其他分部亏损（若为负则加回） | C | 说明口径 |
| = 纯租金口径净利 | D | 覆盖倍数用此分母 |
| 每股纯租金净利 | D ÷ 股本 | 与 DPS 直接比 |

## 1. 股息覆盖：四把尺，交叉验证

| 尺 | 公式 | 读法 |
|----|------|------|
| A 表层尺 | 全年 DPS ÷ 基本溢利（每股） | 高派息地产常见 1.0-1.2x，**不能单独作为红线** |
| **B 可持续尺** | 全年 DPS ÷ **纯租金口径**每股净利 | **核心判定**：<1.0 表示租金本身能养股息；>1.0 说明靠出售/交付/资产负债表补 |
| C 现金尺 | 全年 DPS ÷ 每股经营现金流 | 地产 OCF 受预售回款扰动大，**用三年平滑**，不用单年 |
| D 自由现金尺 | 全年 DPS ÷ (每股 OCF − 每股资本开支) | 在建高峰期此项必然 <1，这是**资本开支周期的正常现象**，不是股息危机 |

**判定纪律**：
1. **B > 1.0 且连续两年** = 股息依赖非租金来源，必须在综合裁决中单列股息可持续性风险。
2. **B < 1.0 但 D < 1.0** = 典型的"建项目期"，股息靠旧资产现金流 + 新增借款撑，可接受但要看**净负债率路径**（见 §2）。
3. **C 或 D 为负** = 当年现金层面根本付不出股息，靠出售资产/再融资，属红旗。
4. 半年度口径不作判据（滨江服务教训已写入 SKILL.md：半年股息 > 半年 OCF 不等于不可持续）——**一律年度口径**。
5. 港元地产公司常以"中期息 + 末期息"两次派发，**TTM DPS = 最新中期息 + 上一财年末期息**；公司 IR 的「股息历史」页比 akshare 分红接口更全（含特别股息、以股代息选项），见 §5。

## 2. 资产负债表可承性（决定"能不能撑到项目落成"）

| 指标 | 口径 | 舒适区参考 | 备注 |
|------|------|-----------|------|
| 净负债率 | (有息负债 − 现金及等价物) ÷ 归母权益 | <30% 舒适、30-40% 观察、>40% 警戒 | **与该司自身历史区间比对**优于绝对阈值 |
| 有息负债口径 | 短期贷款 + 长期贷款 + 应付票据 + 融资租赁 | — | 港式科目名多为「银行借款/贷款」，见 `hk-stock-data-sources.md` §2.6.1 |
| 利息覆盖 | 租金净利（或 EBITDA）÷ 资本化前利息支出 | >3x 稳、<2x 警戒 | **注意利息资本化**：在建期利息进资产，落成后转费用化——同一笔债务的"利息负担"会在落成那年突然显现（利润拐点的隐形杀手） |
| 加权融资成本 | 报告披露 | 与 10Y HIBOR/US Treasury 联动 | 美元债占比高的港资地产对 Fed 路径极敏感 |
| 短债占比 / 未动用授信 | 报告披露 | 短债 <20%、授信覆盖短债 >1x | 再融资风险的第一手证据 |

**"建项目期"的标准画像**：净负债率上行 + 利息覆盖下行 + D 尺 <1 + 股息维持不变 = 用资产负债表替股东垫付资本开支。这不是危机，但**必须把"净负债率峰值年份 + 峰值水平"算出来写进报告**，它是股息政策的真实约束条件。

## 3. 在建/待落成项目 → 增量租金 → 增量 DPS（五步法）

用户明确要求「把未来投产项目纳入增长测算」，这就是标准算法。**没有这一步，收租股的增长就只剩租金续租调整（个位数），会把"落成期"误判成"零增长"。**

### 第 1 步：项目清单表（每行一个项目，缺一列就不完整）

| 项目 | 地点 | 权益% | 总 GFA | 其中投资物业 GFA | 投资额 | 预计落成 | 预租率/预售率 |
|------|------|------|--------|----------------|--------|---------|-------------|

数据来源：年报「主要发展项目」表 / 中期报告在建工程附注 / 季度运营数据公告（见 §5）。**权益比例必须列**——合资项目的租金要按权益折算才能进每股测算。

### 第 2 步：稳定期增量 NOI

```
增量 NOI = 可租赁 GFA × 稳定期单价 × 稳定期出租率 × (1 − 运营成本率)
```

- **单价取值优先级**：①公司披露的同区/同类项目租金；②本公司现有组合平均租金（作为下限，新项目通常定价更高）；③同区可比物业公开租金（标注"估"）。
- **运营成本率**：收租型物业 15-25%（管理费、差饷、维修），写字楼偏低、商场偏高。

### 第 3 步：爬坡曲线（ramp）——这是三情景的分歧所在

| 年份 | 出租率（中性） | 说明 |
|------|--------------|------|
| 落成首年 | 40-60% | 预租率决定下限；空置成本当年全计 |
| 第二年 | 75-85% | 招商期，租金优惠（免租期）摊薄实际收入 |
| 第三年 | 90%+ | 视为稳定期 |

**压力测试标准动作**：把「落成首年出租率 60%」作为悲观情景锚（太古 2028 新项目即用此值），并同时下压单价 5-10%——两项同时下调才能拉开三情景的估值分歧；只调一项会导致三情景差距过小（等同于没做情景分析，参见 SKILL.md 现代牙科悲观情景教训）。

### 第 4 步：时点校准（三个容易漏的点）

1. **利息资本化停止**：落成后建设期利息转费用化 → 净利当年下降（不是生意变差，是会计时点）。
2. **资本开支峰值已过**：建设期现金流出 → 落成后 FCF 恢复，**D 尺会在落成后 1-2 年自然修复**，报告要画出这条曲线（这是"股息先紧后松"的核心证据）。
3. **交付/销售收入的非经常性**：住宅部分按交付确认，不要混入"租金增长"。

### 第 5 步：每股增量与"落成后正常化股息"

```
Δ每股租金净利 = 增量 NOI × (1 − 融资成本影响) ÷ 股本
ΔDPS          = Δ每股租金净利 × 派息率
落成后正常化股息率 = (现 DPS + ΔDPS) ÷ 现价
```

同时给出**「落成后正常化 P/NAV」与「落成后净负债率」**——三个数一起看，才知道增长是"自有现金建成的"还是"加杠杆建成的"。后者在利率高位期会吃掉全部增量。

## 4. 三情景 DPS/DCF 敏感性（用户点名的交付形态）

统一参数纪律照旧：**WACC 10%、tg 3%**（2026-11 起全局统一，不按行业浮动）。收租型公司额外一组：

| 情景 | 落成首年出租率 | 稳定期出租率 | 租金单价 | 融资成本 | 年度资本开支 | 2028E 每股 DPS | DDM 值 | vs 现价 |
|------|--------------|-------------|---------|---------|------------|---------------|--------|--------|
| 乐观 | 75% | 95% | 基准 +5% | −50bp | 计划内 | | | |
| 中性 | 60% | 90% | 基准 | 基准 | 计划内 | | | |
| 悲观 | 45% | 80% | 基准 −10% | +100bp | 计划内 +10% | | | |

**估值方法选择**：
- **DDM 为主锚**（股息≈可分配现金，纯收租公司适用）：`V = DPS₁ / (Ke − g)`，Ke 用 10%，g ≤3%；派息率不稳定的先用三情景 DPS 再做概率加权。
- **DCF 为交叉验证**（FCF 受资本开支周期扰动，单点值不可信）。
- **P/NAV 为历史区间锚**：投资物业按公允价值计量时，**P/B ≈ P/NAV**，直接看该司 10 年 P/B 区间分位（收租股 0.4-0.8x 常见，低于 0.5x 通常是市场在定价资产质量或治理折价，不是"打折买资产"）。
- **市值 ÷ 年租金收入**：最直观的"这栋楼卖多少钱"锚，跨公司比较用。
- 股息率 vs 10Y 美债/港债利差：收租股是"类债券"，**利差收窄到 200bp 以内时股息提供的保护已很薄**。

## 6. 芒格失败路径（收租型六条，替换通用模板）

1. **核心商务区空置率长期化**（中环/金钟类甲级写字楼，远程办公 + 外资收缩）
2. **零售北移/南下客流逆转**（香港零售销售依赖内地客流，政策与汇率敏感）
3. **内地商场同质化供给**（同一城市 5+ 个高端商场分流，租金议价权下滑）
4. **利率长期高企 → 融资成本吃掉增量租金**（美元债 + HIBOR，落成期恰逢高利率是最坏组合）
5. **股息政策转向**（家族/控股股东主导的公司在资本开支高峰年降低派息，股东无否决权）
6. **再投资回报率 < WACC**（用 500 亿建一座 4% 收益率的楼，等于用股东的钱买规模）——判据：**新增投资 ÷ 增量 NOI = 隐含收益率**，低于 Ke(10%) 即价值毁灭

## 7. 跟踪 KPI（每季更新，六项）

| KPI | 阈值含义 |
|-----|---------|
| 组合出租率 | 写字楼 <90%、零售 <95% 视为需求转弱 |
| 续租租金变动（reversion） | 连续两期为负 = 租金周期下行确认 |
| 零售额增速（租户销售） | 领先于租金，下滑 2 个季度后租金才反映 |
| 净负债率 | 突破 30%/40% 触发股息政策讨论 |
| 利息覆盖 | <2x 触发红旗 |
| 在建项目预租率 | 落成前 12 个月 <40% = 悲观情景提前兑现 |

## 8. 常见错误清单

- ❌ 用报表归母或基本溢利算股息覆盖 → ✅ 必须拆到纯租金口径（§0）
- ❌ 把物业买卖交付的增长当成经常性增长 → ✅ 单列桥接表，交付年份不计入外推基数
- ❌ 用半年度 OCF/DPS 判股息危机 → ✅ 年度口径 + 三年平滑
- ❌ 只看现价股息率不看「落成后正常化股息率」→ ✅ 在建项目是增长的全部来源，必须前推
- ❌ 三情景只调出租率 → ✅ 出租率 + 单价 + 融资成本三项同时调整，否则情景无分歧
- ❌ 收租股用 PE/ROE 排名表 → ✅ 用 P/NAV（P/B 区间）、股息率、市值÷年租金、DDM
- ❌ 忽略利息资本化停止的时点 → ✅ 落成当年净利下滑是会计现象，必须在报告里说明
