# A股数据源实测清单（2026-09 宁德时代 300750 实战验证）

> 与 `hk-stock-data-sources.md`（港股）、`us-stock-data-sources.md`（美股）并列的 A 股版。全部端点当日实测通过。

## 1. 实时行情（双源交叉）

### 1.1 东财 push2 API（首选，字段最全）
```
https://push2.eastmoney.com/api/qt/stock/get?secid={secid}&fields=f43,f44,f45,f60,f84,f116,f117,f162,f167
```
- **secid 规则**：深市 `0.300750`、沪市 `1.600519`、港股 `116.03750`
- ⚠️ **字段 ×100 编码**：`f43` 现价 / `f60` 昨收 / `f44` 高 / `f45` 低 / `f162` PE(TTM) / `f167` PB → **全部 ÷100**（宁德：f43=30195→301.95，f162=1614→16.14x）
- `f116` 总市值 / `f117` 流通市值是**原始"元"** → ÷1e8 转亿；`f84` 总股本原始"股" → ÷1e8 转亿股
- **自检公式**：市值 ÷ 现价 = 总股本（宁德 13,972 亿 ÷ 301.95 = 46.27 亿股 ✓），对不上说明字段口径理解错了

### 1.2 腾讯 qt.gtimg.cn（备用+H股）
- A 股直接代码（`sh300750`），港股 `hk` 前缀（`hk03750`）；偶发返回空（`v_pv_none_match`）→ 重试或切东财
- 字段：`[3]` 现价、`[39]` PE(TTM)、`[44]` 总市值（亿）、`[47]/[48]` 52周高/低、`[30]` 时间戳
- ⚠️ **`[39]` PE(TTM) 字段口径不可直接引用**（新易盛 2026-10 实测报 39.41x vs 自算 TTM 33.5x——滚动窗口/股本口径不明），PE/PB 一律自算：市值÷TTM 净利、价格÷(归母权益÷股本)；`[44]` 市值字段可靠（新易盛 5,163.44 ≈ 自算 5,164 ✓）
- **总股本双重验证法**（腾讯无股本字段、push2 不可用时）：① 最新期净利÷EPS；② 市值÷价格。两法偏差 <1% 才采信（新易盛 13.97 vs 13.95 亿股 ✓）；EPS 反推顺带校验净利与 EPS 同源
- **A/H 溢价** = H股价 × HKD汇率（~0.9165）÷ A股价（宁德 507×0.9165÷301.95 ≈ **+54% 倒挂**）。传统认知是 A 溢价 H，遇到 H 溢价本身就是分析素材：收敛方向 = ±54%（H→A 收敛 = H股再跌；A→H 收敛 = A股 +54%）

### 1.3 新浪 hq.sinajs.cn
需特定 Referer，实测 403。优先级最低。

## 2. 财务三表（科目级）

### 2.1 首选：东财 F10 emweb API（实测可用）
```
https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/ZcfzbAjaxNew?companyType=4&reportDateType=0&reportType=1&dates=2026-06-30,2025-12-31&code=SZ300750
```
- 资产负债表 `ZcfzbAjaxNew`、现金流量表 `XjllbAjaxNew`、利润表 `LrbAjaxNew`（**三表全部实测可用，companyType=4 已在宁德/潍柴两例验证**；`dates` 参数支持 CSV 一次拉多年：`dates=2026-06-30,2025-12-31,2024-12-31,2023-12-31,2022-12-31` 一次拿五年序列，全程 <2 秒）
- 利润表关键字段：`TOTAL_OPERATE_INCOME / PARENT_NETPROFIT / DEDUCT_PARENT_NETPROFIT / FINANCE_EXPENSE`（FINANCE_EXPENSE 是汇兑损益诊断入口，见 SKILL.md 恒立"增收不增利"陷阱）
- 返回 JSON `data[]`，字段原始"元"：资产负债表 `MONETARYFUNDS/TRADE_FINASSET_NOTFVTPL/INVENTORY/ACCOUNTS_RECE/CONTRACT_LIAB/SHORT_LOAN/LONG_LOAN/BOND_PAYABLE/LEASE_LIAB/TOTAL_ASSETS/TOTAL_PARENT_EQUITY`；现金流 `NETCASH_OPERATE/CONSTRUCT_LONG_ASSET/ASSIGN_DIVIDEND_PORFIT`
- **有息负债** = SHORT_LOAN + LONG_LOAN + BOND_PAYABLE + **NONCURRENT_LIAB_1YEAR（一年内到期的非流动负债，易漏！）** + LEASE_LIAB（潍柴 2026H1：775.43 亿货币资金 − 325.2 亿有息 = 净现金 450 亿；漏 NONCURRENT_LIAB_1YEAR 会虚增净现金数十亿）；**净现金** = 货币资金+交易性金融资产−有息负债（宁德 4,403−1,271≈3,132亿，占市值 22%）

### 2.2 已验证的失败路径（勿浪费时间）
| 接口 | 症状 |
|------|------|
| datacenter-web `RPT_DMSK_FN_BALANCE` / `RPT_DMSK_FN_CASHFLOW` | HTTP 400 |
| akshare `stock_balance_sheet_by_report_em` / `stock_cash_flow_sheet_by_report_em` | 返回 None |
| akshare `stock_financial_abstract` | 能返回但科目数值单位混乱（"存货"显示 1.87），不可直接当亿元用 |

### 2.3 akshare 快路径
- **`stock_yjbb_em(date="20260630")`** 全市场业绩报表——中报窗口首选，一行拿齐：营收/净利同比 + EPS + 每股经营现金流 + 毛利率 + 净资产 + 披露日期。⚠️ "季度环比增长"字段是本报告期环比上一报告期 → 可反推单季：`Q1 = H1 ÷ (1+环比)`（宁德 Q1 净利 207.4 亿、Q2 225.4 亿，Q2 增速 37% < Q1 48% 的放缓信号就是这么拆出来的）
- **`stock_financial_analysis_indicator(symbol="300750", start_year="2018")`** 全历史指标序列（加权ROE/毛利率/净利率/资产负债率/EPS/每股OCF），中文列名，含最新中报
- **`stock_fhps_detail_em(symbol="300750")`** 分红送配明细：`现金分红-现金分红比例描述`（"10派69.57元"、"10转8派25.2元"）+ 除权除息日 + 总股本演变，10 期分红一次拿全

## 3. K线与含分红再投手算（A股版）

### 3.1 腾讯 fqkline 分段拉取（640 根/段）
```
https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh300750,day,{start},{end},640,{fq}
```
- fq 留空 = **不复权**（分红再投模拟用这个）；`"hfq"` = 后复权
- ⚠️ **hfq 会缺早期数据**：宁德请求 2018-06-01 起，hfq 只返回 2019-05-21 起（缺 220 个交易日）→ **"上市以来收益"不可依赖 hfq，必须用不复权 + 手算**
- 52 周高点**日期**定位：拉一年日 K，对最高价/收盘价取 argmax（宁德 H 股 high 794.5 = 2026-06-03、close 779.5 = 2026-06-02）——比只报 52 周区间更有信息量

### 3.2 分红再投模拟（含转增，A股特有）
- 事件表来自 `stock_fhps_detail_em`：每股派现 = "10派X" ÷ 10；转增比例 = "10转N"
- 腾讯不复权 K 在除权除息日收盘价已自动除权除息，模拟自动正确
- **含转增除权日的处理顺序（10转8派25.2 为例，顺序不能反）**：
  ```python
  cash = shares × 每股派现      # ① 先按转增前股数收现金
  shares *= 1.8                 # ② 再转增
  shares += cash ÷ 当日收盘     # ③ 分红按除权后价格再投
  ```
- **三口径输出**：
  - **纯价格收益（必须含转增）**：终值 = 1 IPO 股 × ∏(1+转增比例) × 现价 ÷ IPO价。宁德：1→1.8股 × 301.95 = 543.51 vs 25.9 = **+1998%**；直接用 301.95/25.9 = +1065% 是**错的**（漏转增，低估近一倍）
  - 落袋（分红不再投）：最终股数市值 + 沿途分红现金（转增后的"每10股派X"按转增后股数计）
  - **含分红再投**：模拟终值 ÷ IPO价（宁德 +2137%，8.27 年年化 45.6%）
- 转增是会计中性：再投收益 − 含转增纯价格收益 ≈ 分红增量贡献（宁德 +139pct；股价基数大时分红贡献占比低，与滨江服务类高息股相反）

### 2.4 中报深度稿来源（分部数据最全）
- **新黄河/济南时报（jinantimes.com.cn）**：区域媒体中报深度解读稿 urllib 直接抓取可用，分部收入/业绩率、一次性损益明细、经营数据（销量/GWh）比快讯类稿全一个量级（潍柴实战：发动机分部 373.10 亿/+14.9%、分部业绩 −2.1%、巴拉德处置损益 13.27 亿全部出自该稿）。财经媒体深度稿 > 快讯稿，抓取前先试区域大报。

## 4. A/H 两地上市检查点
- 总股本核实：中报披露总股本 vs 腾讯字段；年内 H 股配售会改变股本（宁德 45.64→46.27 亿股）——**DCF 每股值与分母必须用最新股本**，旧报告股本作废
- **A+H 拆分口径**：总股本 = A 股股本 + H 股股本（潍柴 86.40 = A 66.97 + H 19.43 亿股），**市值须混合口径** = A股股数×A股价 + H股股数×H股价×汇率（潍柴 2,319 亿）；全按 A 股价会高估 ~2-3%，必须在报告注明口径
- **AH 比价 ≈ 1 的信息含量**：潍柴 0.989 平价（对比宁德 H 溢价 +54%）——平价意味着 A 股定价已充分悲观、两地投资者对基本面分歧极小，H 股不再是"折价备份"
- A/H 溢价的两个方向都要写进风险/机会清单（芒格之问："凭什么确定犯错的是对面那个人"）
