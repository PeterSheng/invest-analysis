# 折现率落差分析 · 前轮口径审计 · 贴现惯例声明

> 沉淀于 POOL 2026-11-06 第三轮重析（前两轮 202606 首轮、202608-19 综合 3.19）。适用任何「统一 WACC 10% 下三情景 IV 全线低于现价」的质量型公司。

## §1 双折现率对照法（02-巴菲特报告必含模块）

**触发条件**：统一 WACC 10% / tg 3% 跑出的三情景 IV 全部低于现价，且基准情景安全边际 ≤ -20%。此时**禁止回调参数迁就现价**，改用"双折现率对照"把落差翻译成市场语言。

**做法**（同一套 FCF 路径、净债、股本，只换 WACC）：

| 列 | 内容 |
|---|---|
| 口径 | 本轮统一口径（WACC 10%）／市场隐含口径（WACC 8.5% 教科书值或从现价反解） |
| IV | 两个数并列 |
| vs 现价 | 分别给安全边际 |
| 读法 | 一句话：差额的**唯一来源**是折现率，不是盈利预测或净债 |

**POOL 实测**：WACC 10% → IV $154（-26%）；WACC 8.5% → IV $207（≈ 现价 $208.82）。**Δ1.5pct WACC = $53/股 = 26%**。三情景（120.7 / 154 / 187）与反向 DCF 隐含 g 6.95%（2019-25 实际 FCF CAGR 仅 4.8%）构成三角交叉验证，指向同一结论。

**结论语言模板**（可直接复用）：
> 它没有泡沫，只是**精确地贵在折现率上**。现价买入的人赌的不是"这家公司会更好"，而是"市场愿意永远用 8.5% 给一家毛利率在跌的分销商打折现"。

**纪律**：①基准 IV 与操作锚（击球区/重仓线）**只用 10% 口径**，8.5% 口径只作翻译器；②不得用它论证"现价合理"；③若反向 DCF 隐含增速 > 历史实际增速 1.5 倍以上，写入正文作"市场已付全款"的证据。

## §2 重析轮前轮口径审计三查（核对表固定加行）

**查一：派生结论用自己的算式重算。** 前轮报告的终值倍数法/年化回报/隐含增速，必须拿它**自己给出的算式**代回去。POOL 上轮写"20 年年化 8-10%"，按其自身算式（EPS $31 × 15x + 累计股息 $150 = $615，3.28x over 20y）实为 **6.1%**——表内不自洽即 🔴，本轮统一为 5.9-6.7% 并在审计小节披露。

**查二：前轮参数所处的 regime 时点。** 全局参数变更（如 2026-11-04 起 WACC 8.5%→10%）之后写入的历史报告可能仍是旧口径。POOL 上轮 IV $215 即 WACC 8.5% 的产物（统一后同参数为 $159）——**重析轮 IV"下降"必须先拆成三块**：口径变更（-$56）+ 净债改善 1660→1409（+$7）+ 价格与增速假设变动，否则会把口径差误读成基本面恶化。

**查三：上轮击球区是否被触及（含窗口天数）。** 拉日线/52 周区间，核对上轮给的买入区间有没有真的被市场送到。POOL：上轮击球区 $155-175，**2026-10-08 最低 $152.70 精确命中**，但窗口仅约 3 周，此后财报 +14.36% 起算一个月 **+43.7%**（11/4 $219.26）。核对表固定行：`上轮击球区触发 | 触发日 / 区间最低价 / 窗口天数 / 此后涨跌`——命中=上轮方法论加分，窗口过短=强度不足，两者都要写。

**查四：首轮报告的每个"每股倍数"都用原始三表重算一次。** 首轮若只交了一份综合报告、没有 00-数据包，倍数几乎都是二手转述或反推，极易整组错位。BRO 2026-11 重析实测四连错：前向 P/E 11.4x → **14.3x**、FCF 收益率 8.3% → **6.2%**、P/B 3.60x → **1.87x**、ROE 19.3% → **9.5%**。根因：拿"价格 ÷ 首轮 P/E"反解出一个隐含 EPS $5.56，而共识调整后 EPS 只有 $4.44——**反推自身的比率等于把错误自乘一遍**。硬规则：① EPS 只用两种来源（NI ÷ 稀释股本，或公司新闻稿调整后 EPS 披露）；② 市值 = 价格 × 股本、净债务只用自有现金、ROE 用期初期末平均权益；③ 重算结果与前轮差 >15% 的每一格都进重析勘误表并解释口径，不静默替换；④ 评分下调必须能拆成"价格变了"与"预期变了"两块（BRO 3.31→3.06 = 股价 +13.3% 与 EPS -20% 双向挤压安全边际）。

## §3 贴现惯例声明（一行解决，不重算六份文件）

每轮 00-数据包必须写完整模型规格（WACC / tg / **贴现惯例 年末 or 年中** / 衰减公式段数与终点 / FCF0 归一化基础 / 净现金构成 / 股本）。若同月其他报告换了惯例（如 202611 谷歌用年中），**不要为此重算本报告全部 IV 与评分**，而是在 02 报告加一行声明并给换算：

> 本轮采用**年末贴现**（与 templates 一致）。若改年中贴现（×1.1^0.5 = 1.0488），基准 IV = $161.5、保守 $126.6、乐观 $196.1——仍全线低于现价，结论不变。

换算系数按 WACC 而定（10% → 1.0488；8% → 1.0392）；**禁止不同惯例的两个数字直接跨轮比较**。

## §4 毛利率下滑的"周期 vs 结构"拆分（分销商/批发商专用）

毛利下滑必须逐项标注**可逆/不可逆**，只对可逆项给回升假设：
- POOL Q3'26 毛利率 29.0%（-60bp）：运费（周期，可逆）+ **National accounts/大客户占比提升（结构，不可逆）**——后者随"高增速低毛利渠道"扩大而持续稀释。
- 结构性项要做**侵蚀敏感性**：净利率每年 -20~30bp → 2028 年 7.2%（非 7.9%）→ IV 从 $154 掉到 ~$130，现价溢价扩大到 60%。
- 跟踪交集变量＝**大客户占比 × 整体毛利率联动**（POOL National accounts 增速 +7%）；这是"越增长越不值钱"的唯一入口。

旁证：同一价值链上 LESL（泳池零售）已归零 $0.055/市值 $0.66M、HAYW/WSO 21-27x，分销端 POOL 19x TTM——零售端清零是最有力的护城河证据，也是最贵的证据（`references/cyclical-business-modeling.md` 渠道分销商段）。

## §6 高 β 标的的 WACC 双口径（风险匹配 vs 横向可比）

> 沉淀于 AppLovin APP 2026-11 重析轮。**这是 SKILL.md「DCF 统一参数 10%」的唯一例外条款来源**——统一口径的例外只有一个方向：往上。

**触发条件**（命中其一即启用）：β ≥ 1.8；单客户/单平台/单渠道高度集中；存在二元监管结局（诉讼-罚款、牌照、平台规则、SEC 调查）；市值中相当比例为尚未兑现的叙事期权。

**为什么必须例外**：10% 对这类标的**不是"偏保守"，而是反向失真**——同一把尺子会把最危险的生意量成最便宜的。§1 是"10% 算出全线低于现价 → 用 8.5% 翻译市场在为什么付钱"；§6 是"10% 算出全线高于现价 → 必须用 13% 才说得出真实赔率"。两个方向相反，**不可混用**。

**做法五步**：

| 步骤 | 内容 |
|---|---|
| ① 横向锚 | 统一 WACC 10% / tg 3% 照跑一遍，结果进评分总表与库内 60+ 家同标尺排名——**10% 的职责是可比较，不是定价** |
| ② 主口径 | CAPM 风险匹配 WACC ＝ **当日 10Y 国债**（财政部 CSV，见 §5，禁凭记忆）+ **β×ERP(4.5–5.5%)**；β 取 5 年月度回归；上界用同业资本成本校验，**下界不低于 10%** |
| ③ 双声明 | 报告头部 + `00-数据包` 模型规格写明两套 WACC 与其职责（APP 实战：**13% 主结论 / 10% 横向对照**）；tg 仍统一 3%，三情景仍只调 g1/g2 |
| ④ 跟口径 | 击球区、操作阶梯、巴菲特安全边际评分 → 跟**主口径**；评分总表排名 → 跟 10% |
| ⑤ 矛盾呈现 | 两口径方向矛盾时（13% 说贵、10% 说便宜）以主口径为准，并把矛盾写成一句话结论：**"市场为叙事付的是 beta 折价，不是质量溢价"** |

**纪律三条**：①同一情景内不换 WACC（否则就是被禁止的"乐观情景配低 WACC"）——换的是"整个模型的风险标签"，不是某一个情景；②高 β **只准往上调**，低 β 类公用事业/REIT/收费资产的向下敏感性仍按 §1 只作翻译器、不作定价依据；③不同标的的风险匹配 WACC（如 13% vs 银行股 10.5%）**禁止跨标的直接比较估值倍数**——它们是不同风险的价格标签，不是同一个尺子。

**可复用结论文档**：`本轮主口径 WACC 13%（Rf {当日10Y} + β {β} × ERP {ERP}）；统一 10% 口径下 IV 高估约 {x}%，仅供与库内标的横向对照，不构成"便宜"的证据。`

## §7 双方法裂口：FCFF/WACC 与 FCFE/Ke 分歧的解读（FICO 2026-11-08 第三轮）

§1 管「同一套现金流、换折现率」；**§7 管「两套现金流、两套折现率给出彼此无法同时成立的答案」**——两者都必须用以翻译市场定价，不是用来挑一个好看的数字。

**触发实例**：FICO 同一批输入，FCFF/WACC 10% 三情景概率加权 → 股权 IV **$419**（-40%）；FCFE/Ke 10.5% → **$661**（-6%）。裂口 **58%**，远超正常口径差（±10%）。

**诊断三步（先归因，再谈选谁）**：

| 步 | 检查项 | 为什么这步最关键 |
|---|---|---|
| ① 杠杆放大 | FCFF 先算 EV 再整笔扣净债务 → 负权益/高杠杆公司（FICO 权益 -$3,873M）在 WACC +1pct 时 EV 掉 20%+ 而扣减项不变（双杀）；FCFE 已扣税后利息，杠杆只体现在 Ke | 裂口的一半来自「净债务扣减是一次性整付、折现却在逐年放大」的时间错配 |
| ② 折现率不再同义 | WACC 10% vs Ke 10.5% 在 3–4x 杠杆下对应的股权风险完全不同（Ke ≈ WACC + (WACC−Kd)×D/E 的镜像） | 两个数字看着接近 ≠ 在量同一个风险 |
| ③ 税盾归属 | FCFF 用税后 EBIT（含税盾）、FCFE 已扣实际利息——税盾被算一次还是两次须逐行核 | 双重计税盾会系统性抬高 FCFE 一侧 |

**判读语言（三段缺一不可）**：①"裂口不在生意，在杠杆如何被折现"；②两法**必须并列呈现，禁止择一静默**；③操作锚取保守端（FCFF）算安全边际、FCFE 只作"若风险溢价下行"的上界——FICO：即便取上界 $661，现价 $704.55 仍无安全边际，结论方向不变。

**纪律**：①裂口 >30% 必在 02 报告新增一段"为什么两把尺子差这么多"，不能把两个 IV 丢给读者自己猜；②裂口 >50% 时先怀疑口径错（股本/净债/一次性项），FICO 首版用全年加权股数 22.99M 而非 Q4 稀释 21.56M，单此一项 6.9%（见 `negative-equity-buyback-machine-analysis.md` §8.3）——口径修完再谈裂口；③裂口方向与价格方向矛盾（一法说贵、一法说接近合理）时，把矛盾本身写进巴菲特"安全边际"结论，而不是取平均。
