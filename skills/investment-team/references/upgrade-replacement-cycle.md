# 换代周期分析框架（设备更新/升级替换周期）

> 适用行业：安防视频监控、电网/电力设备、工程机械、家电、汽车零部件等存在"设备寿命 × 技术代际"双周期的行业。
> 来源：2026-08 海康威视实战（05-安防更新换代周期专项分析）。触发场景：用户问"是否已到 XX 换代/替换/更新周期""设备更新政策影响"。产出：`05-{行业}换代周期专项分析.md`。

## 1. 双周期机制（分析总纲）
- **设备寿命周期（存量替换刚需底）**：设备设计寿命决定"坏一台换一台"的基本盘。年均替换量 ≈ 存量 ÷ 平均寿命。关键洞察：**N 年前的建设高峰期 → 现在的集中替换窗口**（安防：2016-2020 雪亮工程/平安城市高峰 → 2026-2028 替换窗口；摄像头寿命 5-8 年，中国存量 3-4 亿台）。
- **技术代际周期（升级弹性顶）**：每 4-6 年一轮代际切换（安防：模拟→IP→高清→AI→大模型），每轮要求换设备，单价抬升 30-50%。新代际渗透率低 = 升级空间大（AI 摄像机渗透率仅 15-25%）。

## 2. 周期位置判断四步法
1. **历史建设高峰定位**：找到上一轮大规模建设期，计算其设备进入寿命替换窗口的时间
2. **技术代际定位**：当前处于哪一代切换期？新代际渗透率多少（早期/加速/成熟）？
3. **政策催化确认**：设备更新/以旧换新政策与国债资金是否落地（2024 年 3 月国务院《推动大规模设备更新和消费品以旧换新行动方案》+ 3000 亿超长期特别国债，"两新"2025 加力扩围）
4. **财报验证**：龙头公司是否出现量价齐升信号（见下）

## 3. 财报验证信号（换代周期启动的先行指标）
| 信号 | 含义 |
|------|------|
| 政府/公共部门业务增速转正 | 周期"总开关"（安防 PBG、电网国网招标）——最关键 |
| 毛利率连续提升 | 新品占比提升 + 价格战缓和 = 量价齐升 |
| 渠道/中小企业业务高弹性 | 换代需求向渠道端扩散（安防 SMBG +13.55%） |
| 扣非净利连续多季正增长 | 盈利质量拐点确认 |
| 配套业务放量（存储/配件） | 换代配套需求先行（海康存储 +88%） |

## 4. 量化测算
替换市场规模 = 存量 × (1/寿命) × 替换单价 × 公司份额
- 三情景：存量、单价、份额各做保守/中性/乐观
- 对比公司该板块收入占比 → 判断弹性是边际性（<10%）还是实质性（17-43%）
- 业绩路径：启动期（+8%）→ 加速期/替换高峰（+15-20%）→ 高峰延续

## 5. 证伪信号清单（出现即重估）
1. 政府端业务增速再度转负且连续 2 季
2. 毛利率连续 2 季环比回落 >1.5pct（价格战重启）
3. 竞争对手大幅降价抢份额（份额战替代升级战）
4. 制裁/政策黑天鹅中断海外替换需求

## 6. 投资含义（重要）
- **换代周期 ≠ 无脑买入**：周期启动常被提前定价（海康 2026-08：PE-TTM 20.9x，DCF 三情景安全边际 -8%~-26%）
- 正确用法：确认启动 → 跟踪加速信号（替换高峰在 1-2 年后）→ 价格给足安全边际时上车
- 周期弹性兑现后，当前市值对应远期 PE 显著下降——盈利上修是核心引擎
- 跟踪指标体系：季度分部增速、毛利率方向、行业招标额、竞争对手定价行为
