# 高端品牌服饰/运动休闲（premium branded apparel）分析框架

适用：LULU（lululemon）、NKE、DECK、ONON、CROX、ANF、SKX 等「品牌溢价 + 直营为主 + 高毛利 + 高 ROIC」的服饰/鞋类公司。
核心矛盾一句话：**这类公司的高 ROIC 从来不是资产属性，而是定价权的函数——一旦需求退潮，同一个资产负债表会立刻变成负经营杠杆机器。**

---

## §1 一次性项还原：先做毛利率桥，再谈"产品力"

服饰公司最常见的年度一次性项是**关税退款**（IEEPA 类）与**汇兑**，两者都会直接抬高毛利率而不动收入。

- 固定动作：`报表毛利率 → 剔一次性项 → 产品毛利率（可比口径）`。LULU FY2026 报表毛利率 58.7%（+560bp），剔除 $134.5M 关税退款后产品毛利率同比 **-130bp**。
- 判读公式：**一次性退款是"账面故事"，产品毛利率降幅才是"定价故事"**。当报告同时出现"毛利率创新高"与"降价的新闻"时，先拆桥，否则会把让利读成提价成功。
- PE 三口径并列，命名固定：`TTM 报表 PE`（含退款）/ `FY 还原 PE`（剔除）/ `FY+1 一致预期 PE`。LULU 2026-11：10.2x / 17.0x / 17.5x。**结论语言：「便宜在 trailing，贵在 forward」**——这类公司的 TTM 低估几乎全部来自一次性项与库存回冲，不能当估值锚。

## §2 所有者收益与回购可持续性（巴菲特视角的记账法）

1. **所有者收益 = FCF − SBC**（服饰公司 SBC 通常占 FCF 10-15%，LULU FY26 FCF $686M / NI $696M ≈1.06x）。FCF/NI ≈1 是健康信号，但回购与 SBC 必须相减后才是净返还。
2. **回购三算**：`回购/FCF`、`回购/所有者收益`、`授权余额可续月数 = 剩余授权 ÷ (年化回购/12)`。LULU 2026 年前三季 $620M ≈ 86% FCF、剩余授权仅 $386M ≈ 可续 **10 个月** → 结论「回购是 2026 的 EPS 支撑，不是 2027 的」。
3. **净现金叙事要修正**：服饰零售商常有「无有息负债」但**租赁负债巨大**。同时给 `净现金` 与 `净现金 − 租赁负债`（LULU −$53M，基本净中性）。「零债务」标签在这种资产结构下不成立。
4. **现金变动必须逐行拆**：期初现金 + OCF − capex − 回购 − 股息 = 期末，差额进「其他」，禁止用"现金充裕"含糊过去（LULU H1 $1,331M → $1,048M 是回购 $452M + 到期债务 $190M 的结果）。
5. **私有化视角**（该板块 2025-26 反复出现 take-private 传闻）：`EV/EBITDA ≈5.7x` 看似"捡钱"，但 EBITDA 不是所有者收益——维护性 capex 与租赁租金必须扣；私有化买家看的是「品牌能否撑住 3-5 年不动毛利率」，不是倍数。

## §3 品牌溢价被稀释的三个可观测信号（比同店更早）

| 信号 | 算法 | 阈值 |
|------|------|------|
| **其他渠道占比上升** | (奥莱/批发/临时店/折扣渠道收入) ÷ 总收入，逐年 | 11.0% → 12.7%（LULU FY26）＝ 品牌在为正价渠道买不到的量找出口，**折扣渗透的第一指纹** |
| **产品毛利率（剔一次性）** | 见 §1 | 单年 -100bp 以上且伴随降价/促销 = 定价权下移 |
| **库存单位数 vs 金额** | 单位数增速 − 金额增速 | 金额增、单位降 ＝ 主动去库存（好）；单位增、金额降 ＝ 降价清货（坏） |

LULU FY2026：库存 **+7% 金额 / −1% 单位** ＝ 主动去库存 ✓，但同时库存减值 $79M（+57%）＋降价，说明去库存靠让利完成——**"健康动作"与"品牌损伤"同时成立，两个都要写**。

## §4 需求退潮的三降拆解（10-Q/10-K 原文口径）

- 固定三段：`客流(transactions) / 转化率(conversion) / 客单价(ticket)` 各降多少、公司自述归因。LULU Q3 FY26：-2% / -3% / -1%，自述"产品生命周期偏短、消费者对新品反应谨慎"（**公司自认产品力问题 > 宏观借口**）。
- 区域拆分必须与开店分开看：`区域收入增长 = 同店 + 新店`。美洲同店 -5%（客流 -4.4%）/ 国际 +20% / 中国 +42%——**国际高增速是开店驱动，不是同店驱动**，把它当"品牌全球化"会把资本开支读成需求。
- 开店口径陷阱：FY2026 美洲净开 35 家直营店 + 翻新 38 家，**用新店面积撑收入、用翻新掩盖同店下滑**是这一板块的标准操作，必须点明。

## §5 负经营杠杆量化（本框架的核心一击）

服饰品牌是「固定成本前置、毛利后置」的生意：租赁 + 人力 + 营销在收入之前发生。

- 公式：`ΔEBIT / ΔRevenue（弹性）`。LULU：收入基本走平（+5%）而 EBIT 从 $2,210M 滑到 TTM 还原 $1,710M ＝ **-22.6%**，弹性趋于无穷（分母≈0）。
- 结论语言：「高 ROIC 是收入不下降才成立的伪稳定」。同类可对照：NKE FY2025 EBIT 弹性、DECK 的批发出清。
- 必须补一句反身性：负杠杆的另一面是**正杠杆**——收入一旦恢复 3-5%，EBIT 会以 2-3 倍弹性回来。这是"周期股化"的品牌股唯一的多头论据，也是三情景乐观档的依据。

## §6 估值三件套（统一 WACC 10% / tg 3% 口径下）

1. **三情景 DCF**：g1 只调收入增速档（乐观 = 正杠杆回归 / 中性 = 低个位数修复 / 悲观 = 品牌稀释延续），不调折现率。
2. **反向 DCF 的"低门槛"语言**：现价隐含 10 年 FCF **CAGR ≈ +1%**（LULU 2026-11 @ $167.4）＝ 市场几乎不为增长付费，只要求"不再恶化"。这种读法比"贵/便宜"有力：**现价不需要信仰，只需要不再退潮**。
3. **IV 桥（唯一可解释的桥）**：`IV 跌幅 ÷ 股价跌幅`。LULU 中性 IV $231（-20%）而股价自 52 周高跌 -45% → **倍数 2.2x，跌幅是 IV 的 2.2 倍**，说明市场在惩罚"品牌溢价稀释"这一非现金流变量。
4. **敏感性矩阵必须自带判决句**：若矩阵只在 WACC ≤9% 假设下成立 → 直写「安全边际依赖于折现率假设」，禁止把最宽松格当基准。

## §7 巴菲特式判读语言模板（本类标的的"一句话结论"）

- 「品牌是真的，护城河是真的，**但以合理价格买入优秀公司的那个价格已经消失了**」——好生意 ≠ 任何时候都值得买，价格优势消失就够降一星。
- 「不是资产属性给了它高 ROIC，是定价权给了它高 ROIC；而定价权正在被自己的折扣渠道稀释」
- 「现金很好、库存诚实——**问题不在报表，在货架**」（报表干净 + 品牌受伤并存时的标准表述）
