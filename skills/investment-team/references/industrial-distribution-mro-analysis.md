# 工业分销 / MRO 渠道商分析框架

> 适用范围：**维护、维修与运行（MRO）产品分销商**与相邻的工业/建材/泳池批发分销商。
> 实证锚点：固安捷 W.W. Grainger（GWW，2026-11-08 首轮，综合 3.25）、快扣 Snap-on（SNA，2026-10-16，3.75）、快扣 Fastenal（FAST，同业对照）、POOL（2026-08 系列）、MSM / AIT / WCC / GPC 等行业对照。
> 与 `cyclical-business-modeling.md`「渠道分销商/批发商专项」分工：彼文管**库存周期与 OCF 镜子**，本文管**MRO 商业模式、单位经济、护城河与估值语言**。

## 1. 生意本质：卖的不是螺丝和手套，是「设备不停机的保险」

| 维度 | MRO 分销商的真实卖点 |
|------|---------------------|
| 客户买的 | 不是最低单价，而是**停机风险的最小化**（一条产线停 1 小时 ≫ 一年耗材差价） |
| 收入结构 | 长尾 SKU（数十万至数百万 SKU）× 小额高频订单 × 上千客户 |
| 定价权来源 | 目录价（list price）与实付价（net price）之间的**价差管理**，而非成本领先 |
| 周期性 | 需求 = 存量工业资产的「维护税」，随**工业产出/产能利用率**波动，但幅度小于资本品订单 |

一句话：**它是存量工业文明的收租人，租约写在客户的停机成本里。**

## 2. 双引擎商业模式（GWW 范式，其他公司按此光谱定位）

| 引擎 | 特征 | GWW 实例 | 单位经济 |
|------|------|----------|----------|
| **High-Touch Solutions（HTS，高接触）** | 分支网络 + 驻场/合约客户 + 大客户经理，服务成本高、客单价与粘性高 | 北美为主，合约客户占大头 | 毛利率高、SG&A 重、营业利润率中等 |
| **Endless Assortment（EA，无限货架）** | 线上长尾 + 无门店成本，靠流量与算法做「小客户的长尾」 | 含 MonotaRO（日本）等非北美业务 | 毛利率低、履约成本主导、营业利润率薄但资本回报高 |

**判别要点**：HTS 的护城河是「人 + 库存就在客户 30 分钟车程内」；EA 的护城河是「SKU 宽度 + 履约成本」。两者混在一起看会得出错误结论——**分部增速与分部利润率的错配是这类公司最常见的叙事裂缝**（同 `upc-pe-sponsored-ipo-analysis.md` 的「增长引擎 vs 利润引擎」判据）。

## 3. 必算 KPI（不分市场通用）

| KPI | 算法/口径 | 判读 |
|-----|-----------|------|
| **价/成本剪刀差（price/cost spread）** | 售价同比 vs 产品成本同比（公司常披露） | 持续正数 = 定价权；转负 = 让价抢量，护城河松动第一信号 |
| **DA 客户数（Daily/Account 客户数与大客户渗透）** | 公司月度/季度运营披露 | MRO 的份额指标：DA 客户数下滑而营收靠提价撑 = 危险组合 |
| **SKU 宽度 × 库存周转** | 库存/COGS × 365 | MRO 天然低周转（>90 天正常）；周转骤降 = 备货过度或需求转弱 |
| **自有品牌渗透率** | 自有品牌收入占比 | 提升 = 毛利率护城河加深；停滞 = 靠供应商返利撑利润 |
| **营业利润率阶梯** | 分部 OP margin 分列 | HTS 与 EA 的 OP margin 差距是模式语言，不可合并成一个数 |
| **ROIC（含商誉）** | NOPAT /（净债 + 权益） | MRO 轻资产，健康区间 15–35%；**ROIC 是质量锚，ROE 不是**（见 §5） |
| **现金转换周期 CCC** | DIO + DSO − DPO | 强势分销商 DPO > DSO 是常态（用供应商的钱做库存） |
| **有息负债口径** | 短期银行借款 + 透支 + 长期债 + 租赁（按用户定制口径，分开列示） | MRO 应为净现金或低杠杆（GWW 净债 ≈0.69x EBITDA）；净债急升通常对应收购 |

## 4. 一次性项与会计陷阱

1. **关税退款（IEEPA 等）计入成本冲回**：GWW 2026 轮识别出 $43M IEEPA 关税退款一次性抬高毛利率——凡毛利率同比跳升 >100bp 且同期有贸易政策变动，先查退款/关税返还，再做「剔除后」毛利率。
2. **LIFO/FIFO 与通胀**：通胀期 LIFO 清算（LIFO liquidation）会人为增厚毛利，须看公司披露的 LIFO 影响。
3. **供应商返利（volume rebates）跨期**：返利计入 COGS 的期间错配会摆动单季毛利率，看年度口径。
4. **收购摊销**：分销商收购标的常为小品牌/区域商，无形摊销压低 GAAP 营业利润率 → 双口径（GAAP vs adjusted）并读（同 `us-stock-data-sources.md` §2.9 纪律）。
5. **回购压缩权益**：长期回购会让 ROE 结构性强于真实回报（GWW 五年回购约 8.4% 股本），与 `negative-equity-buyback-machine-analysis.md` 同型。

## 5. ROE 高 ≠ 好：MRO 的 ROE 失真三源

GWW 报表 ROE 约 52%、资产周转 2.04x、商誉仅占总资产约 5%：
- 高 ROE 来自**高周转 × 轻资产 × 回购缩表**，而**不是高净利率**（营业利润率仅约 15.9%，毛利率约 39.4%）；
- **PE/ROE 排名表对 MRO 是误导指标**——必须改用 **ROIC / EV-EBITDA / 反向 DCF** 为主锚；
- 对比 FAST（毛利率约 45.0%、营业利润率约 20.2%、ROE 约 35.3%、ROIC 约 32.6%）：**FAST 赚的是毛利，GWW 赚的是周转**，两者 ROE 差异主要来自资本结构而非生意优劣。

## 6. 估值语言：为什么统一 WACC 10% 下这类公司全线为负

MRO 是「质量溢价」行业，市场长期按低折现率定价：

| 工具 | GWW 2026-11-06 实测（现价 $1,440.70） |
|------|------------------------------------|
| Fwd PE | 28.2x（FAST 38.3x） |
| EV/EBITDA | 20.8x（FAST 29.9x） |
| DCF（WACC 10%/tg 3%，FCF0 ≈$1.78B、净债 ≈$2.3B、股本 ≈46.8M） | 悲观 $502 / 中性 $645 / 乐观 $790，概率加权 ≈$646（**-55.2%**） |
| 反推隐含 WACC | ≈6.34%（现价对应的折现率，不是模型参数） |
| 反推隐含十年 FCF 复合增速 | ≈+16.2% |
| 五年持有 IRR（EPS/FCF 路径法） | ≈+5.7% |

**结论写法（三件套，不要只报一个 IV）**：
1. 10% 口径 IV 全线低于现价 → 用「**市场付的是质量溢价倍数**」语言，**禁止回调 WACC 迁就现价**；
2. 再用**反推隐含 WACC / 隐含增速 / 五年 IRR** 把「贵多少」翻译成「市场假设了什么」；
3. 需要「翻译器」时按 `discount-rate-gap-analysis.md` 跑一遍市场隐含 WACC，明确只作对照、不作操作锚。

击球区用法（GWW 案例）：加权 IV 与「Fwd PE 回到 20–22x」两条线取交集 → **$900–1,050**，现价维持「好生意 + 坏价格，不买也不做空」。

## 7. 芒格失败路径清单（MRO 版）

| 路径 | 机制 | 观测信号 |
|------|------|----------|
| 价格透明化 | Amazon Business / 电商比价削平 list-vs-net 价差 | price/cost spread 转负、DA 客户流失 |
| 客户自建 VMI/寄售 | 大客户整合供应商，绕过分销层 | 大客户合约续约价、HTS 客户数停滞 |
| 工业产出下行 | 产能利用率 ↓ → 维护性支出被延后 | 月度 IP/PMI、SKU 动销、库存周转拉长 |
| 关税/政策回吐 | 一次性成本利好消失 + 采购成本上升 | 剔除一次性后毛利率环比 |
| 收购摊薄回报 | 高倍数收购区域商拉低 ROIC | 商誉/总资产上升、ROIC 下穿 WACC |
| 估值均值回归 | 质量溢价倍数压缩（无需基本面恶化） | Fwd PE 从 28x → 20x 即 -29% |
