# 管理式医疗 + PBM 混合体分析框架

> 2026-10 信诺 Cigna (CI) 实战沉淀。适用：CI/UNH/Humana/CVS/ELV 及任何"保险承保 + 药品中间商"混合体。完整数据包样例见 repo `reports/202610/信诺CI/00-数据包.md`。

## 1. 三层生意光谱（先拆层再估值）

| 层 | 本质 | 护城河 | 主要风险 |
|----|------|--------|---------|
| 承保（MA/团险） | 政府定价过路费 | 规模+渠道 | MCR 失血、星级下调、政策摇摆 |
| PBM（Express Scripts/Caremark/OptumRx） | 管道抽成（信息不透明的钱） | 80% 三巨头寡头 | delinking 立法、FTC、客户垂直整合 |
| specialty 分发（Accredo 等） | 河段产权（独占分发，"没我不行"） | 有限分销权+临床服务 | IRA 药价谈判挤压 |

判别信号：**增收不增利**（CI Evernorth 营收+16% vs 利润+3%）= 护城河在"渗水"而非塌方；**利润端先收缩的指引**（Evernorth 2026 指引 $6.9B < 2025 实际 $7.2B）= 管理层自认周期下行，是全年 EPS 指引可信度的核心检验点。

## 2. MCR 三点轨迹法（承保层核心变量）

- 单点 MCR 无意义：CI FY25 82.4% → 26Q1 79.8% → 26Q2 84.5%（Q1 是低点不是趋势，禁止拿 Q1 外推）
- 全年指引带 = 红线：CI 83.7-84.7%，**单季 >85% = 四大师评分全线下修**
- MCR 是"交集变量"判别法：同一数字被多位大师反向解读时（巴菲特读"FCF 深度保护"、芒格读"MCR 失血下未必守得住"），该数字即跟踪清单第一行——谁动了它所有人都重评

## 3. PBM 层结构与尾部

- 格局：Caremark + Express Scripts + OptumRx 合计 **80%**（FTC 口径）；**2024 Express Scripts 借 Centene 协议登顶**（DCI/Adam Fein）
- 监管：FTC 2024 起诉三大 PBM（胰岛素 formulary 排除案）；批评口径 PBM 年抽成 ~$116B
- **delinking 立法 = 第一尾部**：抽成商→透明服务费商的重估问题，终极一问的天然素材
- 行业结构小节补丁模式（李录 TAM 数据合规获取）：主会话 web_search 验证 → patch 进数据包新增行业小节（信诺 §4.1 模式：PBM 80% 三巨头 / specialty >50% / ~$5T 医疗盘子 / 仿制药节约 $496B）→ 再派发子代理；行业数字禁止直接写进 prompt

## 4. 垂直整合"慢刀子"（vs 政策"单点雷"）

两类侵蚀，速度与可逆性不同：
- **单点雷**（政策）：delinking 通过瞬间重估，但概率可跟踪、可对冲
- **慢刀子**（客户绕开）：UNH/Optum 自建 PBM、大客户多年期比价迁移——不可逆、报表最后反映、DCF 分母慢性下移。CI 实战：芒格认为慢刀子比政策雷更致命
- OptumRx 型（客户即母公司）= 结构优势；独立 PBM 的大客户自建 = 最危险路径
- 识别：PBM 客户合同到期日历 + 大客户年报"药房服务自营"表述

## 5. 估值口径（本类公司专用）

- **调整 vs GAAP 双口径并存**：无形摊销差 ~$1.2B（CI 2026E 调整 $8.05B vs GAAP TTM $6.42B）；模型用 GAAP、估值锚用调整，每个数字引用必带口径标签
- **负有形权益分级处理，不要一刀切**：权益为正但商誉占权益 >100%（CI 商誉 $45.5B+无形 $26.9B vs 权益 $42.9B）→ PB **可用但打八折**；权益为负（SPGI/MTD/LAMR）→ PB/ROE 禁用改锚 ROA/ROIC/P-FCF
- 承保商 PE 低是常态（CI 12.6x GAAP / 10x 调整），估值语言重心放**反向 DCF**：
  - 零增长锚 = FCF/WACC 扣净债（CI $261-286；现价高于锚 7-17% = 市场既不为零增长买单也没定价增长）
  - **隐含 g1 为负（CI -5.1%）vs 公司指引 10-14% = 市场定价"利润连续收缩"**——15-19pct 预期差是最大赔率来源
  - 隐含可持续 FCF（CI $9,348M = TTM 的 103%，"增长白送"）与隐含 IRR（15%）并列呈现
- PB-ROE 残余收益三档交叉验证（CI 悲观 13%→$323 / GAAP 15%→$404 / 调整 19%→$566）
- 情景跨度本身是信息：CI 四情景 $105-949（9 倍跨度）= 离散型政策风险，必须报概率加权而非单点 IV

## 6. 六条失败路径模板（芒格视角起点）

① PBM delinking 立法 ② MA 星级/v28 + 止损险重定价失血 ③ IRA 药价谈判挤压 specialty ④ 客户垂直整合绕开 ⑤ 全年指引 miss（H2 隐含残差法：全年指引 − H1 已实现 = H2 隐含需求）⑥ 负有形权益 + 承保周期双击挤压回购
每条：主观概率 + 影响 + 触发条件。激励偏差必查：重组/指引公告择时（股价低位）、CEO 长任期与并购遗产的利益捆绑。

## 9. UNH 实战补充（2026-10 重析沉淀）

- **MCR 指引带精度 ±25bp 是行业惯例**（UNH FY26：88.1%±25bp，自 88.8% 收窄改善）。指引演化表必须从 8-K EX-99.1 新闻稿原文拿（prior vs current 两列对照）——UNH 2026 年内 MCR 88.8%→88.1%、调整后 EPS 数度上调至 ≥$20.50，"指引三上调"类断言禁止靠新闻转述（来源配方见 `us-stock-data-sources.md` §2.12）
- **Q4 是 MCR 季节性高点（UNH 历史 ~93%）**：单季 MCR 骤升先查季节性再定性失血——与 §2"Q1 低点不是趋势"对称；Q1/Q3 在指引带 ±1pct 内波动属正常
- **PPD（prior period development，往年准备金回冲/补提）是承保商盈利平滑器**：净利与 MCR 同时改善时必查 PPD 方向——靠 PPD 释放的改善不算结构性
- **"收缩换利润"模式识别**：主动退出亏损 MA/ACA 计划 → 会员数下降 + MCR 改善并存 = 结构性改善而非需求恶化，用新闻稿会员表逐季验证；反向（会员激增 + MCR 恶化）= 规模换质量，评分给负
- **反向 DCF 第二实例**：UNH 现价隐含十年 FCF 增速 0.4-2%（近零）vs 公司指引 EPS ≥$20.50——市场把"近年利润崩塌"定价为永久性，预期差即赔率来源（与 §5 CI 隐含 g -5.1% 同款模式，本类公司标配）
- **第三方信号作前提的脆弱性**：旧报告若以"巴菲特持仓背书"为卖点，Berkshire 季度 13F 可直接清仓作废该前提（UNH：Q1'26 清仓）——背书型卖点在重析时一律重验
- **UNH 锚（2026-10-21）**：$417.00 / 市值 $374.3B / TTM PE 23.8x / PB 3.60x / 净债 $45.8B / 观察区 $360-430；完整数据包 repo `reports/202610/联合健康/00-数据包.md`
