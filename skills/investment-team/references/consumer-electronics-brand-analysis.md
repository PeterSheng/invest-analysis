# 消费电子 / 智能硬件品牌公司分析框架

> 首创：安克创新 300866.SZ / 0668.HK（2026-09 首轮四大师全覆盖，2026-11 归档）
> 适用：安克 / 传音 / 石头科技 / 追觅 / 九号 / Insta360 / 绿联 / 倍思 / 小米生态链，及任何「出海型 3C 品牌 + 跨境电商渠道」公司。

---

## §1 商业模式三条硬约束（决定估值语言，不是决定评分）

1. **「45% 毛利是真的，8% 净利也是真的」**——差额必须用漏斗表说清，禁止只报毛利率。
   安克 毛利率 ~45%（正常化 ~44.7%），净利率 ~8%。差额去向固定五项：平台佣金（15% 量级）、站内广告/流量费、海运与 DDP 关税、售后与召回计提、SKU 开发前置费用。
   → 报告必含「毛利 → 净利漏斗表」（毛利 / 平台费 / 销售费 / 研发费 / 管理财务 / 净利），逐项给占营收比与同比方向。

2. **「每天奔跑才能站在原地」**——单一品类天花板 2-3 年，增长靠持续开新品，护城河是 SKU 迭代速度而非单一品牌。
   → **新品收入占比（近 2 年上市 SKU 占营收）是第一跟踪指标**，优先级高于毛利率。段永平视角的「本分」判断在这里落地：连续开品 + 不下压渠道 = 本分；压货/降价清库存 = 不本分。

3. **渠道结构决定定价权**：marketplace（亚马逊）≈ 平台定价、DTC ≈ 品牌定价、线下 KA ≈ 被议价压制。渠道占比变化 > 3pct 必须单列成节，因为「毛利率改善」常常只是渠道 mix 变了而非品牌变强。

## §2 现金流：本框架的核心（OCF/NI 低 ≠ 造假，也 ≠ 可以忽略）

品牌出海公司的现金被三处吞掉：旺季备货（存货）、平台账期（应收）、在途海运（存货的另一半）。

- 安克八年 OCF/净利 均值 ~0.75，**2025 年仅 0.19**，2026TTM 回升。单年值不可用，八年序列 + 趋势才是证据。
- **双口径 FCF 必算，且必须并列呈现**：
  - **A 报表口径**：FCF = OCF − 资本开支（安克 TTM **15.08 亿元** → DCF 基准 IV **72.05 元，−35.6%**）
  - **B 所有者收益口径**：净利 + D&A − 维护性 capex，营运资本增量按「可停增长则视为投资」调整（安克 ~**30 亿元** → IV **130.55 元，+16.7%**）
  - 两口径差 **82%**。**分歧的本质是「增长型营运资本占用算不算再投资」**——若增长可停而现金可释放，营运资本增量属投资；若增长必须维持，它就是准资本开支。
- **落地写法**：两口径并列 → 目标价 = DCF 双口径加权 × 0.6 + 远期 PE 法 × 0.4 → 明写「加权系数主观，**分歧本身即结论**」。禁止择一了事（与资产轻型药企「报表 DCF vs 所有者收益」双基同构）。
- **「营运资本增量是投资还是费用」三问**：①存货周转天数是否恶化；②应收增速 vs 营收增速；③**OCF 转正 + 存货增量放缓 = 拐点信号**（老铺黄金同款反向检验：转正 ≠ 出清，还要看绝对值是否仍创新高）。

## §3 一次性项清单（本行业高发，逐项必查）

| 一次性项 | 识别指纹 | 处理 |
|---|---|---|
| **关税退税（IEEPA 等）** | 其他收益 / 营业成本冲减，单季毛利率跳升 3-5pct | 剔出后重算毛利率与扣非。安克 2026H1 收到 **14.47 亿元**、约 **8.45 亿元冲减成本** → 毛利率 44.73%→**49.82%**，撑起 H1 归母 **+42%** |
| **召回计提** | 销售费用-售后 / 预计负债跳增 + 公告 | 分「一次性 vs 质量体系信号」两档；**连续 2-3 次 = 体系问题**，进芒格失败路径并扣段永平「本分」维度（安克 2026-10 日本召回 41 万台，与前期召回形成三连） |
| 认证/合规罚款、平台封号 | 非经常性损益表 | 单列，并评估账号依赖度 |
| 汇兑 | 财务费用符号反转（出口+海外子公司必查） | 剔汇兑双口径（恒立/福耀同款） |

> **正常化判据（安克「两张面孔并存」）**：剔退税后 9M 扣非仅 **+5%**，但 **Q3 单季扣非 +61%、扣非净利率 +2.42pct** 是真实改善。两句话必须同时写——只写好看的那张 = 化妆式叙事；只写难看的那张 = 忽略边际改善。QoE 结论进 03-风险篇 + 综合裁决跟踪清单第一行。

## §4 H 股 / A+H：ROE 摊薄是假象，不是生意恶化

- 安克 H 股 IPO 净募 **45.23 亿 HKD**，归母权益 **107 → 163 亿元**，ROE **26.10% → 14.5%**、PB **5.87 → 4.10**。
- **PE/ROE 1.52 看起来贵，实为分母被募资现金撑大**：剔除净现金 **79.78 亿元**后**经营性 ROE 仍 23.1%**。
- → ROE 必须三锚并列：报表 ROE / **剔净现金经营性 ROE** / ROIC。仅凭报表 ROE 下「生意质量恶化」结论是本框架最常见的错误（与 18A 械企「剔现金 ROE/PE」同理，只是方向相反：这里是募资注入而非现金趴账）。
- A/H 溢价 **22.1%**（A 111.88 元 vs H 99.95 HKD ≈ 91.65 元）；H 股流通盘小（~8.5%）= 溢价是流动性/稀缺性定价，不是收敛保证。裁决表按 `ah-dual-listing-analysis.md`，**击球区双市场各给**（安克：A ≤92 元 / H ≤100 HKD）。

## §5 估值锚选择（禁用单一锚）

禁用两件事：①单一 PE/ROE（被 H 股募资摊薄）；②单一报表 FCF DCF（被营运资本增量压制 ⇒ 系统性低估）。

四件套并行：
1. **DCF 双口径三情景**（统一 WACC 10% / tg 3%）
2. **反向 DCF 隐含 g1**（见 `reverse-dcf-analysis.md`）
3. **远期 PE 法**（next-FY 一致预期 EPS × 品牌溢价倍数区间 18-22x）
4. **剔净现金 FCF Yield**

安克 2026-11 实测：DCF 双口径加权 **95.45 元** ×0.6 + 20x FY27E **120.4 元** ×0.4 = **105 元**；现价 A 111.88 元 → 12 个月隐含回报 −6.1% + 股息 1.4% ≈ **−4.7%**（低于 10% 门槛 → 中性/不新建仓）。操作阶梯：击球区 A ≤92 / 减仓 ≥132 / 泡沫 ≥150。

## §6 芒格失败路径六条模板（消费电子品牌版）

1. **平台政策/佣金上调**（亚马逊自营挤压、费率变更）——最常被低估的单一变量
2. 关税与合规成本（IEEPA 类政策反复，退税是过去时、加征是未来时）
3. **召回/质量事故**（尤其电池与充电类，安全类召回成本非线性）
4. SKU 竞争与价格战（白牌 + 国内同业同时挤压中低价带）
5. 汇率（美元/欧元收入 vs 人民币成本，单季可吞 1/3 利润）
6. **渠道库存压货反噬**（平台仓 + 海外仓双库存，去库存期营收与毛利同降）

> 安克实战判词：「生意值得尊重，价格不值得出手」——八条路径中五条已在观察窗口内出现过（召回/关税/存货/渠道/汇率），因此不是「可能的风险」而是「已发生的成本」。

## §7 跟踪指标表（季度）

| 指标 | 阈值/读法 |
|---|---|
| 新品收入占比 | 下降 = 迭代速度放缓，护城河第一警报 |
| 存货周转天数 | 环比恶化 > 15 天 = 压货或需求转弱 |
| OCF/净利（滚动 8 季） | <0.5 连续两年 = 现金转化结构性恶化 |
| 剔一次性毛利率 | 剔除退税/召回后是否守住 44% |
| 渠道结构占比（marketplace/DTC/线下） | 单季变动 >3pct 必须解释 |
| A/H 溢价 | >25% 且 H 股折价扩大 = 两地定价分歧信号 |
| 召回/认证公告 | 任何一次都是「本分」维度复核点 |

## §8 首轮旧稿审计：本类标的必查四项

安克 202606 旧稿（巴菲特单视角）四盲区 —— 其中**三项改变结论**：

1. **有息负债全口径**：旧稿漏短期银行借款及透支，低估 ~30%（口径：长贷 + 短贷 + 应付票据，港资口径含「贷款」科目）
2. **股本变动**：旧稿漏 H 股发行与募资摊薄（ROE/PB/每股指标全错）
3. **一次性项**：旧稿漏 IEEPA 关税退税（毛利率与 H1 增速被当成经营改善）
4. **质量事故与对外持仓**：旧稿漏日本召回、漏南芯科技持股（公允价值变动 ~3.5 亿量级的非经常项）

→ 消费电子/出海制造标的的旧稿审计固定四问：**有息负债全口径 / 股本是否变动 / 一次性项 / 质量事故与投资持仓**。四项任一漏项即需重算 ROE、毛利率、每股指标与 DCF。
