# 受管制医疗服务商的三个真分母（费率 / 资格 / 公司口径 FCF）

> 起源：DaVita 德维特 DVA 2026-11-16 重析轮（首轮 2026-08-06 @$188.69/3.65 → 本轮 @$174.56/**3.39**，段 3.45／巴 3.60／芒 2.95／李 3.55）。首轮 IV $397 vs 本轮 $205.2 —— **首轮 $397 里 $287（72%）来自分母错（-$202.9）与折现率偏松（-$84.1），真正观点修正只有 -$41**。本文把这次的口径失败与政策风险拆解固化为通用框架。
>
> 适用标的类别：透析（DVA/FMS）、独立检验（LH/OPCH/ADUS）、门诊/手术中心（AMED/EHC）、家庭医疗与临终关怀、任何「政府定价 + 商业保险混合付费 + 合资中心结构」的医疗服务运营商。**不是**管理式医疗/支付方框架（承保+PBM → `managed-care-pbm-analysis.md`）。

---

## §0 一句话定性

美国受管制医疗服务商 = **按行政费率出售「被政治赋予的需求」的公用事业**：需求端由医保资格（entitlement）定义，价格端由 CMS 年度规则（PPS update）定义，中间夹着商业保险议价。它的护城河是**网络与规模**，定价权在华盛顿。

判读语言固定为：**「好生意、没有定价权；便宜了，但便宜是政策给的，不是打折给的」**。

## §1 FCF 真分母：公司口径 FCF（本案最大错误源，必查）

### 1.1 三层桥（JV/合伙中心结构公司必须走完）

```
报表 OCF
 − NCI 分配（支付给合资中心/合伙医生的少数权益现金分配）
 − 维持性 capex（设备更新、翻新，按中心数 × 单中心维护额或 D&A 近似）
 − 开发性 capex（de novo 中心、收购后改造）
 = 公司口径 FCF（company-defined free cash flow）
```

绝大多数这类公司（DVA、FMS、手术中心、检验连锁）的运营主体是**与医生/合作方共同持有的合资中心**，合并报表把 100% 的 OCF 并进来，但现金流里有一大块要按比例付给少数股东——**这部分是真实现金流出，不是会计项目**。

### 1.2 硬判据

| 条件 | 处置 |
|---|---|
| `OCF − total capex` 与「公司口径 FCF」差 **<15%** | 可用报表口径，但必须声明 |
| 差 **15–30%** | **主锚用公司口径**，报表口径只作对照 |
| 差 **>30%** | **报表口径作废**，DCF 起点只能用公司口径；若已用报表口径跑了模型，必须整轮重跑（不是打补丁） |

**DVA 实证：高估 70%。** 首轮归一化 FCF0 取 **$1,900M**（OCF−capex），未扣：
- NCI 分配 ≈ **$325M**
- 开发性 capex ≈ **$170M**

→ 公司口径 TTM FCF 仅 **$980M**（FY26 指引 $1.0–1.25B）。FCF0 一改，同形状 DCF 的 IV 直接掉一半以上（$397 → $133.5）。

### 1.3 取数路径（最可靠的一手来源）

公司为了给市场「干净的 FCF」通常**主动在财报新闻稿里做 reconciliation**：

1. SEC EDGAR `data.sec.gov/submissions/CIK##########.json` → 找最新 8-K accession
2. `.../data/{CIK}/{accession 去横线}/index.json` → 拿真实文件名（**不要猜 ex99 文件名，必 404**）
3. 读 **exhibit 99.1**（press release）的「Reconciliation of Free Cash Flow / company-defined FCF」表
4. 若公司只给 adjusted EBITDA 不给 FCF → 用 §1.1 三层桥自建，并在 `00-数据包` 写「FCF0 归一化基础 = OCF − NCI − 维持性 − 开发性」

**纪律**：FCF 起点一旦改口径，必须照 `SKILL.md` 的「IV 变更拆分（可加总）」逐项列出（折现率 / 分母 / 净债股本 / 公式形状 / g 各一行），否则读者只会看到「IV 腰斩」而无法归因。

## §2 政策风险 = 两条独立路径，不可合并成「政策风险」

这是本类标的**唯一**值得单列成表的分析动作。两类风险的时间结构、可预测性、对冲手段完全不同：

| 维度 | ① **费率风险**（rate） | ② **资格风险**（eligibility） |
|---|---|---|
| 机制 | CMS 年度 PPS update、捆绑支付、支付比例调整 | 谁有资格被覆盖（公民身份、年龄、诊断门槛、工作年限） |
| 可预测性 | **高**：每年 7-11 月出拟议/最终规则，有公开评议期 | **低**：可挂在任何法案/预算调节程序里，一夜成文 |
| 时间常数 | 年化 ±2-3%，渐进 | 生效日一刀切（本案 2027-01-01，最迟 2027-04 终止） |
| 可否被商业保险/效率对冲 | **可以**（提价、降本、mix 优化） | **不可以**（患者直接消失，成本不会同步消失） |
| 芒格路径命名要求 | 可写「PPS 更新率 <X%」 | **必须写到具体规则条款 + 生效日 + 受影响人群量级** |

### 2.1 DVA 实证：首轮押对了费率、完全漏掉资格

| 事件 | 规则细节 | 结果 |
|---|---|---|
| 2027 ESRD PPS 最终规则 | 更新率 **+2.7%**（优于市场担心的下调） | ✅ 首轮「报销下移」的方向对但幅度押错——首轮把它当作核心风险，实际是利好 |
| **PFS 最终规则（2026-11-09 发布）第 III.E 节** | 限制**非公民** Part A 资格，明确覆盖 ESRD 路径；**2027-01-01 生效、最迟 2027-04 终止** | 🔴 首轮零覆盖 → 当月 **DVA -10.4% vs FMS -5.0% vs XLV -0.4%** = **纯个体 alpha** |
| 磷结合剂进入捆绑支付 | 固定 **$12.85/次**，Q2 已现成本压力 | ❌ 首轮已识别，实际落地与首轮推演一致（这一条押对了） |

**教训的一般形式**：对受管制标的，「市场共识的费率假设」几乎总被研究透，**真正的 alpha 在资格/覆盖口径的边角条款里**——这类条款在 Federal Register 的 PFS 长文档中出现几行，券商模型普遍不建模。查证路径：Federal Register API（`conditions[term]=physician fee schedule` + `publication_date` 区间）→ `/documents/full_text/text/{date}/{docnum}.txt` 全文 → 搜 `eligibility` / `citizen` / `ESRD`。

### 2.2 事件 alpha 对照法（判断「政策冲击」还是「板块情绪」）

任何单日 >5% 的政策类下跌，必须做三列对照（进 `00-数据包` 的「下跌归因时间线」）：

```
个股（DVA -10.4%） | 直接可比（FMS -5.0%） | 板块（XLV -0.4%）
```

- 个股跌幅 ≈ 板块 → 系统性/情绪
- 个股跌幅 显著大于 直接可比（同政策暴露）→ 存在**非对称个体因素**（本案：DVA 非公民患者占比更高 / 合资中心结构更依赖 Part A）
- 直接可比跌幅 ≈ 个股、两者都远大于板块 → 政策定价（板块内同类一起被打）

### 2.3 「已计价 vs 未计价」拆分（决定赔率而不只是决定方向）

```
未计价比例 = 1 − (价格已反映的政策冲击 / 券商共识已下调的盈利幅度)
```

DVA 实证：价格口径已计价 **14.9%** ≈ 未计价 **7.3%** 的 2.0x（卖方 2027 共识 EPS **$16.01 未下修**，若按 -$1.5 → $14.5）。结论语言：**「赔率偏上行，但绝对折价不足」**——不能因为「跌了 10% 而共识没动」就判「错杀」。

## §3 这种结构下的估值语言

| 项目 | 处置 |
|---|---|
质量锚 | **ROE 禁用**：合资结构 + 长期回购常致负权益（DVA 股东权益 **−$591M**，报表 ROE 96.8% 纯分母假象）→ 改 **ROIC（含商誉）/ ROA / 净债-EBITDA** |
| **DCF 用无杠杆 FCFF**：净债包含租赁负债时口径易混用（DVA 净债含租赁 **$11,780M** vs 不含 **$10,337M**），模型规格必须写清哪一版 |
| 主锚 | 三情景 DCF（WACC 10%/tg 3%，只调 g）+ 零增长锚 + 反解隐含 g1 |
| 辅证 | **EV/EBITDA**（收购方语言）+ 净债/EBITDA 杠杆带（3.0–4.0x 是本类常态） |
| 反证 | 报表 PE 只能作「指引中值 PE」参考（DVA 11.8x 指引中值 / 10.9x 共识 / 12.9x TTM），不得作为便宜论据 |

**DVA 本轮参考值**（可直接作为同类标的量级校准）：FCF0 $1,553M、股本 63.40M、净债含租赁、WACC 10%/tg 3%、5 年显式 → 悲观 g0.5% **$160.6** / 基准 g3.5% **$205.2** / 乐观 g7.5% **$272.6**；零增长锚 **$154**（现价 $174.56 比零增长贵 13%）；反解隐含 g1 **1.47%**（低于「政策全额落地」的 2.0%）。

击球区阶梯固定三档：**0.85 × 基准 IV**（$174.4）→ **0.73 ×**（$149.8，需 mix 剪刀差转正）→ **悲观 IV × 0.85**（$136.5，需规则被阻断）。**现价高 0.10% 即「进射程上沿未入区」＝观察不买**，这类 0.1% 的边界要写出来，它决定要不要动手。

## §4 关键运营 KPI（这类公司的「同一张报表」）

| KPI | 为什么是它 | DVA 参考 |
|---|---|---|
| 治疗/日（treatments per day） | 需求量的物理计数，先于收入 | 92,780 |
| 中心数 | 供给端规模与网络护城河 | 3,269 |
| **单次收入增速 vs 单次成本增速（剪刀差）** | 定价权 vs 成本通胀的唯一交汇变量；剪刀差转正是上修必要条件 | 本轮首位跟踪项 |
| 商业保险 mix vs 政府付费 mix | 政府部分是行政定价，商业部分是议价能力 | 商业/MA 贡献 **25–30% 收入** |
| 每次治疗的磷结合剂等药品成本 | 捆绑支付后的直接成本项 | 固定 $12.85/次 |

**跟踪第一行的选定原则**：取「剪刀差」而非「收入增速」——收入可由治疗量堆出来，剪刀差决定利润率方向。

## §5 特殊股东结构：关联方回购合同义务

DVA 的长期回购里有**伯克希尔按比例卖回的合同安排**。这类「与大股东有回购协议」的公司必须多查一步：

```
关联方定价偏离 = 关联方回购成交价 / 同期市价（加权）− 1
```

DVA 实证：**Q3 溢价 +10.7%、9M 累计折价 -13.6%**——机制不透明，方向随季度翻转。处置：
- 不是定罪，而是**治理维度扣分项**（占巴菲特/段永平治理分一档）
- 报告必须写明「回购节奏受合同约束，不等于管理层主动看多」
- 旁证：回购的同时**新增借款**（TLB-2 $500M）= 「借钱买自己的股票」的经典黄旗

## §6 重析轮审计清单（本类标的专用）

首轮报告若不慎用错分母，重析轮必须逐项清算（DVA 实证全部命中）：

| 审计项 | 首轮 | 实际 | 判定 |
|---|---|---|---|
| 归一化 FCF0 | $1,900M（OCF−capex） | $980M（公司口径） | 🔴 高估 70%，IV 虚高一倍 |
| 政策风险覆盖 | 只覆盖费率（PPS/捆绑） | 漏 PFS 非公民资格条款 | 🔴 零覆盖，且是当月主跌因 |
| 财年数字 | FY25 营收 13.05B / 净利 1.02B | 13.64B / 0.747B | ⚠️ 营收低估、净利高估 37% |
| 净债务口径 | 含/不含租赁混用 11,780 vs 10,337 | 需单一主口径 | ⚠️ 口径未声明 |
| 回购关联定价 | 未查 | Q3 +10.7% / 9M -13.6% | ⚠️ 治理漏项 |
| 阈值触发判断 | 「$200 阈值已触发」 | 建立在 15.8% 假 FCF 收益率上（真实 8.1%） | 🔴 **击球区从未触及** |

**「击球区从未触及」是本类最贵的错误形态**：假 FCF 收益率（15.8% vs 真实 8.1%）让「现价已便宜」的结论凭空成立。凡出现「FCF Yield >12%」在受管制医疗/合资结构标的上，第一反应就是回查 §1 三层桥。

### 首轮「信号结算表」（重析轮固定动作）

把首轮自己列的多空信号逐条结算，并**按首轮自己定的规则**给出结论（DVA：① ESRD PPS +2.7% ✅ ② 磷结合剂固定成本压力 ❌ ③ 加大回购同时借增量债 ❌ → **1 好 2 坏，按首轮规则不上桌**）。这比新评分更能暴露方法论是否自洽。

## §7 芒格路径模板（受管制医疗版，替换通用六条）

| 路径 | 触发条件 | 概率 | 影响量化 |
|---|---|---|---|
| 资格收紧 | 非公民/非长期居民 Part A 受限并扩围 | 中 | 患者量 -X% → 单次成本上升 → EPS -$Y |
| 费率重置 | PPS 更新率转负或捆绑范围扩大 | 中 | 每次治疗毛利 -$Z |
| 支付方压价 | 商业保险/MA 降费率（**与 UNH/CI 同向受损**） | 中高 | 商业 mix 毛利差收缩 X pct |
| 成本项行政定价 | 药品/耗材进入捆绑固定价 | 高（已发生） | 固定 $/次 成本超预期 |
| 杠杆与负权益 | 净债/EBITDA >4.0x 或利息覆盖 <3.0x | 低中 | 评级/再融资成本台阶 |
| 回购合同义务 | 关联方定价偏离扩大 | 低 | 每股价值转移 |

**交叉引用纪律**：DVA 25–30% 收入来自商业/MA，政策收紧时与 **UNH/CI 同向受损**（复合尾部）→ **不可同时重仓**；正确搭配是非支付方（设备/耗材，如 Medline）。

## §8 报告写法要点

- 综合裁决的裁决句用 §0 模板，不写「买入/卖出」
- `00-数据包` 必含：模型规格（WACC/tg/贴现惯例/FCF0 归一化基础/净债口径/股本）、FCF 三层桥数字、政策双路径表（含 Federal Register 出处与生效日）、IV 变更拆分（可加总）、首轮信号结算表
- 终极一问优先问「剪刀差」或「资格口径的量级」——这两者是四大师上修条件的交集变量
