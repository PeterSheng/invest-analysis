# 周期性企业财务建模补充指南

> **适用场景**：住宅建筑商、大宗商品生产商、航运、化工、半导体存储器等利润随宏观周期大幅波动的行业。

---

## 核心问题

标准 DuPont/DCF 模板假定盈利线性外推。周期性企业在周期顶点和谷底的 EPS 可能相差 2-5 倍——直接用 TTM 数据做估值会得出严重误导的结论。

以 Lennar (LEN) 为例：
- 峰值 EPS (FY2022): $15.72 → TTM P/E = 5.3x（看似极度便宜）
- 谷底 EPS (TTM Q2'26): $6.55 → TTM P/E = 12.7x（看似合理甚至偏贵）
- **4年归一化 EPS: $13.88 → Normalized P/E = 6.0x（这才是真实估值水平）**

---

## 必须追加的建模步骤

### 1. 多周期盈利归一化

在 DuPont/DCF 模型输出后，**必须追加**以下分析：

```python
# 计算归一化 EPS（4年算术平均）
avg_eps = sum(annual_eps_list) / len(annual_eps_list)
avg_ni = sum(annual_ni_list) / len(annual_ni_list)

# 三种 P/E 视角
pe_ttm = price / ttm_eps        # 当前周期位置的 P/E
pe_peak = price / max_eps       # 如果盈利回到峰值的 P/E
pe_normalized = price / avg_eps # 归一化（中周期）P/E

# 归一化 ROE
avg_roe = avg_eps / current_bvps * 100
pe_roe_normalized = pe_normalized / avg_roe
```

**输出格式**：

| 视角 | EPS | P/E | 含义 |
|------|:---:|:---:|------|
| TTM（当前） | $6.55 | 12.7x | 市场对当前周期位置的定价 |
| 峰值 (FY2022) | $15.72 | 5.3x | 如果周期回到顶部的 P/E |
| **归一化（4yr avg）** | **$13.88** | **6.0x** | **中周期估值——核心参考** |

### 2. 归一化 PE/ROE 修正

周期性企业在谷底的 ROE 被人为压低，直接用 TTM PE/ROE 会高估「昂贵程度」。

```
错误做法：PE/ROE (TTM) = 12.7 / 8.1 = 1.56 → "不便宜"
正确做法：PE/ROE (Normalized) = 6.0 / 15.0 = 0.40 → "深度低估"
```

> **⚠️ 必须在综合报告的 PE/ROE 排名表中使用 Normalized 值**，并在脚注中说明归一化方法。

### 3. DCF 敏感性矩阵扩展

周期性企业 FCF 波动巨大（Lennar: $5.05B → $1.83B），单一 FCF 起点不可靠。DCF 敏感性矩阵应覆盖更宽的 FCF 范围：

```
FCF 起点: $1.0B (熊市), $1.5B (当前), $2.0B (复苏), $2.5B (牛市)
增长率: -2%, 0%, 3%, 5%, 8%, 10%
→ 6×6 = 36 格敏感性矩阵
```

## DuPont ROE 下降诊断（针对周期性企业）

周期性企业的 ROE 下降需要区分三种成分：

| 成分 | 诊断 | 含义 |
|------|:---:|------|
| **净利率压缩** | 🔴 **坏下降** | 周期下行，定价权丧失，毛利率被激励/折扣侵蚀 |
| **资产周转率下降** | 🟡 **中性偏坏** | 收入停滞但资产（土地/库存）膨胀——资本被困在存货里 |
| **权益乘数下降** | 🟢 **好下降** | 去杠杆化，资产负债表变得更健康 |

当三项全在下降时（如 Lennar 2022→2025），主因分析至关重要：
- Lennar 的 ROE 从 22.1%→11.2%，其中**净利率贡献了 ~65% 的降幅**（13.6%→9.4%）
- 这意味着 ROE 下降是「周期性的」而非「结构性的」——周期回升时 ROE 会恢复

## 报告中必须体现的周期性语言

### 巴菲特视角估值部分

在安全边际判断中，必须区分三种安全边际类型：

| 类型 | 强周期企业的评价 | 示例 |
|------|:---:|------|
| **资产安全边际** | P/B < 1，但账面资产（土地/库存）在下行周期可能减值 | Lennar P/B 0.79x |
| **盈利安全边际** | 取决于周期位置，Normalized P/E 比 TTM P/E 更有参考价值 | Lennar Norm P/E 6.0x |
| **护城河安全边际** | 周期性企业通常护城河薄弱，不能依赖 | Lennar 品牌无溢价 |

### 芒格视角风险部分

必须包含「土地/库存减值」作为独立失败路径——这是周期性重资产企业的专属风险：

> "房价跌 10-15%，土地残余价值跌 25-50%——PB 0.79x 的安全边际在真实衰退中脆弱不堪。"

---

## 数据搜集时的特殊注意

1. **需要更长的历史窗口**：至少 4 年数据（一个完整周期），最好 6-8 年（覆盖两个周期）
2. **必须获取毛利率趋势**：周期性企业利润压缩最先反映在毛利率上
3. **行业周期指标**：获取行业级领先指标（如住宅建筑：住房可负担性指数、按揭利率、新房库存月数）

## 黄金珠宝商/金价周期股建模（老铺黄金 6181.HK 2026-08 实战）

黄金珠宝商是"奢侈品叙事 × 金价周期"的混合体：品牌溢价提供α，但金价方向决定β的符号与大小。标准 DuPont/DCF 会严重误判，必须追加：

### 1. 周期见顶三信号（先于财报确认见顶）

| 信号 | 老铺黄金实证（2025年报） | 含义 |
|------|------|------|
| **OCF 转负且缺口巨大** | 净利+48.68亿 vs 经营现金流 **-68.5亿** | 利润全部沉淀为黄金存货——盈利是纸面的 |
| **存货+负债同步暴涨** | 存货~160亿；总负债 24亿→101亿（+77亿） | 用杠杆囤金，金价下行时无安全垫 |
| **季度环比崩塌** | Q1净利37亿（春节+涨价恐慌抢购）→ Q2仅6亿（-84%） | 需求被金价"前置透支"，Q1把Q2的需求吸干了 |

> "业绩向左，股价向右"：7月27日公告 H1 预盈净利超43亿（表面利好），7月28日股价反而暴跌25%——市场读懂了 Q2 环比崩塌。**财报发布日前后必须把季度环比拆出来看，不能只看同比。**（老铺案例：H1 43亿 = Q1 37亿 + Q2 6亿）

### 2. 估值必做四件套

1. **盈利归一化**：金价2025年+64.6%后的利润是周期顶点。老铺 TTM PE 11.4x 看似便宜，归一化后（4年均值EPS 10.39→PE 31x；3年均值13.62→23.7x）完全另一个故事。
2. **ROE 均值回归四情景**（⚠ ROE 64.8% 是"金价β×囤金杠杆"的乘积，不是经营回报）：ROE→40%/30%/25%/20% 时 PB 按比例收缩，算隐含股价。老铺：ROE→30% → PB收缩至2.38x → 股价163 HKD（较现价-54%）。**不能仅因 PE/ROE<1.0 判定低估。**
3. **存货减值敏感性**：存货×金价跌幅=减值额，再÷净利=冲击比例。老铺160亿存货：金价跌10%→减值16亿=净利1/3；跌20%→32亿=净利2/3。**"一口价"高溢价产品（按件不按克）减值风险更高**——溢价部分无金价支撑。
4. **季度环比追踪**：高增长消费股的"前置释放"（涨价恐慌、节日脉冲）会在次年制造高基数负增长。小摩假设老铺2026 Q2同店 -60%~+10%——需求崩塌假设未证伪前，不因低PE抄底。

### 3. 管理层行为信号

- 周期顶部管理层公开看多（"黄金今年不会持续下跌"）= 反向信号（芒格：激励错位）
- **"全仓裸奔"不套保**：自称奢侈品的公司对金价零对冲 = 投机基因而非品牌基因（段永平"不做不对的事"）
- 关键跟踪：管理层是否开始对冲存货、是否在暴跌后加大回购

## 渠道分销商/批发商（Distributor）专项（POOL 2026-08 实战）

批发分销商（泳池/建材/工业品）的周期性与制造/建筑商不同：**利润弹性来自"库存周期 × 需求周期"的叠加**，且有四个专属诊断：

### 1. OCF 是"库存的镜子"——单年 OCF/NI 不可信，必须看 5 年均值

分销商 OCF/NI 呈典型过山车：需求火爆期大量备货（OCF/NI 可 <0.7x），需求崩塌期去库存回笼现金（OCF/NI 可 >1.5x），补库后回落。POOL 实测：0.49x → 0.65x → 1.71x → 1.53x → 0.90x。**2023-24 年 1.5-1.7x 的"优秀现金流"是去库存红利，不是经营变好；0.9x 才是常态。** 报告必须：①展示 OCF/NI 全序列 + 对应年度库存变化（$M）；②用 5 年均值（POOL ~1.06x）作质量判断；③芒格视角把"补库赌需求→二次探底→库存减值"列为独立失败路径。

### 2. 高杠杆 × 高周转 × 回购压缩权益 → ROE 虚高，锚定 ROIC

分销商 EM 常在 2.5-3.5x（POOL D/E 1.35、EM 3.0），叠加持续回购压缩权益（POOL 股本 5 年 -9.5%），ROE 31% 里约 1/3 是借来的。**PE/ROE 0.55 看似极度低估，实为统计假象——即使 ROE 高位是"商业模式常态"而非尖峰，PE/ROE 依然失真**（区别于 AppLovin 式尖峰）。正确估值锚：ROIC（POOL TTM 15.9% / 5年均值 24.3%）+ 归一化 PE + 归一化 FCF Yield。报告必须同时给 ROE 和 ROIC，并注明杠杆成分。

### 3. 周期位置判断用"逐季营收增速轨迹"，不用年度

季度页（stockanalysis `?p=quarterly`）的 YoY 增速序列是周期定位的一手证据：POOL 2023Q1 -14.6%（谷底增速）→ 2025Q1 -4.4% → 2026Q1 +6.2% / Q2 +2.2%（底部企稳）。**"收入连续 2-3 季正增长但利润仍降"= 周期底部确认但拐点未兑现**——这是报告的核心叙事张力（四大师分歧点）。同理毛利率逐季方向（POOL 2026Q2 29.66% vs 2025Q2 29.99%，仍在微降）= 拐点未确认信号。

### 4. 下行期"剩者为王"：同业崩溃是份额集中逻辑的证据

行业收缩期对比同赛道玩家状态极具说服力（POOL 实战）：零售渠道（LESL 股价 -98% 至 $0.63、净资产为负、濒临破产）与制造（SWIM TTM 微利、PE 153x）在寒冬中先死，**规模最大的批发分销商份额反而集中**（承包商砍低效供应商、订单集中到"永远有货"的最大渠道）。芒格视角必须包含"同行死亡名单"章节——它同时是段永平护城河（收缩期强化）和李录确定性（反脆弱）的证据。注意 LESL 类崩盘股在 stockanalysis 的股价序列呈反向拆股式跳跃（$411→$0.63），报告用方向性描述而非精确历史价。

### 5. 周期股 DCF 的 FCF 起点必须用归一化值 + 宽矩阵

分销商 FCF 波动同 OCF（POOL：$276M→$828M→$310M），单点 FCF 起点的 DCF 会误导。做法：三情景用归一化 FCF（5 年均值打 9 折，POOL $491M→$450M），另输出 FCF 起点敏感性矩阵（谷底 $300M / 归一化 $450M / 复苏 $600M × g1 3/5/7%）。反推现价隐含假设（POOL：隐含 g1≈3.5%、"低增长定价、零复苏期权"）是报告的金句来源。

## 常见错误

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 用 TTM P/E 判断周期性企业贵贱 | 用 Normalized P/E（至少4年均值）作为主要估值锚 |
| PE/ROE 排名用 TTM 值 | 用 Normalized PE 和 Normalized ROE 计算 |
| 单一 FCF 起点的 DCF | 宽范围敏感性矩阵（至少覆盖熊市→牛市） |
| P/B < 1 自动等于「安全边际」 | 评估账面资产在衰退中的减值风险后再判断 |
| 把 ROE 下降全归为「坏下降」 | 区分净利率（周期）、周转率（效率）、杠杆（结构）各自贡献 |

## 黄金珠宝/囤金零售商专用章节（老铺黄金 6181.HK 实战，2026-08）

金价周期股（黄金珠宝商）在标准周期股框架之上还有四个专属特征，缺一不可：

### 1. ⚠️ "囤金模式"：利润暴涨期 OCF 反而大幅为负

金价上涨期，零售商为抢货大量采购黄金 → **净利与经营现金流严重撕裂**：
- 老铺黄金 2025：净利 +48.7亿 vs 经营现金流 **-68.5亿**（利润全部沉淀为存货~160亿）
- 负 OCF 不是经营恶化，是"金价上涨周期主动囤货"——但金价见顶后这就是减值炸弹
- **报告必须同时展示 NI 与 OCF，并量化缺口去向（存货增量）**——"利润是纸面的，现金变成了仓库里的黄金"是芒格视角的核心拷问

### 2. 存货减值敏感性表（必做）

```
减值 = 存货账面值 × 金价跌幅
```
老铺案例：160亿存货，金价每跌10% → 减值~16亿 ≈ 净利1/3；跌20% → 32亿 ≈ 净利2/3。做 5%/10%/15%/20% 四档敏感性表，直接与当年净利对比。

### 3. 周期顶点 ROE 的 PE/ROE 幻觉

金价牛市 + 囤金杠杆（负债24→101亿）把 ROE 推到 64.8%（老铺）——PE/ROE = 0.18 看似极度低估，实为统计幻觉。均值回归必须用**双效应**（已有公式）：PB 随 ROE 比例收缩 `PB_norm = ROE_norm/ROE_current × PB`。老铺：ROE→30% 时 PB 5.13x→2.38x → 股价 -54%。**高增长爆发期（CAGR>100%）的多年均值归一化会严重低估正常化盈利**——此时应结合券商 2026E 指引与周期位置判断，而非机械套 4 年均值。

### 4. "业绩向左，股价向右"：环比崩塌比同比高增更致命

老铺 2026：Q1 净利 37亿（春节+涨价恐慌性抢购）→ Q2 仅 6亿（环比-84%）→ H1 预盈43亿公告当天股价暴跌25%。**周期股财报必须拆季度看环比**——同比+87%的H1预喜掩盖了Q2环比崩塌，市场对环比拐点极度敏感。暴跌复盘搜索：`"TICKER" 暴跌 OR 大跌 + 日期` + 财报日期对齐。

### 5. 管理层"全仓裸奔"信号

金价周期股若管理层不设套保（对冲），且周期顶部公开唱多（"金价今年不会持续下跌"）——这是芒格最爱的反向信号：品牌公司做投机者的事。报告必须单独评估：对冲政策、涨价频率（"一口价"定价权 vs 锚定金价）、周期顶部管理层表态。

## 贵金属零售周期股（黄金珠宝）专项（老铺黄金 6181.HK 实战，2026-08）

黄金珠宝零售是"奢侈品叙事 × 金价周期"的混合体。除通用周期建模外，必须追加以下检查：

### 1. "利润变存货"警示：净利↑ + OCF↓ 的背离
高金价周期中，零售商用经营现金流大量囤金（老铺 2025 年：净利 48.68 亿 vs OCF **-68.5 亿**，存货约 160 亿，总负债 24→101 亿）。**利润是纸面的，现金变成仓库里的黄金。** 检查清单：
- OCF/NI 比率 < 0.5 且持续恶化 → 囤货信号（盈利质量红旗）
- 存货 ÷ 年营收 > 50% → 金价下行时减值杠杆巨大
- 存货减值敏感性：`存货 × 金价跌幅%`，与当期净利对比（老铺：金价跌 10% → 减值约 16 亿 ≈ 净利 1/3；跌 20% → 2/3）

### 2. 盈喜分解技巧：H1 预盈 ≠ 利好（老铺 2026-07-27 案例）
公司发布 H1 盈喜（净利超 43 亿）**次日暴跌 25%**——因为 Q1 已预告 37 亿，H1 盈喜隐含 Q2 仅约 6 亿（环比 -84%）。**港股盈喜/盈警必须分解为"已知季度 + 隐含残差"：**
- `Q2_implied = H1_盈喜 − Q1_已预告`
- 隐含季度环比崩塌（< 50%）时，盈喜是**业绩拐点确认 / 卖出信号**，不是利好
- 单日暴跌日期可从 akshare `stock_hk_valuation_baidu` 市值序列相邻日差识别（老铺 2026-07-28 单日 -24%），再反查当日新闻确认触发事件

### 3. 一口价 vs 按克双轨与毛利率周期
- "一口价"（按件高溢价）品牌（老铺）毛利率 40%+，传统按克金店 20% 出头——估值体系完全不同，不可直接对标
- 金价快涨但调价滞后 → 毛利率被动压缩（老铺 2025 年 41.2%→37.6%，10 月补调价后回 40%+）；金价回落 + 已涨价 → 毛利率扩张（2026E 瑞银预计 +3-4pct）
- 毛利率方向 = f(金价周期位置, 调价频率与幅度)，单年毛利率不能外推

### 4. ROE 均值回归必须叠加 PB 收缩效应（周期顶点必算）
老铺 ROE 64.8%（金价β × 囤金杠杆的乘积，非经营效率）→ 若 ROE 回归 30%，PB 从 5.13x 收缩至 2.38x，对应股价 -54%。公式：`PB_norm = (ROE_norm / ROE_current) × PB`。周期顶点的 TTM PE/ROE < 1.0 是统计幻觉（老铺 PE/ROE = 0.18），不可据此判低估。

### 5. 金价周期数据源
- 金价走势：伦敦金现年度涨幅（2025 年 +64.6%）、COMEX/沪金主力、关键关口新闻（"跌破 4000 美元/盎司"）

## "收缩释放"现金流陷阱（POOL $M + 正泰电器 亿元 双案例，2026-08 实战）

周期底部公司常出现"**利润平庸、现金流爆炸**"的报表形态——不是经营变好，是战略收缩的一次性存量变现。识别三件套：

| 收缩释放信号 | POOL 实证 | 正泰电器实证 |
|------|------|------|
| ① 资本开支骤停 | Capex/营收 ~1.1%（历史常态） | 投资现金流 -38~-43 亿/年 → **-1.7 亿**（2026H1） |
| ② 去库存回笼现金 | 2023-24 去库存 OCF/NI 1.5-1.7x | 组件减产，存货变现 |
| ③ 应收集中回款 | — | 2025 回款改善，OCF 231 亿 |

**判定与修正法**：
1. **扩张期 vs 收缩期 FCF 对比**：正泰 2021-23 FCF 均值 19 亿 vs 2024-25 均值 161 亿 → 可持续 FCF 取中段 60-110 亿；POOL 5 年 FCF 均值 $491M vs TTM 谷底 $301M → base 用归一化 $450M
2. **市场隐含 FCF 反推交叉验证**（永续近似）：`FCF_implied = EV × (WACC − g) / (1+g)`。正泰：EV 752 亿、WACC 10%、g 3-5% → 隐含 55-75 亿（2025 实际 FCF 203 亿——市场没信收缩红利）；POOL：EV $8.47B、WACC 8.5%、g 3% → 隐含 ~$440M（接近归一化 $450M，市场定价合理）
3. **DCF sanity check**：**三情景安全边际全部 >100% 时，几乎必然是 base FCF 用了收缩释放口径**（正泰首版 DCF +142%~+719% 是垃圾输出；修正为可持续 FCF 后保守 +18%/基准 +140%，保守情景才与现价可比）
4. **报告呈现**：DCF 必须标注"可持续 FCF 口径"，附 5 年 FCF 波动表（正泰 8→203 亿、POOL $276→$828M），明确"扩张期-收缩期"均值，防止读者把现金流爆发误读为新常态

## 存储半导体周期顶专项（镁光 MU 2026-10 实战）

存储/面板/资源类周期股在周期顶（NPM 创历史新高、Forward PE 显得极便宜）时，在通用归一化框架之上追加四件武器：

### 1. 历史周期顶同构解剖学
- **取上一轮周期顶的"市场定价行为"而非财务数字**：顶点价 ÷ 当年峰值 EPS 倍数 + 顶后 12 个月回撤（即便次年仍盈利）
- MU：FY18 顶点 = 5.1x 峰值 EPS → 次年最大回撤 -53%；本轮现价 = 4.97x FY27E 一致预期 EPS → 同构警示位 ≈ 现价 × (1-53%) ≈ $412
- 用途：① 芒格"历史重演路径"章节的定量骨架；② 下修触发器用"回到上轮顶倍数"替代拍脑袋百分比；③ 与现价 Forward PE 并列展示，让"4.97x 看似便宜"自动失去说服力
- 数据需求：上轮顶点价走价格史 API（`us-stock-data-sources.md` §2.13），当年峰值 EPS 走年度序列（`?p=10Y` 只有 5 财年，见同文件）

### 2. FCF yield vs 无风险利率硬规则（周期顶专用）
- **归一化 FCF yield < 无风险利率 → 巴菲特/李录锚封顶 ≤3.25**：周期顶现金流的持续性撑不起"长期确定性"叙事（MU：归一化 yield 2.2% < rf 5.0% → 李录锚 3.00）
- **TTM 口径与归一化口径倒挂时以归一化为准**（MU：TTM yield 5.9% > rf，归一化 2.2% < rf——TTM 是周期顶幻觉）
- rf 当天现查（web_search "10 year treasury yield"）：2026-10-23 ≈ 5.0%，10 月初曾 5.28%——rf 变动 0.3pct 就能翻转硬规则判定，禁止沿用记忆值
- 数据包 §10 必须声明 yield 口径（TTM/归一化/有无调整）

### 3. "这次是否不一样"检验框架：长协/包销覆盖率拆解
周期顶公司必带"结构性升级"叙事（AI 需求/HBM/长期合约）。三步拆解，拒绝直接接受叙事：
- **覆盖率拆解**：take-or-pay/LTA 合同覆盖 FY 收入比例（MU：覆盖至 2030 的合同 ≥35% 收入）→ 剩余 65% 仍随行就市；合同平滑的是谷底现金流，不改变周期属性
- **重谈条款披露缺口必列**：合同是否含"价格重谈/调整机制"、披露在哪？未披露 = 数据缺口写进数据包 §10，禁止假设合同刚性
- **主 Follow-up = "下一次下行的重谈测试"**：本轮合同签于上行期，下行时客户是否援引重谈条款——周期是否被驯化，答案在这里，不在 DCF 里

### 4. 反向 DCF 的周期顶判读句式（三反推同向才下"贵"的结论）
- **隐含永续 FCF ≈ 当前峰值 FCF = 市场把峰值当永续定价**（MU：EV $924.6B @ WACC 10%/g 3% → 隐含 $62.8B ≈ FY26 实际 FCF $59-62B）
- 零增长锚：峰值 FCF ÷ WACC vs 实际 EV 溢价
- 敏感性矩阵反解：现价隐含的 FCF0/g 组合是否要求"历史大峰值常态化"
