# 保险行业专用财务建模

当分析保险公司（而非银行、经纪商或普通企业）时，使用以下专用指标体系替代通用 DuPont 模型。

## 核心指标层次

### 第一层：承保质量（最核心）

```python
"combined_ratio_pct": {year: value, ...}  # 合成本 = 损失率 + 费用率
"loss_ratio_pct":     {year: value, ...}  # 损失率
"expense_ratio_pct":  {year: value, ...}  # 费用率
"uw_income_m":        {year: value, ...}  # 承保利润 ($M)
```

**解读规则**：
- CR < 100% = 承保盈利。CR 越低越好。
- CR 趋势下降 = 护城河在加深（定价权增强/规模效应）
- CR 趋势上升 = 危险信号（竞争加剧/定价激进）
- **连续承保盈利年数** 是终极质量信号

### 第二层：资本效率

```python
"bvps":               {year: value, ...}  # 每股账面价值
"eps_gaap":           {year: value, ...}  # GAAP EPS
"invested_assets_b":  {year: value, ...}  # 投资资产总额
"gwp_b":              {year: value, ...}  # 总保费收入
```

**保险专用比率**：
- `ROE = EPS / BVPS` — 注意：GAAP ROE 可能低估（OCI 未计入）
- `BVPS CAGR` — 衡量 CEO 业绩的终极指标（巴菲特标准：>15% = 世界级）
- `GWP / 权益` — 杠杆率。1.0-1.5x 安全；>2.0x 有风险
- `浮存金 ≈ 投资资产 − 股东权益` — 浮存金的"免费"杠杆
- `浮存金成本 = 合成本 − 100%` — 负成本 = 白用别人的钱

### 第三层：估值（保险专用）

```python
pb = price / bvps       # P/B：保险公司的核心估值倍数
pe_ttm = price / eps    # P/E：波动大（投资收益影响），参考价值有限
```

**P/B 估值框架**：
- `公允 P/B = ROE / 资本成本`（经验：ROE/10%）
- 历史 P/B 区间对比比绝对 P/B 更有效
- **主估值锚是 P/B，不是 DCF**：保险公司 DCF 会因为浮存金/投资组合的复杂性而严重失真

**当用户明确要求 DCF 估值时**（常见于"给出不同情景下的现金流折现估值"类请求）：
- ✅ **可以给 DCF**，但必须三点并行：(1) 使用"可分配利润"(EPS) 而非 FCF 作为现金流代理；(2) 在结果旁用 P/B-ROE 框架做交叉验证；(3) 明确标注哪种方法更可靠
- ✅ DCF 起点 EPS 若处于周期高点（如 TRV TTM $36），必须追加"正常化 EPS"版本的保守估值，避免 DCF 给出过度乐观的结果
- ✅ P/B 框架的"5Y BVPS × 公允 P/B → 折现回当下"是比 DCF 更可靠的交叉验证方法

### 第四层：业务结构

```python
# 收入拆分
"earned_premiums_b":  {year: value, ...}  # 保费收入
"investment_income_b": {year: value, ...}  # 投资收入
"ventures_revenue_b": {year: value, ...}   # 实业收入（如 Markel Ventures）
```

**判断准则**：
- 承保利润 > 净利润的 50% = 不依赖投资赚钱（质量高）
- 承保利润 < 净利润的 30% = 投资收益驱动（质量低，熊市脆弱）

## 四类保险公司对比框架

| 类型 | 代表公司 | 核心指标 | 估值锚 |
|------|---------|---------|-------|
| 纯 E&S 承保 | Kinsale | CR < 80%, EPS CAGR | P/E + PEG |
| 三引擎复利 | Markel, Berkshire | BVPS CAGR, CR | P/B |
| 特种保险工匠 | RLI | 连续承保年数, CR | P/B + P/E |
| 保险经纪 | Brown & Brown, AJG, MMC, AON | **有机增长率**, 调整后 EBITDAC 利润率, 并购资本回报 | EV/EBITDA + 调整后 P/E（**禁用 P/B**，见下节专用框架） |

## 保险经纪商（Insurance Broker）专用框架（BRO 2026-11 重析轮实战）

> 经纪商**只收费不承保**：无浮存金、无合成本、无巨灾损失。CR / 浮存金 / P/B 三件套全部失效——套用承保商框架会把"中介"误当"承保商"。核心是三件事：**有机增长 × 利润率 × 并购资本回报**。

### 1. 必须先拆的四个指标

1. **有机增长对账表（8-K EX-99.1 财报新闻稿必有一张）**：总增长 = 有机 + 收购 + 处置 + 汇率。只看总营收会把 roll-up 当成内生增长——BRO TTM 收入 +27.5%，同期**有机仅 +0.3%**（FY2024 +10.4% → FY2025 +2.8% → 2025Q4 **-2.8%** 十年首负 → 2026Q3 +1.2%）。有机序列是估值倍数的唯一自变量，必须在 00-数据包列 6-8 个季度。
2. **调整后 EBITDAC 利润率**：EBIT 在"收购无形摊销 + 或有对价（earn-out）估计变动"之前的口径（BRO 调整后 EBITDAC margin 36.0%）。与 GAAP 营业利润率的差额 = 并购会计噪音，两份都要写。
3. **或有佣金（contingent commission / profit sharing）**：保险公司按赔付率达标后返还的额外佣金，Q4 集中确认 → 利润率季节性的主因，也是监管与利益冲突焦点（披露口径、客户知情同意）。分析季节性时先扣掉它。
4. **信托现金（fiduciary cash）≠ 自有现金**：代收保费/代付赔款是客户的钱（BRO 信托 ~$24.4 亿 vs 自有现金 $11.0 亿）。**净债务、EV、杠杆率、FCF 一律只用自有现金**，否则杠杆虚低、EV 虚小、FCF 虚高。

### 2. 估值口径（负权益公司通用）

- 商誉 + 收购无形常占资产 60%+ → **有形权益为负**（BRO -$70 亿），P/B 是分母游戏、P/TBV 无意义。**禁用 P/B 作为估值锚，最多作诊断行**（首轮 BRO 报告写 P/B 3.60x 实为 1.87x，且两个数都无估值意义——这是"把比率算对了也只是假精确"的典型）。
- 主锚：**EV/EBITDA**（成熟经纪商 12-18x 区间）+ **调整后 EPS × 倍数**；FCF yield 与 20 年反向 IRR 做交叉验证。
- **有机增长 → 倍数的映射**（BRO 三情景实证）：有机 ≈1% → 13x；2-3% → 15x；4-5%+ → 17.5x+。有机 0.3% 时市场仍给 16x = 并购/防御溢价，是均值回归风险而非安全边际。
- **调整后 EPS 的摊销加回只在停止并购时真实**。持续 roll-up 的摊销是真实经济成本（等于买入客户关系的分期折旧）→ 长期并购型经纪商必须同时给 GAAP EPS、含商誉 ROIC、有形 ROIC 三口径。

### 3. 并购资本回报体检（roll-up 专用）

- **买入资产现金回报率 = 标的 EBITDA ÷ 对价**，与自身 ROIC 对比。BRO 收购 Accession：对价 $98.25 亿（$43.15 亿股票 + $41.92 亿债务）/ 标的 EBITDA ≈ $5.2 亿 → **5.4% 税前现金回报** vs 自身 10.2% = 溢价并购，要靠 $30-40M 协同才勉强打平。这一条比"收入增长多少"更能判断管理层资本配置质量。
- **维护性并购（maintenance M&A）**：为维持增长必须每年买公司，这部分现金支出应从 FCF 中扣除再算 owner earnings。并购停摆年份（BRO 2026 支出仅 $4,100 万 vs 上年 $76.6 亿）若转为回购（$7.5 亿）+ 去杠杆，是**战略转向信号**，要单独评估，不能按"增长引擎熄火"简单扣分。
- 结构性风险：生产者（producer）是唯一资产——离职投奔初创/竞争对手即收入流失（BRO 9M 拖累收入 $44M、一次性调整 $18M），竞业诉讼与留才对价要写进风险章并跟踪同店 producer 人数与人均佣金。

### 4. 陷阱表

| ❌ 错误 | ✅ 正确 |
|---|---|
| 拿总营收增速当有机增长 | 用新闻稿对账表拆 organic / acquisition / FX，逐季列 |
| 用 P/B 或 P/TBV 估经纪商 | 负有形权益，改 EV/EBITDA + 调整后 P/E + FCF yield |
| 净债务扣减含信托现金 | 只用自有现金（BRO 信托 $24.4 亿 vs 自有 $11.0 亿） |
| 用调整后 EPS 断言"便宜" | 同时给 GAAP EPS、含商誉 ROIC（BRO 7.3% vs WACC 6.6%，仅 +0.7pt） |
| 把巨灾/承保周期风险套到经纪商 | 经纪商风险是**客户保费池收缩（hard market 反转）+ 佣金率被压缩 + 或有佣金落空** |
| 分部利润占比不标期间 | 标清累计 vs 单季（BRO Specialty 9M26 占 52%、Q3 单季 62%） |

## 保险同业估值对比模板

当用户要求同业对比时，使用以下表格格式（TRV 实战验证）：

| 公司 | 代码 | 市值($B) | P/E | P/B | ROE% | CR% | PE/ROE | 股息率 |
|:---|:---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|

**解读规则**：
- **PE/ROE** = 每单位 ROE 付出的估值溢价，越低越便宜。>1.0 偏贵，<0.5 低估
- **P/B** 是保险核心估值倍数——对比历史区间比绝对水平更重要
- **CR** 是质量指标——CR < 90% 的公司在软市场中更有韧性
- **股息+回购**：对于 TRV/PGR 这类高回购公司，加上回购收益率后总股东回报更全面
- ⚠ PE/ROE 排名受 ROE 周期性影响——硬市场年 ROE 虚高时 PE/ROE 会"假便宜"，必须补充正常化 ROE 版本的对比

**排名输出格式**（参照本轮 TRV 实战）：
```
| 🥇 | ACGL | 0.45 | ← 最低 = 最便宜
| 🥈 | PGR | 0.49 |
| 🥉 | TRV | 0.55 |
| 4  | ALL | 0.56 |
| 5  | CB  | 0.76 | ← 最高 = 最贵
```

## 保险控股集团 / 类伯克希尔模式（WTM 白山保险 2026-09 实战）

> 适用于 WTM/Markel/Fairfax/伯克希尔这类"浮存金 + 承保 + 资本配置"三引擎控股公司。与纯承保商（Kinsale/RLI）的差异：**BVPS 轨迹 + 资本配置记录比单年 CR 更重要**。

### 核心分析配方

1. **BVPS 轨迹拼图法**：保险公司不公布每股股价对应的"业绩"，用季度新闻稿关键词 `"White Mountains" book value per share` 逐季搜索拼出 BVPS 序列（2023末 $1,704 → 2024末 $1,745 → 2025末 $2,188 → 2026Q2 $2,258）。环比变化率 = 该季度真实股东回报（含股息）。**一次性收益识别**：某季 BVPS 跳增 >10% 必查事件（WTM 2025Q4 +18% = Bamboo 77% 出售给 CVC，一次性增厚 ~$320/股 = +15pct，有机仅 ~6-7%——不能外推）
2. **表观 PE 极低 = 一次性收益污染红旗**：WTM PE(TTM) 4.74x 但 2025 EPS $430 含 Bamboo 出售净收益 $816M（~$345/股）；剔除后正常化 EPS $125-140 → 正常化 PE 15-17x。**保险控股公司"表观 PE <6x"几乎必是一次性，先做 normalizing 再谈便宜**
3. **市值/浮存金比率**：`浮存金 ≈ 总资产 − 权益(含NCI) − 债务`（WTM：$13.77B − $6.25B − $0.93B ≈ $6.6B）。市值/浮存金 <1.0（WTM 0.76x）= 市场定价低于公司白用的钱，是"类伯克希尔"股的核心吸引力语言
4. **分部季度行 = 业务动向雷达**：stockanalysis 季度页（`?p=quarterly`）对保险公司会把分部当行名（Ark/Kudu/HG Global/Distinguished/Bamboo），逐季序列直接暴露：分部并表/出表（Distinguished 2025-09 出现、2026 消失）、新实体成立（Wtm Partners 2026Q2 首次出现）、出售完成（Bamboo 行消失）
5. **管理层信/新闻稿数据挖掘**：官网 IR 可能 403（WTM investor.whitemountains.com Forbidden），**prnewswire.com 的公司新闻稿可 urllib 直接抓**（UA 伪装即可）。新闻稿含：CEO 评论（可发现换帅——"CEO commented" 名字变化）、分部 CEO 原话（费率/市场判断）、回购股数与价格（纪律验证：WTM 只在 <92% BVPS 回购）、未部署资本（弹药 = 催化剂）
6. **公允 P/B 框架**：`公允 P/B = 正常化 ROE / CoE`；当前 P/B 反推市场隐含 ROE（0.93x × 9% ≈ 8.4%）与历史实际（10-12%）对比 = 折价量化。**回购地板价 = 管理层铁律阈值 × BVPS**（WTM <92% × $2,188 ≈ $2,077）是硬下行保护
7. **CEO 代际传承 = 长期确定性最大变量**：掌舵者退休/交接（Rountree→Caffrey 2026-01）时，四大师分歧集中在"资本配置文化是否制度化"；观察信号 = 新 CEO 首笔弹药去向（清理复杂科技持仓=纪律延续利好 / 溢价收购=风格漂移利空）。Rountree 留任顾问 = 缓冲

### 常见陷阱（WTM 实战）

| ❌ 错误 | ✅ 正确 |
|---------|--------|
| 用表观 PE 4.7x 判断"极度低估" | 先剔一次性（Bamboo $816M），正常化 PE 15-17x 才是真相 |
| 把 2025 BVPS +25% 当常态 | 拆解：一次性 +15pct + 有机 ~6-7%；看 2026H1 +3% 确认常态 |
| 直接用腾讯美股市值字段算 PB | 微股本（<3M 股）公司市值字段不可靠；用 stockanalysis Market Cap ÷ Shares Out，PB = 价格/BVPS 直算 |
| 用通用 DCF 估保险控股 | P/B 主锚 + 正常化盈利 PE + 市值/浮存金 + 5Y BVPS×公允P/B 折现，四法交叉 |
| 忽略 stockanalysis 利润表对保险公司解析为空 | 保险公司行名是分部名（Ark/Kudu）非 Revenue，parse_tables 解析出的 key 不同属正常，直接读分部行 |
| 只看 GAAP ROE | 剔一次性正常化 ROE（WTM GAAP TTM 20.4% vs 正常化 9-12%）——"双面孔"必须并排呈现 |

## 中国国有保险公司（SOE Insurer）补充

> 中国财险(2328.HK)、中国人保(1339.HK)等国有保险公司与 US 特种保险公司有显著差异：

| 特征 | US E&S/Specialty | 中国国有财险 |
|------|:---:|:---:|
| **承保结构** | 多险种均衡 | 车险利润独大（非车险CR≈99%盈亏线） |
| **投资自由度** | 高（权益+另类） | 受限（固收为主，权益比例低） |
| **ROE 区间** | 12-25% | 8-12% |
| **P/B 区间** | 1.5-5.0x | 0.5-1.0x（长期破净是常态） |
| **股息率** | 0-2% | 4-6%（国企分红是政治任务） |
| **市场份额** | 分散 | 高度集中（中国财险 31.6%） |
| **管理层驱动** | 股东回报 | 政策导向+股东回报平衡 |
| **核心风险** | 巨灾+承保纪律 | 投资端波动（2/3利润靠投资收益）+国企换帅 |

**中国SOE保险估值框架调整**：
- `公允 P/B = ROE / 资本成本` 仍然适用，但资本成本可用 10-11%（比 US 的 8-9% 高，反映国企治理折价）
- P/B < 1.0x 是常态而非"低估"——只有当 ROE > 资本成本时，P/B > 1.0x 才合理
- 股息率 5%+ 是核心安全边际——"下有股息保底、上有估值修复期权"
- BVPS CAGR 比单年 ROE 更重要——国企利润受投资波动大，BVPS 是更干净的复利指标

### 中国财险（2328.HK）2026-10 重析轮实战补丁（适用于所有 H股/两地上市中国保险公司）

1. **权益口径红线（PB 算错的头号来源）**：东财/akshare 聚合器给的归母权益是**中国会计准则口径**（中国财险 3,789.6 亿），公司公告 **HKAS34/IFRS 口径**是 2,859.74 亿——同一公司 PB 0.74× vs 0.99×，差 0.25×。港股保险公司 PB 一律以公告口径自算：归母权益 ÷ 总股本 = BVPS → Price/BVPS；交叉验证用公告「每股净资产」× 股本 ≈ 归母权益。聚合器口径差异主要在少数股东权益与投资资产分类，且页面不标注准则版本，直接引用必错。
2. **真实 PE 折算法（利润质量折扣）**：承保利润占净利 <50% 时表观 PE 严重失真。中国财险 H1'26：净利 322.84 亿中承保利润仅 153.76 亿（48%），另一半靠交易性金融资产收益 +126%（不可持续）→ 对投资端依赖（62%）打 7.3 折，**真实 PE 6.81–7.82× vs 表观 6.26×**（双口径并报）。芒格式纪律：出价只按承保利润反推（0.85–0.95×PB），投资收益不计入安全边际——熊市里浮存金投资端和权益市场同涨同跌，"便宜"会同步消失。
3. **好年份 CR 逆向判读**：单期创纪录低 CR ≠ 结构性改善。先拆损失率/费用率贡献——若红利来自费用率（中国财险 22.1%，-0.9pct，报行合一/渠道压缩类政策），均值回归方向向上；**Q3 费用率回升至 23–24% = "周期馈赠"确认，是撤离信号不是加仓信号**。好年份的承保纪律与坏年份的承保纪律是两回事，用跨周期 CR 均值评估承保能力。
4. **击球区用 PB 网格语言**：SOE 财险击球区 = PB 网格（≤0.95–1.0×PB 分批 / 0.85×PB 重仓 / 隐含公允 1.1–1.2× 减持），禁用 DCF 单点值；公允 PB 上沿用 ROE/CoE（CoE 取 10–11% 含国企治理折价）。
5. **数据自洽反推校验**：保险分部数字（季度承保利润）必须用「保费 × (1−CR)」反推对账——实战中搜索摘要/OCR 把 Q1 承保利润误读为 271.54 亿，反推应为 71.54 亿，与 Q1 CR 94.2% 及 H1 累计 153.76 亿自洽后才采信。季度数字与累计数字对不上 = 源数据错，先修数再建模。

## 常见陷阱

| ❌ 错误 | ✅ 正确 |
|---------|--------|
| 对保险公司用 DCF 估值 | 用 P/B + ROE 框架 |
| 只看 GAAP ROE | 关注 OCI 中的未实现损益（保险公司特有） |
| 只看 P/E | 保险公司 P/E 因投资收益波动巨大——P/B 是核心 |
| 忽略合成本趋势 | CR 是保险公司"毛利率"的镜像——最核心指标 |
| 把所有保险公司当一种类型 | E&S vs 经纪 vs 三引擎——估值逻辑完全不同 |
| 用 US 特种保险公司的 P/B 标准要求中国 SOE 保险 | P/B < 1.0x 对中国国有保险是常态（0.5-1.0x），不要机械对标 US 同行的 2-4x |
| 忽略中国保险公司的投资端依赖 | 如果承保利润 < 30% 的净利润，需要做敏感性分析——投资收益率波动 1% = 利润波动 20-30% |
| 用户要求 DCF 时粗暴拒绝 | ✅ **可以给 DCF**，但必须：(1) 用可分配利润/EPS 替代 FCF；(2) 追加正常化 EPS 保守版本（起点 EPS 处于周期高点时）；(3) 并行输出 P/B-ROE 框架交叉验证；(4) 标注哪种方法更可靠 |
| DCF 起点 EPS 取 TTM 周期高点（如硬市场年） | ✅ 追加"正常化 EPS"保守版（4年均值或软市场水平）的 DCF。以 TRV 为例：TTM EPS $36 但正常化仅 $24-26，DCF 结果差 30-40% |
| 保险 DCF 不输出 P/B 交叉验证 | ✅ 保险 DCF 永远附带 P/B-ROE 框架的"5Y BVPS→公允P/B→PV"对照表，让读者对比两种方法并自行判断 |
