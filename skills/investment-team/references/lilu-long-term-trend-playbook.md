# 04-长期趋势·李录视角 写作手册

适用：`04-长期趋势-李录视角.md` 单文件交付（用户点名路径 + 行数区间）。
本手册由 PEP 百事可乐 2026-11 重析轮（190 行 / 17.5KB，评分维持 3.25）沉淀。
李录视角的独特性：**它不问"明年赚多少"，只问"20 年后这门生意还在不在、还值不值更多钱"**。
因此所有短期波动都必须被翻译成"这是 20 年赛道上的一段噪声，还是赛道本身的位移"。

## §1 文明级赛道的四问法（核心骨架，缺一即空转）

不要写"消费必需品是好赛道"这种同义反复。逐条回答：

1. **需求会不会消失？**（20 年后人类还喝不喝含糖饮料）
   答"会"才有资格进入下一步；答"不确定"就直接把置信度打到 3 分以下。
2. **需求会不会迁移形态？**（从瓶装到现制、从糖到代糖、从货架到即时零售）
   这是李录最锋利的一问——**需求不死 ≠ 你的载体不死**。
   必须点明"载体风险"与"需求风险"是两件事，且载体风险更早到期。
3. **这门生意的成本曲线是向下还是向上？**（规模效应 vs 渠道碎片化）
4. **20 年后谁在收这份钱？**（品牌方 / 渠道方 / 平台方 / 原料方）

**写法要求**：每条给一个"如果答案为否则估值含义"的落点，否则四问只是哲学。

## §2 20 年置信度评估（李录的招牌，必须有分数）

固定五维、每维 1-5 分、给出权重与理由：

| 维度 | 看什么 | PEP 实测 |
|---|---|---|
| 需求永续性 | 品类是否人类学级别（非潮流） | 4.75 |
| 载体稳定性 | 品牌+渠道能否穿越形态迁移 | 3.50 |
| 定价权 | 长期能否跟住通胀以上 | 3.25 |
| 地理纵深 | 增长是否还有未饱和市场 | 3.75 |
| 治理与资本配置 | 20 年不分心的概率 | 3.50 |

**三条硬规则**
- 每维必须写"为什么不是更高/更低"一句，禁止只给分。
- 加权后**不要与综合评分混为一谈**：置信度衡量"看得清"，评分衡量"值不值得买"。
  两者可以背离（讲清楚背离本身就是本章价值）。
- 若某维靠"GLP-1 之类 2030 后才到期的变量"扣分，必须写明**到期时点**，
  以及**公司现在有没有在做对冲（加法期权）**。

## §3 TAM：三种口径必须分清，混淆就会得出离谱的份额

| 口径 | 含义 | 陷阱 |
|---|---|---|
| 零售额 TAM | 终端货架价 × 量 | 最常见，也最容易被当成公司收入 |
| 厂商出厂额（公司可及收入） | 零售额 ÷ 加价倍数 | 与财报口径可比 |
| SAM | 公司真正能打的市场（品类+地理+渠道） | 必须写清剔除了什么 |

**PEP 实测**：零食 ~$1.0-1.4 万亿 + 软饮 ~$0.9-1.2 万亿 = **$2.0-2.6 万亿零售额**；
按零售折算公司份额仅 **5-6%**。
结论句式（可复用）：**"它在一门两万亿美元的生意里只占 5%——这既是空间，也是它 20 年都改变不了的位置。"**

**人均收敛法**（比分份额更可靠的增长论证）：
目标市场人均消费 → 对标成熟市场人均 → 差额 × 人口 = 20 年可及增量。
必须写明"收敛需要多少年、按什么速度、被什么打断"。

**份额天花板反证**：若靠抢份额实现增长，20 年后份额要到多少？
一旦算出 >15% 就说明假设不成立——**双寡头品类的份额天花板是结构性的，不是努力问题**。

## §4 竞争格局：区分「结构折价」与「周期折价」（本报告最值钱的一段）

同业 PE 差不能笼统说"便宜"。三分法：

| 类型 | 判别 | 20 年会不会收敛 |
|---|---|---|
| 周期折价 | 盈利在低谷，修复即收敛 | 会，1-3 年 |
| 结构折价 | 商业模式层级差异（如装瓶资产重、增长慢、治理复杂） | **只会部分收敛** |
| 情绪折价 | 叙事/流动性 | 不确定，不可依赖 |

**PEP vs KO 实测**：KO 28.3x vs PEP 17.8x ＝ **~10.5x PE 折价**。
判定为结构折价：装瓶特许化是可见的收敛路径（把重资产转给装瓶商），
但股权结构、增长引擎（零食 vs 纯饮料）、管理层历史都会让折价**长期存在一部分**。
结论句："折价会收敛，但不会消失；把折价全部当成错误定价，是把周期折价的结构版误读。"

**五力速写要求**：每力一句结论 + 一个数字，不写教科书定义。
**梯队分级**：第一梯队（全球双寡头）/ 第二梯队（区域龙头）/ 挑战者（自有品牌+渠道商）。
写一句"梯队与挑战者之间的价差是由什么维持的"（通常是货架位与冷链，不是广告）。

## §5 20 年增长模型（自建推演，必须显式标注）

**口径先立，再算**（PEP 实测锚点）：

| 参数 | 值 | 说明 |
|---|---|---|
| TTM 营收 | $982.41 亿 | 数据包口径 |
| 核心净利率 | 11.4% | 剔一次性，非 GAAP 报表净利率 |
| FCF 转化率 | 0.68 | FCF / 核心净利 |
| 净债 | $407 亿 | 含短期借款与透支（用户定制口径） |
| 股本 | 13.63 亿股 | 最新 |
| 股息 | $5.92 | 当期 |
| 核心 PE / TTM PE | 16.9x / 17.8x | 双口径并列 |
| 核心 ROIC | 19.1% | 质量锚 |
| 10Y 无风险 | 5.0% | 超额收益的分母 |
| DCF IV | $83 | 与现价 $141.88 的巨大裂口必须解释，不能藏 |

**基准假设固定为"不回购、不再投资"**——这是最保守也最可审计的口径：
股息 + 内生增长 = 全部回报。任何"回购提升 EPS"的假设都要单列一行敏感性，
因为 20 年维度里回购是**价格 dependent** 的，不是免费午餐。

**输出三件事**
1. 三情景（保守/基准/乐观）各自的内生增速与 20 年后 EPS；
2. **年化总回报 = 股息率 + 内生增长 + 倍数变化**（三项分开列，禁止合并成一个数）；
3. 与 10Y 无风险利率的**超额收益**（PEP 基准 5.3% vs 5.0% = **+0.3pp**）。
   ← 这个 0.3pp 是全篇最有说服力的一句：**"20 年的不确定性，只换来 0.3 个点的补偿。"**

## §6 评分：四维桥接 + 双向辩护 + 权重即观点

**四维等权桥接**（必须四数能精确算出总分，可跨轮相减）：

| 维度 | PEP 本轮 | 含义 |
|---|---|---|
| 赛道质量 | 高 | 文明级需求 |
| 竞争位置 | 中高 | 双寡头第二 |
| 20 年确定性 | 中 | 载体风险 + 治理 |
| 价格安全边际 | **2.25** | 核心 PE 16.9x 无折价 |

加权 3.20 → 按 0.25 档取 **3.25**；等权 25% 敏感性 3.06 → 3.00
（**两个算法都给出来**，说明分数对权重不敏感＝结论稳健）。

**双向辩护是硬要求**（缺一段就是偷懒）：
- 为什么不是更低：短期失血（PFNA 利润率、北美有机下滑、股息覆盖 0.98x）属**可修复经营周期**，
  3-5 年可见结果；真正不可修复的 GLP-1 冲击在 2030 后，且公司已用并购做"加法期权"对冲。
- 为什么不是更高：17.8x PE 下基准超额仅 +0.3pp，**没有安全边际**；价格维度只配 2.25。

**"权重即观点"技巧**：当同一套分数在等权与加权下差 ≤0.25 时，
明确指出"结论不依赖权重设定"，比争论权重更有说服力。

## §7 行数超限压缩法（PEP：230 → 190，六轮，零表格损失）

顺序固定，先做便宜的：

1. **删冗余分隔线**：每块 `空行 + --- + 空行` = 3 行。标题层级已足够分段，删靠后的两块省 6 行。
2. **合并小节标题**：`### 4.3 全球梯队分级` 并入上段末句"梯队分级："，省 2-3 行。
3. **压缩复述段**：同一结论在 §1 与 §6 各说一次 → 只留在评分处，§1 改一句话指回。
4. **缩短结论句**：删修饰词而非删数字（"第一、第二梯队与挑战者之间的价差"→"梯队与挑战者之间的价差"）。
5. **最后才删表格行**，且只删"已被正文复述"的次要行。

**绝对不许为行数删掉的表**：20 年模型三情景表、置信度打分表、对手对比表、评分桥接表。
**不要为省 5 行跑 `md_trim_report.py`**（那是 30+ 行大压缩的工具）；
溢出 <10 行时手工删分隔线最快。
**每轮改完立刻 `read_file(limit=1)` 看 `total_lines`**，只信文件的数字，不信自己的估算。

## §8 结尾：不写总结，写一个痛问题

李录视角的 Follow-up 应该指向**20 年维度的结构性矛盾**，不是季度经营。
PEP 版本方向：若公司必须靠"卖更多零食"来抵消饮料端的定价权流失，
那这门生意 20 年后还叫不叫"饮料公司"？——**品类定位漂移比增速下滑更早杀死估值倍数。**

三个可复用模板：
- "如果 20 年后它的增长全部来自低毛利品类，今天这个倍数还成立吗？"
- "它现在的股息是股东回报，还是增长乏力的替代品？"
- "这门生意 20 年后收的是品牌税，还是渠道过路费？"

## §9 质量自检六门（交付前逐条打勾）

1. 头部：分析日 / 价格截至日 / 上轮价 / 上轮评分 四项齐全？

3. 算术：年化回报三拆项加总 = 报告的合计数？超额收益 = 年化 − 5.0%？
4. 评分：四维能算出总分？等权与加权都给？双向辩护都在？
5. 竞争：折价被判定为结构型还是周期型，并有收敛路径？
6. 行数：`total_lines` 落在区间内，且四张必含表都没被删行？
