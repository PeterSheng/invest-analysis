# 交易所 / 市场基础设施公司分析框架

适用：港交所（00388.HK）、CME、ICE、NDAQ、SGX、LSEG、DB1、上交所/深交所（未上市）及任何
**「对流动性收税」的牌照型市场基础设施**（交易所、清算所、结算机构、中央证券存管）。

与相邻框架的分工：本文管**交易/清算收费 + 保证金投资收益（NII）+ 客户资产污染资产负债表**的交易所；
`financial-institutions-modeling.md` 管银行/券商/资管（ROTE/P-TBV）；`financial-infrastructure-companies.md`
管 SPGI/MCO/MSCI 类**数据与评级订阅**公司（无 ADT、无客户按金）。

---

## §1 生意本质：卖的是「过路权」，不是「金融」

一句话定义：**在资本管制/时区分割之下，唯一合规可交易某类资产的通道，对过手成交额抽税。**

识别指纹（命中 3 条以上即套用本框架）：

| 指纹 | 含义 |
|---|---|
| 收入 ∝ 成交额（而非 ∝ 客户数/资产规模） | 收入是**流量税**，不是存量费 |
| 费率由监管者/政府定价或需其批准 | 定价权不在自己手里 → 让利是单向棘轮 |
| 牌照垄断 + 单一通道 | 护城河来自制度，不来自品牌或转换成本 |
| 保证金利息（NII）单列成大科目 | 利率红利的暂时性收入，常被误当护城河 |
| 资产负债表含巨额「客户资产」 | ROE/净现金/周转率全部失真，见 §5 |

⚠️ **最常见的误判**：把「牌照垄断」直接等价于「定价权」。港交所的抽成率被 CMM 框架、
handling fee 递减表、交易费检讨三条行政路径逐年下调——**垄断的是通道，不是价格**。

## §2 核心驱动：ADT 与收入弹性系数（全文最重要的一根杠杆）

### 2.1 系数推导（必做，且必须写进 00-数据包）

```
核心业务收入 / ADT 系数 = 期间核心业务收入 ÷ (期间 ADT × 天数 / 10)
```

港交所实测：2026H1 核心业务收入 139.97 亿 HKD、H1 ADT 2,981 亿（=298.1 十亿/日）→
**系数 = 0.9892 亿 HKD / 十亿 ADT**，即「ADT 每少 100 亿（=10 十亿），核心收入少 9.89 亿」。

- 该系数**已含** LME/衍生品/上市费/数据费等全部交易类收入（用总核心收入做分子即可），
  不必分项拆——分项拆会漏掉"其他核心业务"。
- 系数用于：ADT 情景 → 收入 → 毛利 → 净利的单变量推演；也是反向 DCF 反推"隐含 ADT"的桥梁。

### 2.2 为什么 ADT 跌幅几乎 1:1 变成净利跌幅

交易所的 opex 是**准固定**的（人力 + 监管合规 + 系统摊销），不随 ADT 线性变动。港交所 2026E
opex 82.2 亿 vs 收入 310 亿，收入跌 30% 时 opex 只跌个位数。

> **硬规则**：ADT 情景推演必须显式写出「收入跌幅 → 净利跌幅 ≈ 1:1（扣税率 15.9% 后）」
> 这条链，而不是给一个"温和下滑"的形容词。港交所实测：ADT 2,730 → 2,019（−711 亿）
> → 收入 −70.3 亿 → 税后净利 −59 亿 = 2026E 净利 −30%。

### 2.3 月度序列拆解：9M 平均数是"上半年借来的"

年度/9M 平均 ADT 会掩盖拐点。**必做月度表 + H1/H2 分段均值**：

| 港交所 2026 | ADT（亿） |
|---|---|
| 1–6 月均值 | **2,981**（3 月 3,040、6 月 3,191 为峰） |
| 7–9 月均值 | **2,542**（同比 −11.2%） |
| 9 月单月 | **2,019**（2025-02 以来最低；7→9 月 −34%） |

读法：9M 那个漂亮的 2,730 亿，有四分之三是 H1 撑起来的 → **用 9M 均值做估值起点必然高估**。
同理，「Q3 收入 +1.2% 但净利 −0.8%」= 两年来首次净利同比转负，是第一块多米诺的确认信号。

### 2.4 一个反直觉的联动：「ADT↑ 与 NII↓ 是同一个降息周期的两个孩子」

降息 → 风险偏好上升（ADT 涨）+ 保证金收益率下降（NII 跌）。市场常把降息当单向利好。
**必须检查当期落在哪个象限**：`ADT↑+NII↑`（最佳）、`ADT↑+NII↓`（量补价）、
`ADT↓+NII↓`（最差，港交所 2026Q3 即此）。

### 2.5 IPO 是 ADT 的敌人，不只是朋友

创纪录的 IPO 募资（港交所 9M 3,880 亿）在发行当年抬高成交与上市费，但 12–24 个月后变成
**解禁与增发供给**。写作语言：「成交额被自己的 IPO 纪录喂大，再被自己的 IPO 纪录压回」。

## §3 NII（保证金投资收益）：区分「周期波动」与「结构性再定价」

港交所四重压缩（2026H1 NII 25.60 亿，−11%）：

| 压缩项 | 路径 | 性质 |
|---|---|---|
| 客户保证金框架 CMM | 1.33x → 1.2x（2026-09 已实施）→ 1.1x（2027-03 目标） | **行政决定** |
| handling fee 递减 | 80bps → 70bps（2026-12-31）→ 每年 −10bps → 50bps（2028 末/29 初） | **行政决定** |
| 非现金抵押品扩容 | 接受债券通国债/政银债/离岸国债作抵押（2026Q4） | **行政决定** |
| 降息 | HIBOR 下行 | 市场决定 |

> **判读规则**：三项是行政决定 → **不会再回来**。因此 51.2 亿（2026E）→ 47（2027E）→ 38–40（2029E）
> 不是"底部"，是"新常态"。凡行政定价的收入，估值时一律按**阶梯下行**建模，禁止假设均值回归。

NII 的估值权重：NII 挂在零成本资金上，几乎全是税前纯利润。港交所 NII 税后 43 亿 ≈ 净利 **22%**
（税前口径约四分之一）——**表述必须写明税前/税后**，否则"四分之一"与 22% 会被读者当成矛盾。

## §4 收入结构的正确拆法

按「是否随 ADT 变动」两层拆，不要按会计科目罗列：

| 层 | 港交所 2026H1 | 占收入 | 特征 |
|---|---|---|---|
| 交易类（交易费 35.9% + 结算费 26.0%） | 103.40 亿 | **61.9%** | 纯 ADT 函数 |
| 上市费 | 10.51 亿 | 6.3% | 与 IPO 节奏挂钩，滞后 ADT 6–12 个月 |
| 市场数据费 | ~8.30 亿 | 5.0% | **最像订阅、最抗周期**——增速是质量指标（港交所仅 +4%） |
| 其他核心 | ~17.76 亿 | 10.6% | — |
| NII | 25.60 亿 | 15.3% | 利率 + 行政定价，见 §3 |
| 其他收益（含一次性重估） | 1.45 亿 | 0.9% | 必须剔除后看增速 |

**「最抗周期的那一项跑不动」是最响的质量警报**：市场数据费只 +4%（行业订阅型应 +8~10%），
说明增长全靠成交量，一旦 ADT 回落没有第二根支柱。

## §5 资产负债表：客户资产污染（本框架最容易犯的错）

交易所报表里「总资产 4,740 亿」绝大部分不是自己的钱：

| 港交所 2026-09-30 | 金额（亿 HKD） | 处理 |
|---|---|---|
| 总资产 | 4,740.9 | **禁止**用于杠杆/周转分析 |
| 结算参与者按金/预收 | 2,505.4 | 客户资金，剔除 |
| 衍生金融工具负债 | 891.1 | 客户/对冲仓位，剔除 |
| 自有资产（自算） | ≈1,344 | 这才是分母 |
| 现金及等价物（报表） | 1,629.9 | **绝大部分是客户保证金，禁止当净现金/安全垫** |
| 有息负债合计 | ≈2.25 | 实质零杠杆 |

**双口径 ROE（必须并列）**：

- 报表 ROE = TTM 净利 / 期末归母权益 = 197.62 / 558.33 = **35.4%**
- 剔商誉 ROE = 197.62 / (558.33 − 203.94) = **55.8%**
- DuPont（自有资产口径）= 净利率 63% × 自有资产周转 0.23x × 权益乘数 2.41x ≈ 35% ✓
- ⚠️ 用报表总资产算周转率只有 0.065x——**分母被客户保证金污染，是无意义的数字**，报告中须显式说明。

> 「剔商誉 ROE 从 35.4% 跳到 55.8%」不是好消息，是**「有 204 亿的钱在睡觉」的证据**（见 §6）。
> PB 8.73x 高不是问题（ROE 35–56% + 90% 派息下的合理 PB），但也不能拿 PB 做主要锚。

## §6 商誉与收购结算单：一次 14 年才被看清的资本配置

交易所的商誉几乎都来自「用股东的钱买战略叙事」。做法是给收购做一张**14 年结算单**：

| 项目 | 港交所/LME（2012 收购，14 亿英镑 ≈ 170 亿 HKD） |
|---|---|
| 2026H1 收入 | 19.92 亿（占总收入 11.9%） |
| EBITDA 率 | **68%**——全公司最低（现货 92%、衍生品 84%、数据 82%） |
| EBITDA | 13.55 亿（占全公司 10.1%） |
| 14 年累计 EBITDA（粗算） | 约 250–270 亿（从 ~10 亿线性增至 27 亿） |
| 对 170 亿成本 | **≈1.5x 名义倍数 → 名义 IRR 3% 量级** |
| 同期主业 ROE | 35.4%（同一笔钱回报是它的十倍） |

> 结论语言不是"亏了"，是 **"占着 170 亿资本、14 年只赚回一个本金"**——芒格所说
> *a failure of capital allocation that never shows up as a loss*。它不减值（现金流还在），
> 只**永久占用股东资金**。这也是评估「下一个 14 亿英镑会怎么花」的参照系。
> 风险未结束的判据：量涨价跌（LME ADV +18% 但 margin 仅 68%）+ 监管重构（FCA/BoE 清算咨询）。

## §7 估值：先拆「周期峰值 PE 假象」，再用三重锚

### 7.1 峰值盈利 PE 假象（交易所最贵的错觉）

港交所 PE(TTM) 24.66x **低于**同业中位 26.2x，看起来便宜；但：

- TTM 净利 197.62 亿 = 周期峰值（2025 收入 +30.3%、净利 +36.0%）
- **EV/EBITDA 20.1x 高于全部同业**（CME 17x、ICE 14x、NDAQ 15x、SGX 18x、DB1 16x）
- 正常化 PE（ADT 2,200 亿 → EPS 11.00）= **35.0x**

> 「PE 低是分母高的假象」——**TTM PE 只能作「峰值盈利 PE」参考，禁止作为"便宜"的论据**；
> 跨同业比较一律用 EV/EBITDA 或正常化 PE。

### 7.2 正常化 EPS 的取法

中周期 ADT 不要用长历史均值（会低估结构性上移的中枢），用**近三年均值 + 结构性调整**：
港交所取 2,200 亿（2024–2026 三年 ADT 均值 2,183 亿；2018–2025 八年均值 1,388 亿属"低换手时代"，
不直接用，但须在数据包写明为何弃用）。

### 7.3 三重锚并行

1. **正常化 EPS × 正常化 PE 矩阵**（ADT 2,000/2,200/2,400/2,600 × PE 20/25/28/30/33）
2. **DDM**（派息率 90% 的公司 DCF ≡ 股利折现）：DPS = 90% × 正常化 EPS；给 r×g 敏感性表，
   反推**现价隐含永续 g**（港交所：10%/3% 口径 7.15%，风险匹配 r=9% 口径 6.15%）
3. **EPS 路径法**（现价买入、10 年、股息再投入前）给年化回报三情景——这是「价格化风险」的最直白语言
   （港交所：悲观 4.3% / 基准 7.1% / 乐观 10.0%）
4. 交叉验证：**EV/EBITDA 跨同业位次** + **FCF 对股息的覆盖倍数**（港交所 1.08x；含新总部一次性
   capex 24.5 亿则降至 0.95x——**覆盖 <1 是派息可持续性的第一条红线**）

### 7.4 现价的多种读法（写进报告，比单点目标价有用）

港交所 @384.40 同时等于：ADT 2,600 亿 × PE 28x、ADT 2,200 亿 × PE 35x、DDM 隐含 g 7.15%。
**三种读法并列 = 把"贵"翻译成"市场假设了什么"**，比"目标价 300"信息量大得多。

## §8 芒格视角：失败路径九条模板（港交所实战）

交易所的死法**不是竞争**（牌照不会丢），是「均值回归 + 慢性让利 + 范式降级」——三件都不需要黑天鹅。

| # | 路径 | 触发条件 | 概率 | 影响量化 |
|---|---|---|---|---|
| ① | 成交额均值回归（最大风险） | ADT 连续 2 季 < 中周期锚 | 高（已在进行） | ADT −711 亿 → 净利 −30% |
| ② | NII 利率红利永久退坡 | CMM/handling fee/非现金抵押 | 高（已定时生效） | 51.2 → 38–40 亿，税后占净利 22% |
| ③ | 定价权不在自己手里 | 印花税上调 / 交易费检讨 | 中 | 印花税 0.1%→0.13%：政府多收 ~400 亿/年、交易所 0 收入，但 ADT −5~8% → 净利 −6~9% |
| ④ | 制度性与地缘（双面刃） | 资本管制/南向额度/A 股国际化替代 | 中低（慢变量，影响最大） | 南向占 41%，砍半 → 净利 −12% |
| ⑤ | 商誉与收购资产 | LME 费率战/监管重构 | 中（慢性） | 商誉 203.94 亿 = 权益 36.5%，减值 1/3 → BPS −12.2% |
| ⑥ | 市场结构（南向/ETP/量化） | 占比升高 + 流动性负反馈 | 中高（结构已在） | ETP 453 亿 = ADT 16.6%；骤降时做市商撤单 → 价差走阔 |
| ⑦ | 成本刚性 + 新总部 D&A | opex +5%/年、D&A 16→18.5 亿 | 高（已锁定） | 收入 +1.2% vs opex +6.4% → 净利 −0.8% |
| ⑧ | 90% 派息的可持续性 | 净利下滑 + capex 高位 | 中 | FCF 覆盖 1.08x；悲观年股息率降至 2.1% |
| ⑨ | 治理：没有主人的公司 | 港府 5.9% + 投票权 ≤5% + CEO 3 年一续 | 结构性存在 | 无法量化，但决定前 8 条**如何被处理** |

**必写的三个递进层次**（只列 9 条表 = 半成品）：

1. **「三条最致命的，说透」**——每条 1 段，带一个"反直觉"钩子：
   ① ADT：9M 数字是上半年借来的 + IPO 是 ADT 的敌人；② NII：行政决定不会再回来；
   ③ **范式降级**——EPS 不动、倍数 35x→25x 即 −29%（385→275）、→20x 即 −43%（220）。
   语言模板：**"盈利跌 20% 你能等回来，倍数跌 40% 等不回来。"**
2. **「补一刀」**——一条资本配置/商誉的深挖（§6 模式），证明"不减值 ≠ 没损失"。
3. **「双面性」**——地缘/政策类风险必须做**双向对照表**（受益侧 vs 人质侧），
   结论固定为「短期是受益者，长期是人质」。核心纪律：**"地缘恶化 → 交易所受益"不能当多头逻辑**，
   因为受益与人质是同一条新闻的两个读法，不可预测、不可择时；不可预测变量越多，合理折价应越深。
   （港交所 EV/EBITDA 20.1x > CME 17x = 「拿确定性的倍数、付人质的风险」。）

### 8.1 芒格报告的质量自检（写完必跑）

- **五维评分均值必须精确等于总分**（港交所 4.50/3.25/2.50/2.50/2.25 → 3.00）：用脚本复算，禁止手算凑。
- **评分是"投资吸引力"不是"风险度"**：视角声明必须写明；风险多≠给低分（港交所风险 9 条但生意 A+ → 3.00 而非 1.50）。
- **"不上修/不下修"各给理由**：上修锚在"Q3 超预期"这类**"跌得比预期少"**的证据上不成立；
  下修锚在"生意质量硬指标"（EBITDA 80.3%、零负债、9M 收入 +12.4%）上不成立。
- **模糊量词必须与实算口径对齐**：「约四分之一」必须标税前/税后（港交所税前 26% vs 税后 22%）。
- 结尾固定两件：**证伪线**（↓4 条 / ↑4 条 / ⚪ 价格阶梯）+ **一个最直击痛点的 Follow-up 问题**
  （用报告自身的数字打报告自身的结论，如"2027 净利比 2026 低 21% 是你自己基准情景写的，那 35x 买的是什么？"）。

### 8.2 证伪线模板（交易所版）

| 方向 | 触发信号 | 调整 |
|---|---|---|
| ↓ | ADT 连续 3 个月 < 中周期锚下限（港交所 2,000 亿） | −0.50 |
| ↓ | 半年度 NII 大幅低于台阶（CMM 提前兑现） | −0.25 |
| ↓ | 派息率 <85%，或中期 DPS 不再同比增长 | −0.50 |
| ↓ | 印花税上调 / 交易费检讨结论为下调 | −0.25 |
| ↑ | ADT 连续 3 个月 > 9M 均值以上 | +0.25 |
| ↑ | 半年度 NII 超台阶（被非现金抵押/降息路径对冲） | +0.25 |
| ↑ | 市场数据费增速 >10%（第二根支柱出现） | +0.25 |
| ↑ | 南向占比降至 35% 以下且外资 ADT 回升（SPOF 解除） | +0.25 |
| ⚪ | 价格阶梯：正常化 28x 观察 / 公允下沿建仓 / 范式 20x 才是钟响 | 价格触发不改公司分 |

## §9 常见陷阱

| 陷阱 | 正确做法 |
|---|---|
| 把「牌照垄断」当「定价权」 | 费率由监管者定价 → 让利单向棘轮，逐年 −1.5~2% 必须进模型 |
| 用报表总资产/报表现金做杠杆与净现金分析 | 客户按金 2,505 亿 + 衍生品负债 891 亿剔除；报表 1,629.9 亿现金绝大部分是客户保证金 |
| 用 TTM PE 跨同业比较 | 峰值盈利 → 低 PE 是分母假象；改 EV/EBITDA + 正常化 PE |
| 用 9M/年度平均 ADT 做估值起点 | 必做月度表 + H1/H2 分段均值，识别"上半年借来的" |
| 把 NII 下滑当周期波动、假设均值回归 | 行政定价（CMM/handling fee/抵押品）不会再回来 → 阶梯下行建模 |
| 派息率 90% 就当"债券替代" | 先算 FCF 覆盖（含一次性 capex 后 0.95x <1）→ 悲观年股息率可腰斩 |
| 商誉不减值就认为没损失 | 做 14 年结算单算名义 IRR（港交所 LME ≈3%），"never shows up as a loss" |
| 地缘风险只写单向（利好或利空） | 双向对照表 + 结论「短期受益、长期人质」，且禁止当多头逻辑 |
| 五维评分手算求和 | 脚本复算均值是否精确等于总分（±0.25 网格） |
| 「约四分之一/大幅/显著」等量词不带口径 | 税前 or 税后、含 or 剔一次性，一律显式标注 |

## §11 数据源配方（港交所实战，CME/ICE/SGX/LSEG 同理）

### 11.1 一手源优先级（不要从新闻摘要拼数字）

| 优先级 | 源 | 取法 | 用途 |
|---|---|---|---|
| ① | **业绩公告 / 投资者关系包 PDF** | 从 IR 页拿 PDF 直链 → 下载到 `/tmp` → `pdftotext -layout x.pdf` | 收入结构 / 分部 margin / NII 拆项 / 前瞻指引（全部一次到位，含表格） |
| ② | **官方月度市场统计 xlsx** | IR 页 Monthly Market Highlights 的 `.xlsx` → pandas 读 `Monthly Data` 工作表 | ADT / IPO 募资额 的**月度序列**——§2.3「H1/H2 分段均值」的唯一来源 |
| ③ | 行情 | 腾讯 `qt.gtimg.cn/q=hk00388` | 价格 / 市值 / PE / PB / 股息率 |
| ④ | 媒体摘要 | web_search | 只用于事件、分析师目标价、管理层表态，**不用来取财报表内数字** |

⚠️ **官网新闻列表页 / 公告索引页的 HTML 常返回空壳（JS 渲染）→ 这不是「官网没有数据」，是抓错了层**。正确姿势：直接定位 `/media/...pdf` 或 `.xlsx` 直链下载，再本地转文本。同理，港交所的业绩公告 HTML 版基本无法正则解析，PDF 版永远可用。

### 11.2 PDF 检索技巧（不要通读 20 万字）

`pdftotext -layout` 输出后按**段落标题**定位，比全文 grep 关键词准：

- `Key Updates` / `Changes in <FY>` — 年度关键经营更新
- `1H 20XX Revenue Analysis` — 收入分项表（交易费/结算费/上市费/市场数据/NII）
- `Comprehensive Margin` / 分部 margin 表 — EBITDA 率与分部效率
- `Looking ahead (n/3)` — 前瞻指引与政策日程（CMM 台阶、handling fee 递减表常在此）
- 文件名习惯：`rev*` = 收入分析稿、`drv*` = 业绩公告正文、`irpack*` = 投资者关系包（含全套财务报表）

### 11.3 口径纪律：「收入及其他收益」≠「主要业务收入」（差约 10%）

- **报告一律用公告的「收入及其他收益 / Revenue and other income」**（港交所 2026H1 = **291.61 亿 HKD**）
- akshare `stock_financial_hk_analysis_indicator_em` 与东财港股 F10 返回的是**「主要业务收入」（263.39 亿）**——剔除了其他收益等科目
- 混用后果：ADT 收入弹性系数（§2.1）、NII 占收入比（§4）、核心业务收入占比**全线偏移 ~10%**，且平移不显眼、极难事后发现
- 硬规则：数据包 §1 行情表与 §收入结构表**都标注口径全称**，出现两套收入数字时必须二者并列并说明差异来源，不许择一
