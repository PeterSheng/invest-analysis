① 东财 F10 只回 5 行导致单季推导错位；② 公告正文/交易进度核查无处下手；③ 回忆式数字污染报告。

## 1. 单季度数据：不要用"累计相减"，直接取同花顺单季表

**坑**：东财 F10 `LrbAjaxNew` 一次只回 **5 个报告期**。取 `dates=2026-09-30,2025-09-30,2025-12-31,2024-12-31,2023-12-31` 后再想拆单季，
`Q = 本期累计 − 上期累计`，若上期累计行（如 `2024-03-31`）不在返回结果里，代码会**静默回落到"去年同期累计"**，
算出 2025Q1 YoY = +16.9% 这种**假的**数字（实际应为 Q1 累计本身）。**这是最容易污染报告的一类错误**：数字看着合理，无人复核。

**正确做法（一次拿全，含 12+ 个季度）**：

```python
import akshare as ak, pandas as pd
df = ak.stock_financial_benefit_ths(symbol="300685", indicator="按单季度")
# 列示例：报告期 / *营业总收入 / 其中：营业成本 / 销售费用 / 管理费用 / 研发费用 / 财务费用
#         *归属于母公司所有者的净利润 / *扣除非经常性损益后的净利润
# 单位混用：营收为"亿"（3.10），成本/费用为"万"（5949.29万）——统一换算后再算毛利率/费用率
```

已验证价值（艾德 2026-11-07）：
- 一眼看出 **2026Q2 归母 −17.8%**（H1 真正的坑），Q3 +10.3% 只是填坑；
- 一眼看出 **2025Q3 本身是下滑季**（营收 −6.1%/归母 −11.9%），Q3'26 的 +8.4% 建立在软基数上；
- 一眼看出 **2024Q4 归母仅 0.276 亿、销售费用率 41.1%** → 2025 年"+41.7%"的一半是**会计坑填回**，不可外推。

**交叉校验**：THS 单季 12 个季度求和 = 东财年报数（营收/归母），对不上就是口径（合并/单季重述）问题，
在数据包里注明，不要二选一蒙。

## 3. PE 口径：东财 f162 不可信，自己算 + 腾讯取同业

- 东财 `push2 f162`（PE）在同一请求里对艾德返回 `22.58`（= 市值/扣非 TTM，**扣非口径**），
  对华大/迪安等同业返回 `23955`/`2854` 这类 **×100** 编码值。**同一字段两种编码，不可直接比较。**
- 纪律：**PE(TTM) 一律自算**：`市值 / TTM归母`（TTM = 去年年报 + 本年前三季 − 去年同期前三季）；
  若与东财值不一致，在数据包写清"东财 f162 = 扣非口径"。
- 同业倍数用腾讯：`https://qt.gtimg.cn/q=sz300676`，字段 `[39]`=PE(TTM)、`[45]`=总市值(亿)、`[46]`=PB。**不编码，可直用**。

## 4. 事件核查：公告全表 + 正文 API（判断"交易是否落地"唯一可靠办法）

```python
# 公告列表（一次拉 100 条，覆盖数月）
f"https://np-anotice-stock.eastmoney.com/api/security/ann?sr=-1&page_size=100&page_index=1&ann_type=A&client_source=web&stock_list=300685"
# 单篇正文
f"https://np-cnotice-stock.eastmoney.com/api/content/ann?art_code={art_code}&client_source=web&page_index=1"
```

**核心技巧：用"缺失的公告"作证据。**
股权转让/实控人变更的落地，标志是出现《股份过户完成暨实控人变更》类公告。
若股东会已通过、协议已签，但**全表核至当日仍无"过户完成"字样** → 结论是**"尚未过户"**，
再叠加三季报十大股东名单（受让方未进榜）形成**双重证据**。这比任何二手新闻都硬。
艾德案例：2026-06-05 签协议 → 6-23 股东会通过 → 核到 11-06 无过户公告、十大股东仍为原控股方 22.48% ⇒ 结论"悬空 5 个月"。

## 5. 事件类公告要一起扫的几类标题（A 股中小市值公司高发）

`债务重组` / `仲裁` / `权益变动` / `回购进展` / `董事、高管增持…进展` / `限制性股票回购注销` / `减持计划完成`。
- **债务重组+仲裁**：常对应一笔技术转让/服务款收不回 → 看是否已**全额计提**（全额=会计诚实，加分；分期摊销=要警惕）。
- **高管增持"时间过半进展"**：计划 1,800-3,600 万、过半只做 404 万（22%）= 承诺执行弱，直接写进治理扣分。
- **限制性股票回购注销**：多半是业绩考核未达标 → 内部目标落空的硬证据。

## 6. 投资者关系活动记录表 = 单篇信息密度最高的文件

标题形如《…投资者关系活动记录表》（业绩说明会后 1-3 天披露），常给出：
剔除汇兑/一次性后的口径、单季拆解、政策落地进度、新产品认证、费用率指引。
**拿到"剔除 X 后 +9.67%"这类公司口径后，必须再自己剔一次**（如再剔信用减值低基数），
否则会把"口径调整"当成"经营改善"。艾德：剔汇兑 +9.67% → 再剔减值低基数后核心经营利润仅 +1.7%。

## 7. 三条不可违反的写数纪律

1. **禁止回忆式数字**。任何 YoY / 增降幅 / 毛利率，要么来自取数，要么写"—"并注明未取基数。
   本轮初稿曾凭印象写 2025Q3 +5.7%、2025Q4 +19.7%，实为 −6.1% / +27.4%，差 12 个点。
2. **毛利率按同一口径重算**：`(营收 − 营业成本)/营收`，用年报/THS 的"营业成本"，不要用含税/含运费的"总成本"
   （艾德 2025 毛利率真值 82.6%，曾误写 83.5%）。
3. **扣非口径单列**：归母与扣非逐年都要有；2022 这类"归母 2.64 / 扣非 1.57"年份，估值要用扣非并说明差额来源。

## 8. 重析轮：先找首轮，再谈"首次覆盖"

**坑**：台账 `grep 公司名` 零命中 ≠ 没有首轮。旧报告目录可能用**简称或谐音**：
艾德生物的首轮在 `reports/202606/爱得/aide_buffett_analysis.md`（目录名"爱得"、文件名 `aide_*`）。
**检索顺序**：① 台账搜全称+简称；② `grep -rl 公司名 reports/ skills/`；③ 扫 `reports/*/` 目录名找谐音/英文名（aide/amoy）；
④ 命中旧式命名（单篇 buffett/最终报告、缺 00/05）⇒ 按**重析轮**跑 + 首轮审计表 + 台账**合并补录**。

**首轮审计必查的一项：击球区是否真的被触发过**——用**盘中最低价**对比首轮买入区，并用**收盘价**二次确认。
艾德：首轮区 13-16 元，2026-06-29 **盘中 15.62 触及、收盘 16.18 站在区外**，从盘中低点到 11-06 收盘 +18%。
这条同时是"价格纪律比预测准确更重要"的实证，写进裁决部分。
