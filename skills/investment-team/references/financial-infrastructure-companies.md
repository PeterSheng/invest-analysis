# 金融信息基础设施公司分析指南

> 适用于：S&P Global (SPGI)、Moody's (MCO)、MSCI (MSCI)、FactSet (FDS)、ICE (ICE)、LSEG 等

> ⚠️ **不适用于个人征信局（TransUnion/Equifax/Experian）**：征信局是按次/按订阅计费（非纯订阅）、CapEx 占营收 6%+（非 <2% 轻资产）、三寡头+上游评分层结构、政治监管是第一估值变量——差异足够大，征信局分析用 `credit-bureau-data-rent-analysis.md`（2026-09 TRU 实战）。

## 为什么需要单独指南？

金融信息基础设施公司不是银行、不是保险、不是传统工业企业。它们具有以下独特特征，使得标准 DuPont/DCF 分析需要大量调整和解释：

| 特征 | 影响 |
|------|------|
| **大规模并购商誉**（SPGI商誉$550亿，MCO类似） | 报表ROE被严重压低，账面BVPS虚高 |
| **有形净资产为负** | P/B无意义，需要切换到P/TBV或EV/EBIT |
| **寡头监管护城河** | NRSRO牌照、SEC注册等监管壁垒是核心护城河 |
| **订阅制收入主导** | 55%+订阅收入 → 可预测性极强，估值溢价合理 |
| **轻资产极致** | CapEx < 2%营收，FCF/NI > 100% |
| **发行量周期性** | 债券评级收入与发行窗口相关，存在"refinancing sugar high" |

## 核心调整

### 1. ROE 的"假低"诊断

**标准模板的输出（13.5%）严重低估真实盈利能力。**

必须补充"调整后ROE"估算：

```
调整后ROE ≈ 净利润 / (报表权益 - 商誉)
```

对于SPGI：$44.7亿 / ($340亿 - $550亿) = 负分母 → 说明公司用极少/负的有形资本创造巨额利润，真实ROIC远超50%。

> 在报告中必须明确解释："报表ROE 13.5%看起来平庸，但扣除IHS Markit并购留下的$550亿商誉后，实际资本回报率极高。这是一个会计假象，不是基本面问题。"

### 2. P/B 改用 P/TBV 或放弃

- SPGI P/B = 3.7x 看似偏高，但如果有形净资产为负，P/B毫无意义
- 替代方案：EV/EBIT、P/FCF、PEG
- 报告中对P/B只做一句话标注即可，不要作为主要估值锚

### 3. 订阅收入占比是质量指标

| 订阅占比 | 评价 |
|----------|------|
| > 60% | 极高质量（FactSet, MSCI） |
| 50-60% | 高质量（SPGI 55.5%） |
| < 40% | 周期性强（依赖交易/发行量） |

SPGI的55.5%订阅占比提供了下行保护——即使债券发行量萎缩，超过一半收入仍然稳定。

### 4. 评级业务的周期性风险

评级收入的驱动因素：
- ✅ 企业债发行量（IPO、再融资、并购融资）
- ✅ 结构性金融产品发行
- ✅ 主权评级和绿色债券等新兴品类
- ❌ 利率上升 → 发行窗口关闭 → 评级收入下降
- ❌ 私募信贷替代公开发债 → 不需要NRSRO评级

> 关键判断：当前是否处于"refinancing sugar high"？即企业趁利率下行窗口大量再融资带来的收入脉冲。如果是，需要预期未来12-18个月的自然回落。

### 5. 行业特定指标

| 公司类型 | 核心指标 | 数据来源 |
|----------|----------|----------|
| 评级机构（SPGI/MCO） | 全球债券发行量YoY、NRSRO市场份额 | SIFMA, BIS |
| 指数公司（MSCI/SPGI Indices） | 被动基金AUM、ETF净流入 | ICI, Bloomberg |
| 数据终端（Bloomberg/SPGI MI/Refinitiv） | 终端数量、ARPU、续约率 | Company filings |
| 交易所/清算（ICE/CME） | 日均交易量、未平仓合约 | Exchange data |

## DCF 假设调整

金融信息基础设施公司的DCF假设可以比传统工业企业更激进：

| 参数 | 传统工业 | 金融信息基础设施 | 理由 |
|------|:------:|:----------------:|------|
| WACC | 10% | 8-9% | 低Beta、高可预测性、低杠杆 |
| 终端增长率 | 2-3% | 3% | GDP+超额增长可持续 |
| 高增长年限 | 5年 | 5-7年 | 护城河支撑更长的增长窗口 |

## 常见错误

| 错误 | 正确做法 |
|------|----------|
| ❌ 报表ROE低就认为资本回报差 | ✅ 必须做商誉调整后ROE估算 |
| ❌ 用P/B做主要估值锚 | ✅ 用EV/EBIT、P/FCF、PEG |
| ❌ 忽略评级收入的周期性 | ✅ 区分"结构性"和"周期性"收入驱动 |
| ❌ 把SPGI当"金融股"用保险/银行模板 | ✅ 使用本指南，它更像"数据订阅+监管牌照"公司 |
