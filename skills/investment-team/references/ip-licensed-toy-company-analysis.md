# 授权 IP 依赖型玩具/潮玩公司分析框架

> 2026-08 布鲁可（00325.HK）+ 名创优品（9896.HK）实战沉淀。适用：布鲁可（积木人）、卡游（卡牌）、52TOYS、TOP TOY、名创优品、泡泡玛特（自有为主对照组）、万代（IP 原厂对照组）等 IP 驱动型公司。核心问题：**收入的 IP 是你自己的吗？授权到期那天会发生什么？**
>
> 2026-10 合并吸收 `licensed-ip-consumer-companies.md`（同主题早期文件，布鲁可 00325.HK 单案例版）：其独有内容已并入本文件 §5（价格带轨迹/真实需求检验）、§7（次新股折价/事件驱动识别）、§9（港股建模注意）、§10（跟踪指标清单）。

## 1. IP 收入结构演变表（必做）

按 IP 列出 3-4 年收入与占比时间序列，识别换挡与依赖度变化：

| IP | 2023 | 2024 | 2025 | 信号 |
|----|------|------|------|------|
| 奥特曼（授权） | 5.57亿/63.5% | 10.96亿/48.9% | 8.15亿/28% | 见顶回落 |
| 变形金刚（授权） | - | 4.54亿/20.3% | 9.51亿/33% | 接棒第一 |
| 英雄无限（自有） | - | 3.10亿/13.8% | ~4亿 | 自研爬坡 |

- 单一授权 IP 占比 >40% = 高危依赖；<30% 且呈下降趋势 = 换挡成功（布鲁可案例）
- 前四大 IP 合计占比（布鲁可 2025H1 为 83.1%）反映集中度

## 2. 授权到期日历（必须逐 IP 查）

- **到期时间**：奥特曼中国 2027、亚洲其他 9 国 2025（同一 IP 区域授权期不同！）
- **是否自动续约**：布鲁可授权协议"通常为期一至三年、一般不会自动重续"
- **是否独家**：布鲁可大部分授权非独家——竞品也能做，护城河最致命缺陷（非独家 → 竞品同 IP 分流，圆谷可同时授权多家）
- 检索配方：`"{公司名}" "{IP名}" 授权 到期` + `"非自动续约"`（招股书/年报风险章节）
- 到期前的续约谈判年份是股价波动窗口（提前 12-18 个月定价）

## 3. IP 方自身经营数据 = 领先指标（免费的情报源）

授权方财报比被授权方更早反映 IP 热度：
- 圆谷 Fields 2026 财年中国 IP 授权收入 -51.6% → 布鲁可奥特曼收入下滑的先行确认
- 卡游奥特曼卡牌收入占比降至 ~30%（2024）→ 佐证 IP 整体降温
- 反向：泡泡玛特 THE MONSTERS 家族年收 141 亿 → 自有 IP 生态健康

## 4. 自有 IP 收入占比 = 护城河核心指标

| 公司 | 自有 IP 占比 | 本质 |
|------|-------------|------|
| 泡泡玛特 | 90%（17 个艺术家 IP 过亿） | IP 资产化 |
| 布鲁可 | 15-20%（英雄无限/百变布鲁可） | 授权搬运为主 |
| 名创优品 | 5.7%（0.5% 起，16 个自有 IP） | 转型初期 |
| 卡游 | 仅 1 个自有 IP | 授权依赖 |

**自有 IP 占比 <20% 的公司，估值不应按"IP 公司"给，应按"渠道效率公司"给**（布鲁可 PE 26.4x vs 名创经调整 8.9x 的定价差，本质是市场对 IP 资产的定价差）。跟踪：自有 IP 占比能否破 20%→50%。

## 5. 低价走量"增量不增收"剪刀差

低价格带产品（布鲁可 9.9 元星辰版）：
- 2026H1：销量占 47.6% vs 收入仅 19.5% → 毛利率被系统性稀释（52.6%→46.8%→44.3% 三连降）
- 机制：低价产品毛利率低于其他价格带 + SKU 暴增（682→1851）模具折旧 +64% 未摊薄
- 观察指标：低价格带销量占比 vs 收入占比剪刀差、毛利率连降趋势、模具折旧增速
- 判别公式：低价产品销量占比 >> 收入占比 = 盈利中枢下移（增量不增收）
- 价格带轨迹：89 元(2021) → 19 元(2024H1) → 9.9 元(2024 末星辰版)——持续下探本身是增长焦虑信号
- 真实需求检验：剔除低价产品后原有价格带销量增速（布鲁可仅 ~11%）→ 远低于整体增速 = 增长靠低价硬撑
- 反面观点（市场分歧点）：低价产品带来海量新客，若向上复购成功 = 长期用户资产；若停留低单价走量 = 持续压制盈利中枢

## 6. 渠道健康度（经销商压货识别）

- 存货周转天数骤升 = 压货信号：布鲁可 2024 年 28 天 → 2025H1 75 天（IPO 阶段向经销商压货嫌疑）
- 与直营模式公司对比（泡泡玛特 130→87 天下行）更显异常
- 超 9 成收入依赖经销 + 经销商数量暴增 = 渠道管理风险

## 7. 估值口径警示

- 必须注明"经调整 vs GAAP"：名创 GAAP PE 21.5x（被永辉权益法亏损污染）vs 经调整 PE 8.9x
- IP 依赖型公司 PE 对比须同口径（布鲁可 26.4x GAAP vs 泡泡玛特 ~20x）
- 授权 IP 到期时间表应纳入 DCF 情景（悲观情景假设头部 IP 到期不续约、收入 -30%）
- 次新股三重折价叠加：解禁减持（机构股东君联 6.93%/源码 5.64%/云锋 3.15%/高榕 1.19%）+ 投行下调目标价 + 叙事退潮（泡泡玛特行情冷却）
- 事件驱动识别：单日跳涨 >15% 用 `stock_hk_valuation_baidu` 市值序列定位日期，再搜当日公告（布鲁可 8/13 +19.7% = 中报发布，非指数纳入——2025-06-09 港股通纳入那次才是指数事件）

## 8. IP 原厂对照组：万代南梦宫（7832.T，2026-08 实战）

框架第 4 节的"自有 IP 占比 <20% 按渠道公司估值"只适用于**授权搬运型**公司。万代是 **IP 原厂**（高达 1979 年自有 + 吃豆人/太鼓达人等），视角反转：

| 维度 | 万代（IP 原厂） | 布鲁可（授权依赖） |
|------|----------------|------------------|
| 护城河本质 | 四合一纵向一体化（IP 原厂+玩具制造+游戏发行+动画制作），全球唯一 | 授权搬运+渠道效率 |
| 自有 IP | 高达（FY2026 销售 ¥2,543亿 = 集团营收 18.9%） | 15-20% |
| 授权 IP 地位 | 龙珠/海贼王为**数十年深度独家**（动画+玩具+游戏全链绑定），非普通授权 | 3 年短约非独家 |
| 估值锚 | IP 资产组合+变现管道，PE 中枢更高（24x vs 布鲁可 26.7x 已含成长溢价） | 渠道效率（低 PE） |
| 核心风险 | IP 热度周期（GQuuuuuuX 脉冲后 FY2027 计划 -5.6%）+ 游戏管线真空 | 授权到期不续约 |

**实战要点：**
- **IP 销售数据源**：万代 IR 補足資料 PDF 的 IP別売上高 表（集团/国内玩具两个口径），列 = 1Q実績|上半期|通期|1Q実績(新)|上半期今回見込|通期年初計画——一张表同时给实际+计划，跨年换挡一目了然。FY2026：高达 2,543亿(+65.7%)、龙珠 1,380亿(-27.6%)、海贼王 1,393亿、火影 257亿 → 前三大 IP 占营收 39.4%
- **授权 IP 热度领先指标**（框架第 3 节反向应用）：对 IP 原厂，看自家动画/剧场版票房（GQuuuuuuX 剧场版破百亿日元 = 高达玩具 +65.7% 的先行确认）；对授权方，看 IP 方内容供给节奏（鸟山明去世后龙珠无新作 = 龙珠销售 -27.6%）
- **IP 脉冲 vs 稳态**：爆款动画年（+65.7%）后的回落是公司自己指引的一部分（-5.6%）——分析时必须把"公司自认的回落"与"市场定价的持续高增长"对照，这是预期差核心
- **IP 原厂的反向风险**：不担心授权到期，但担心"IP 老化+新 IP 孵化失败"（内容产业口味漂移）——芒格视角从"授权到期日历"换成"爆款依赖度+游戏管线"

## 9. 建模注意（港股 / RMB 财报，布鲁可实战）

- **上市前连亏 + 可转换优先股按公允价值计入负债** → 净资产为负 → 上市后跳升 → 平均口径 ROE 虚高（布鲁可 99.9% 假象）
- 正确锚：**期末净资产口径 ROE**（6.34/28.7 = 22.1%）；ROE 均值回归分析用期末口径做基准（详见 SKILL.md 常见陷阱"上市首年报表 ROE 虚高"）
- DCF：FCF 基数用实际 OCF − CapEx（布鲁可 2025 FCF 6.4 亿）；净现金 = 现金 − 有息负债（IPO 募资未动用部分是重要现金项，布鲁可 2025 末 14.3 亿港元未动用）
- **按地区拆分增长假设**：国内（成熟，10-15%）vs 海外（起步，25%+）——单一 g1 会高估或低估，三情景 DCF 应分别校准
- 中报毛利率/净利率用新闻稿数字（时代周报/36氪等），akshare 港股接口只到最新年报
