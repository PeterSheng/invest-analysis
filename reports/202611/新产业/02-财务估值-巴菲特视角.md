# 新产业（300832.SZ）— 财务与估值视角（巴菲特）

**评分：3.0 / 5**（公司质地 4.5 分，价格 2 分，合计 3.0）
**一句话结论**：资产负债表是我见过最干净的 A 股制造业之一（零负债 + 净现金 28 亿 + 商誉 0 + ROIC 29%），但**你现在的出价（60.42 元 / 26.3x TTM）已经把未来三年的好消息提前付掉了**，隐含长期回报只有 9.7%，低于我要求的 10% 门槛。

---

## 1. 财务体检：四项全优，一项退步

| 检查项 | 数据 | 判定 |
|---|---|---|
| 盈利能力 | 毛利率 71.3%（9M26）、净利率 37.6% | **优秀**（制造业罕见） |
| 资本回报 | 加权 ROE 18.43%（2025）、**ROIC 约 29%（自算）** | **优秀**，且 ROIC > ROE 说明杠杆是负贡献（现金太多） |
| 杠杆 | 资产负债率 8.4%、有息负债 0.017 亿、**净现金 27.96 亿（市值 5.9%）** | **优秀**（抗周期能力极强） |
| 现金质量 | OCF 15.22 亿（2025）≈ 净利 16.20 亿（0.94x）；9M26 OCF 15.13 亿 / 净利 13.91 亿（**1.09x**） | **良好**，2026 年回款改善 |
| 资本开支 | 2025 年 3.11 亿（6.8% 收入）；9M26 2.28 亿；**在建工程 6.94 亿** | 轻资产，但扩产在途 → 未来折旧上行 |
| 商誉/并购 | **0** | 干净 |
| 退步项 | **加权 ROE 23.72%（2023）→ 22.85%（2024）→ 18.43%（2025）** | ROE 三年降 5.3pct，需解释 |

### 1.1 杜邦拆解（2025）

ROE 18.4% = 净利率 35.4% × 资产周转率 0.47 × 权益乘数 1.09

- **净利率是唯一引擎**（35.4% 净利率在 IVD 里顶级），资产周转 0.47 偏低（现金+理财 28 亿摊薄了分母，在建工程未投产）；
- 权益乘数 1.09 = 几乎无杠杆。**这意味着 18.4% 的 ROE 是"纯经营"赚出来的，没有任何财务杠杆加成**——含金量高于同样 18% 但靠 60% 负债率撑起来的公司；
- ROE 下滑的根因不是效率下降，而是 ①净利率从 40.3%→35.4%（集采降价 + 仪器低价铺路）②权益分母持续变厚（留存利润 + 28 亿现金未分配）。**若把 28 亿净现金从权益中剔除，经营性 ROE = 16.20/(94.0−28.0) = 24.5%**——真实赚钱能力被现金拖累了账面数字。

### 1.2 ROIC 29% 的意义

IC = 权益 94.0 + 有息 0.02 − 现金类 28.0 ≈ 66.0 亿；NOPAT（TTM EBIT 21.9 × (1−13%)）≈ 19.0 亿 → **ROIC ≈ 29%**。
**这是我认为新产业值得放进"观察池"的核心理由**：29% 的增量资本回报率，配上 12–15% 的增长，属于"戴维斯双击的原料"。问题只剩一个——**价格**。

## 2. 现金流与股东回报

| 项目（亿元） | 2024 | 2025 | 2026E(自算) |
|---|---|---|---|
| 归母净利 | 18.28 | 16.20 | 18.51 |
| 经营性现金流 | 13.57 | 15.22 | ~19.5（9M26 已 15.13，Q4 为传统旺季） |
| 资本开支 | — | 3.11 | ~3.5 |
| **自由现金流（OCF−Capex）** | — | **12.11** | **~16.0** |
| 分红总额 | 10.21 | 9.41 | ~10.7（按 58% 派现率） |
| 派现率 | 55.9% | 58.0% | 58% |
| FCF / 净利 | — | 0.75x | 0.86x |

- **FCF 收益率**：16.0 / 474.7 = **3.4%**（扣除净现金后 EV 口径 3.6%）；
- **股息率**：1.20 / 60.42 = **1.99%**，前瞻约 2.3%。**这是典型的"成长股分红"，不是"高息股"——别拿它当债券替代品**；
- 派现率 58% 且现金 28 亿趴在账上，说明管理层**有能力也愿意分钱**，但也没有更好的再投资机会（ROIC 29% 却仍大额分红，隐含管理层认为产能扩张不需要更多外部资本——这本身是对股东友好的信号）。

**一个巴菲特式追问**：既然 ROIC 有 29%，为什么不把 58% 的利润全留下再投资？
答案藏在增长的天花板：国内受集采压制、海外扩张是"慢变量"（分支机构 16 家、163 国渠道需要时间）。**分红多，恰恰说明公司自己也知道"钱在国内投不出 29% 的回报"**——这是诚实的信号，也是成长性的边界。

## 3. 三情景 DCF（WACC 10% / 永续 3%，与台账统一参数）

**模型假设**（基年 2026E 营收 51.21 亿，股份 7.857 亿股，净现金 27.96 亿）：
- 资本开支 5.5% 收入（在建工程 6.94 亿转固后上行）、ΔWC＝20% 增量收入、D&A 5% 收入、税率 13%（高新 15% + 研发加计）
- FCFF = 净利 + D&A − Capex − ΔWC

| 情景 | 概率 | 2027–2031 营收增速 | 稳态净利率 | WACC | 每股价值 | 相对现价 |
|---|---|---|---|---|---|---|
| **熊市**（集采穿透 + 国内零增长 + 留留置发酵） | 25% | 8% / 7% / 5% / 4% / 3.5% | 34.0% | 10.5% | **35.9 元** | −40.6% |
| **基准**（国内低个位数、海外 15%+、结构升级） | 50% | 14.4% / 14.5% / 13% / 11% / 9.5%（后逐年递减 1.5pct 至 3%） | 36.2%→37.0% | 10.0% | **57.9 元** | −4.2% |
| **牛市**（海外超预期 + 国产替代加速 + 生化凝血协同） | 25% | 17% / 17% / 16% / 14% / 12% | 37.5%→38.5% | 9.5% | **77.4 元** | +28.1% |
| **概率加权** | | | | | **57.3 元** | **−5.2%** |

### 3.1 敏感性矩阵（基准情景，每股价值）

| WACC \ 永续增长 | 2.5% | 3.0% | 3.5% |
|---|---|---|---|
| 9.0% | 64.4 | 67.7 | 71.6 |
| 9.5% | 59.7 | 62.4 | 65.6 |
| **10.0%** | 55.7 | **57.9** | 60.5 |
| 10.5% | 52.1 | 54.0 | 56.2 |
| 11.0% | 49.0 | 50.6 | 52.5 |

**读法**：只有把 WACC 压到 9.5% 以下（即认定这是一家"低风险"公司），现价 60.42 才算合理；按 10% 的中性贴现率，**现价已高于基准价值 4%**。
**隐含回报率（现价买入，基准情景）**：解方程得 **IRR = 9.7%**；牛市情景 11.2%；熊市情景为负。**9.7% < 我要求的 10%，也远低于 15% 的"好球"标准。**

### 3.2 倍数交叉验证

| 口径 | 数值 | 判断 |
|---|---|---|
| PE(TTM) | 26.3x | 2022 年以来区间 20–27x 的**中上部** |
| PE 2026E | 25.6x | |
| PE 2027E | **21.8x** | 若 2027 兑现 21.78 亿，21.8x 不算贵 |
| PE 2028E | 18.6x | |
| 22x × 2027E EPS 2.772 | **61.0 元** | 与基准 DCF 57.9 元交叉吻合 |
| 25x × 2027E | 69.3 元 | 需牛市兑现 |
| 同业：迈瑞 23.3x / 安图 20.1x | 新产业溢价 15–30% | 合理：增速 15% vs 4–5%，ROE 19% vs 17.8%/9.4%，试剂毛利 87% |

**结论**：DCF（57.9）与倍数（61.0）两个独立方法收敛在 **58–61 元**区间，取中值 **59.5 元 ≈ 目标价 60 元**。现价 60.42 元正好站在内在价值上——**这不是"低估"，是"公平定价"**。

## 4. 击球区与买卖区间

| 区间 | 价格 | 对应估值 | 逻辑 |
|---|---|---|---|
| **泡沫区（清仓）** | ≥85 元 | 30.7x 2027E / DCF 牛市 +10% | 需要"海外超预期 + 集采停止"双条件，赔率极差 |
| **减仓区** | 72–85 元 | 26–30x 2027E | 把未来 3 年增长全部定价完，只赚 EPS 不赚倍数 |
| **持有区（合理）** | 46–72 元 | 16.6–26x 2027E | 现价 60.42 落在中枢偏下沿之外（上沿内），可持有不加仓 |
| **击球区（买入）** | **≤46 元** | 16.6x 2027E，DCF 基准 −20%，隐含 IRR ≈ 11.7% | 20% 安全边际，对应 2026-07 留置恐慌时的价格带（37.5–46） |
| **深度击球区** | ≤40 元 | 14.4x 2027E，隐含 IRR ≈ 13.3% | 只有"政策再恶化 + 治理风险落地"才会给，要敢买 |

**巴菲特会怎么做**：把新产业放进"太难的篮子旁边的好公司篮子"——不买，但记在本子上，等下一次恐慌（2026 年 7 月那种 37.5 元）再动手。**"一家好公司，在错误的价位买入，依然是一笔坏投资。"**

## 5. 需要盯住的三个财务变量

1. **研发费用**（最重要）：2026Q3 −30%、前三季 −11.7%。若 2026 年报研发绝对额低于 2025 年的 4.78 亿，则"利润增长"含水分，我会把 2027 年净利率假设从 36.5% 下调 1pct（对应每股价值 −2 元）。
2. **在建工程 6.94 亿转固后的折旧**：若 2027 年 D&A/收入从 5% 升到 6.5%，每年吞掉约 0.7 亿税前利润（每股 −0.06 元），影响有限但需计入。
3. **应收账款（9.18 亿，占 TTM 收入 18.9%）**：目前 69 天周转正常。若升至 90 天以上（医院回款恶化），说明集采后医院现金流紧张已传导至上游——这是最灵敏的先行指标。

## 7. 证伪线

1. 现价买入后，若 2027E 净利下修至 <19 亿（对应 2027E PE >26x），则"公平定价"变为"高估"。
2. 若 2027 年经营现金流/净利 <0.85x（回款恶化），FCF 假设失效，基准价值下修 ~10%。
3. 若净现金被大额资本开支或对外投资消耗（>10 亿），资产负债表优势消失，估值中枢下移。
