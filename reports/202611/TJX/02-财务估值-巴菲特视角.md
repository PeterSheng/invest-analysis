# TJX 财务估值 — 巴菲特视角
> 价格 $131.09（2026-11-16 收盘，前收 $134.37，-2.44%）｜市值 $144.2B｜稀释股本 1,123.5M｜TTM 截至 2026-08-01｜估值参数统一 WACC 10% / tg 3%，全部引用 00-数据包 §五 原文，不重算
## 一、DuPont：58.2% 的 ROE 是怎么来的
**三因子恒等式（TTM）**：净利率 **9.7%**（6,067 / 62,363）× 总资产周转 **≈1.68x**（62,363 / 37,115，期末总资产口径）× 权益乘数 **≈3.56x**（37,115 / 平均权益 10,420）= **58.0%**，与数据包加权平均权益口径的 **58.2%** 一致（差异仅为期末/平均资产的四舍五入）。
| 因子 | FY2024 | FY2025 | FY2026 | TTM |
|---|---|---|---|---|
| 净销售额（$M） | 需补 | 56,360 | 60,372 | 62,363 |
| 净利润（$M） | 需补 | 4,864 | 5,494 | 6,067 |
| 净利率 | 需补 | 8.6% | 9.1% | **9.7%** |
| 总资产周转 | 需补 | 需补 | 需补 | ≈1.68x |
| 权益乘数 | 需补 | 需补 | 需补 | ≈3.56x |
| ROE | 需补 | 需补 | 需补 | **58.2%** |
> 口径说明：数据包仅固化 2026-08-01 一张资产负债表，FY24–FY26 的资产/权益明细未入库，故资产类因子只给 TTM，按纪律写"需补"而不虚构。净利率三年路径 8.6% → 9.1% → 9.7% 已足够说明一件事：**ROE 的抬升主要来自利润率与周转，不是杠杆**。
**必须点破的三点**。第一，**权益乘数 3.56x 里几乎没有有息负债**：金融有息负债合计仅 2,871（短借 1,000 + 长借 1,871），现金 6,004，净现金 **+3,133**；乘数的真实来源是 **11,446 经营租赁负债 + 5,024 应付账款**——前者是租店的"类债务"（其成本已全额计入营业费用 3,814），后者是供应商给的无息浮存。这是一家净现金公司，不是杠杆公司。
第二，**分母被人为压小**：股东权益仅 10,651（上年 10,190），TTM 回购 2,796 + 股息 1,949 = 4,745 的股东回报，相当于把 TTM 净利润的 78% 返还股东。ROE 58.2% 里有一大块是"回购缩表"的算术效应，而非经营效率的边际改善——这也是为什么 ROE 不能直接拿去和银行、消费品牌比。
第三，**真正衡量生意质量的是 ROIC，且必须含租赁**：
| 口径 | 分子 / 分母 | ROIC | 评价 |
|---|---|---|---|
| 含租赁（主口径） | NOPAT 5,726 / 投入资本 18,964 | **30.2%** | 零售业唯一可跨公司比较的口径，仍属顶级 |
| 不含租赁 | NOPAT 5,726 / 投入资本 7,518 | 76.2% | **失真**：租金在费用里、11,446 租赁资产在表外，分母被系统性低估 |
**76.2% 是会计幻觉**。把 5,285 家门店的 137.9M 平方英尺全部当作"不占资本"，等于假设 TJX 可以零成本复制门店网络。零售业只认 **30.2%**：它意味着每投入 1 美元资本（含租约）每年赚回 0.30 美元，配合 +25.7 天的现金转换周期，这才是"高周转 + 高利润率 + 负营运资本 + 大额回购"四件事叠出来的 58% ROE 的真实含金量。
## 二、现金流质量：96.9% 的转换率是真的吗
| 检验项 | 数值 | 判读 |
|---|---|---|
| 经营现金流 / 净利润 | 8,034 / 6,067 | 132%，营运资本在"放"现金 |
| **FCF / 净利润** | 5,876 / 6,067 = **96.9%** | 资本开支后仍几乎全额落袋 |
| 正常化 FCF / 正常化净利 | 5,711 / 5,902 = **96.8%** | 剔除关税退款税后 165 后，转换率纹丝不动 |
| 资本开支 / 营收 | 2,158 / 62,363 = **3.5%** | 轻资产，零售业里的异类 |
| 资本开支 / D&A | 2,158 / 1,319 = **1.64x** | ＞1，说明是在**扩张**而非修理旧店——这是好事 |
| SBC / 营收 | 223 / 62,363 = **0.36%** | 无股权激励稀释，回购是净减股本 |
| 存货 / 应付账款 | 7,862 / 5,024 | 供应商融资覆盖存货 64% |
| 现金转换周期 | DSI 64.7 − DPO 42.9 = **+25.7 天** | 每 1 美元销售只需垫 0.07 美元营运资本 |
**三项检验，结论是"真"**。① **利润与现金同步**：96.9% 的转换率在剔除一次性项后仍是 96.8%，说明没有靠应计撑利润；② **增长不靠垫资**：营收 TTM +7.7%，而存货只增 2%（单店口径），存货/营收比在下降——增长是自己生出来的，不是买库存买出来的；③ **没有会计化妆的常见手法**：SBC 仅 0.36%（不靠股权换利润）、capex/D&A 1.64x（没有把资本开支砍到 1.0x 以下来"制造"FCF）、无大额资本化研发。
**唯一的结构性风险在 DPO 42.9 天**。应付账款 5,024 是负营运资本模式的支柱之一，一旦供应商（21,000 家、无长期合约、季内可调）集体要求缩短账期，会一次性抽走现金；但反过来看，"无长期采购合约 + 就近买手采购 + 门店无隔墙可随时改部门"正是这套模式能承受库存风险的制度基础——所以 +25.7 天的 CCC 是**结构性**的，不是会计操纵。现金流评级：接近满分，扣分只扣在"应付账款是外部给予的、不是自己造的"。
## 三、估值四格表（PE / ROE / PB / PEG）
| 倍数 | 数值 | 锚定对象 | 判读 |
|---|---|---|---|
| PE（TTM） | **24.3x** | EPS 5.40 | 为 6–8% 增长付 24x，偏贵 |
| PE（FY27E GAAP 5.335） | **24.6x** | 含 $0.14 关税退款 | 收益质量打折（GAAP +10.9% vs 调整后 +6.2%） |
| PE（FY27E 调整后 5.175） | **25.3x** | 唯一干净口径 | 贵，且是"峰值利润率 + 一次性"双重美化后的价格 |
| PE（FY28E 自建 5.84） | **22.4x** | 一年后的正常盈利 | 用前瞻一年才降到 22x，仍高于 20x 的心理线 |
| PB（MRQ） | **13.5x** | 权益 10,651 | 高 PB 由 58.2% ROE 支撑，见下 |
| **PB/ROE 一致性** | 24.3 × 58.2% = **14.1x** vs 实际 13.5x | — | PB 比"ROE 可支撑水位"折价 **4%**，不算离谱 |
| PEG | 25.3 / 6.5 = **3.9**（GAAP 口径 24.6 / 6.5 = 3.8） | 调整后增速 6.5% | 远超 1.5–2.0 的合理带，**这是最刺眼的一格** |
**PB 13.5x 的唯一辩护词是 ROE 58.2%**：按 PB = PE × ROE 的恒等式，24.3x 的 PE 配 58.2% 的 ROE 应该给 14.1x PB，实际 13.5x 还便宜 4%——所以"高 PB"本身不是问题。问题是这个 ROE 的可持续性：若回购减速或利润率从 9.7% 回归 8.5%，ROE 落到 40% 出头，同一个 13.5x PB 隐含的 PE 就是 33x 以上，安全垫立刻消失。**PB 表面看是"贵得离谱"，实质是"把 58% ROE 当成永续"**。
**贵 / 合理 / 便宜——判断与锚**：以 **FY28E 22.4x** 为锚 → **"合理偏贵"**（前瞻一年仍高于 20x 上界约 12%）；以 **PEG 3.9** 为锚 → **"贵"**；以 **DCF 基准 91.9** 为锚 → **"贵 30%"**。三票里两票"贵"、一票"偏贵"，**本报告以 DCF 为主锚、FY28E 倍数为校验锚**，结论是"贵，但不是荒谬的贵"。分析师目标价 $165.4 不作为估值锚（它反推的 PE 是 28x FY28E，比现价还贵 25%，属于动量定价而非价值定价）。
## 四、DCF 内在价值（§五 原文引用）

**三个补充锚**：① 市场隐含 WACC ≈ 8.8% → **每股 $111.8**（仍低于现价 15%）；WACC 9% → $108.1。**折现率下调 1.2pp 只能把缺口从 -30% 收窄到 -15%，缺口不是折现率造成的**。② 零增长锚（FCF 恒定 5,711、WACC 10%）：5,711/10% + 3,133 = $60.2B → **$53.6/股**。③ 倍数法交叉验证：FY28E 5.84 × 22x（十年中枢下沿）= **$128.5 ≈ 现价**——即"P/E 说合理、DCF 说贵 30%"，**分歧 100% 落在永续增长假设上**（24.6x 反解的 tg ≈5.5%，而 10/3 框架只给 3%）。

## 六、安全边际与击球区
| 对照 | 现价 $131.09 的相对位置 | 安全边际 |
|---|---|---|
| vs 基准 IV $91.9 | 溢价 42.6% | **-30%**（IV 比现价低 29.9%） |
| vs 牛 IV $114.0 | 溢价 15.0% | **-13%** |
| vs 市场隐含 WACC（8.8%）$111.8 | 溢价 17.3% | **-15%** |
| vs 零增长锚 $53.6 | 溢价 144.6% | 现价 = 2.45x 零增长价值 |
**击球区 $95–110**。理由三条：① 对基准 IV 91.9 是 **+3%~+20% 的溢价**（即愿意为"好生意"付一个小溢价，但拒绝为"永续 5.5%"付钱），对牛市 IV 114 是 **-17%~-4% 折价**；② 对应 FY27E 调整后 EPS 5.175 的 **18.4x–21.3x**，回到 TJX 十年估值中枢的下沿；③ 上界用倍数法封顶：**20x FY28E 5.84 = $116.8 ≈ $117**，任何高于 $117 的买入都是在为永续 g 付 5.5% 的钱。**$110 以上不买、$95 以下加速买**，中间地带按 Q3（11/18 盘前）两条线裁决：Marmaxx 同店 ≥+3% 且全年调整后 ≥$5.20 → 允许向 $110 上沿靠；同店 ≤+1% 或指引下修 → 基准 IV 本身要下修，击球区随之下移到 $85–100。

## 八、巴菲特式结论
| 维度 | 判断 | 一句话依据 |
|---|---|---|
| 好生意 | **✓** | ROIC 含租赁 30.2%、CCC +25.7 天、capex 仅 3.5% 营收、SBC 0.36%——"低资本强度 + 高周转 + 负营运资本"三件套齐全 |
| 可预测 | **✓（有折扣）** | 三十年同店正增长、7,500 店跑道 +42%、新店回本 ≈2 年；但 Marmaxx 同店 +1% 与一次性收益让未来 12 个月可见度打折 |
| 价格 | **✗** | DCF 基准 91.9（-30%）、反向 DCF 要求 17.9% 起点增速（公司目标的 2.2 倍）、现价高于牛市情景 15% |
**这不是泡沫，只是精确地贵在永续增长假设上。** 把 $131.09 拆开：零增长价值 $53.6（占 41%），增长与永续假设贡献 59%。生意侧几乎无可挑剔——ROIC 30.2%、FCF 转换率 96.9%、应付账款覆盖存货 64%、无 SBC 稀释、净现金 +3,133——这就是巴菲特会愿意长期持有的那类零售资产。问题只在价格：24.6x 反解出 tg ≈5.5%，而在 10Y 国债 5.12% 的世界里，一家增长 6–8%、永续 3% 的公司不该拿 24x。市场没有疯，它只是把"门店 +4% + 同店 +3%"这条本已很好的曲线，又额外加了一倍杠杆的乐观。等 11/18 盘前那两条线，$95–110 才是愿意出价的地方。
