## 一、盈余质量：真金白银，但"non-GAAP"这块糖有点大

| 指标 | 数值 | 巴菲特判读 |
|---|---|---|
| FCF / 净利 | **1.24** | 利润全是现金，无纸面收入 |
| FCF 利润率 | **40.8%**（$1,034M / $2,535M） | 五年从 34.6% 抬到 40.8%，收费站形状 |
| ROIC / ROA | **80.2% / 41.0%** | 资本效率顶级（ROE 因负权益禁用） |
| 毛利率 | **86.1%**（Q4 86.9%） | 定价权的财务证据 |
| 营业利润率 | **51.0%**（调整后 53.6%） | 同业最高（TRU 19.4%、EFX 19.2%、MCO 46.0%） |
| **SBC / 营收** | **7.3%**（$185.5M） | non-GAAP EPS $42.99 **先把 $8.07/股 的 SBC 加回** |
| 税率 | **24.1%**（FY25 18.8%） | 税盾利用率下滑，+5.3pt |

**第一个要拆穿的糖**：Street 用的 15.74x 前瞻 PE，分母是 non-GAAP EPS。而 FY26 non-GAAP 净利 $988.3M 是**把 $185.5M 员工股权费用加回来**之后的结果——这笔费用年复一年真实发生（SBC 从 FY24 $149M 涨到 FY26 $185M，两年 +24%）。用 GAAP 口径就是 **TTM 19.4x**（EPS $36.32）；若把 SBC 扣回去算 FY27E GAAP EPS（$44.75 − $8.07 ≈ $36.7），前瞻 PE 也是 **≈19.2x**，不是 15.7x。

**第二个糖**：non-GAAP 还剔了 $65M 和解、$27.3M 重组、$47.9M 一次性出售收益——这三项本轮**方向相反**（两负一正），净效果是少报利润。这一项我认为可以接受。

> **结论**：盈余质量 3.25 维持。生意本身是真印钞机（FCF 利润率 40.8%、资本开支 1.5%），但"加回 SBC"这件事让 non-GAAP EPS 比 GAAP 高出 **18.4%**（$42.99 vs $36.32）——任何用 non-GAAP PE 做的比较都要打折。

## 二、资本配置专节：一美元留存检验（连续第二年不合格，且更差）

**检验标准：每一美元留存收益，是否至少创造一美元内在价值？**

| 事实 | 数值 | 判读 |
|---|---|---|
| FY26 回购 | **$3,046M**（FCF 的 2.9 倍） | 靠发债：总债务 $3,056M → **$5,259M**（+$2,203M） |
| 净股本缩减 | 24.239M → **22.863M**（**-1.376M 股 / -5.7%**） | $3,046M 只买回 5.7% |
| **每净减 1 股有效成本** | **≈ $2,214** | SBC 年 $185.5M（≈1.4M 股）吃掉一半效果 |
| 股东权益 | -$688M → -$1,746M → **-$3,873M** | 连续三年为负，越买越负 |
| 15% 裁员 | $27.3M 计提 ≈ 560 人 | 唯一像"克制"的动作 |

**判定：一美元留存检验不合格，且比上轮更严重。**

- 上轮（9/29）我的判断是"净债/FCF 5.4x 已封死回购弹性"。**实际是：他们又借了 $2.2B，继续买了 $3.0B。** 这条判断被事实推翻（Debt/FCF 现为 4.94x，靠 EBITDA 增长而非去杠杆改善）。
- 最刺眼的一笔账：**$3,046M 花出去，净股本只少了 1.376M 股——每净减 1 股花 $2,214，而现价 $704.55。** 这不是回购，是"用 6% 利率的债务，给股权激励兜底"。
- 结果：股东权益 -$3,873M，流动比率 **0.99**，利息覆盖 **5.79x**（FY25 7.56x）。**容错空间已经归零，而且是自己选的。**

情景不是拍脑袋，是按**收入三块拆**（按揭评分 $960M 估／非按揭评分 $692M／软件 $883M）：

**三种 WACC 下的加权结果**：

**关键观察：现价 $704.55 高于 10% 口径下的全部三情景（含乐观 $606）**，只在 9% 口径的乐观情景（$748）之上还有空间。也就是说——**市场今天的定价，等于"用低于 10% 的折现率，押注乐观情景"。**

### ③ 反向 DCF：现价在假设什么

| 口径 | 现价隐含 |
|---|---|
| EV / FY26 FCFF | **20.2x**（$20.14B / $998M） |
| WACC 10% + tg 3% | 需 FY28–31 FCFF **CAGR +14.1%** |
| WACC 10% + tg 4% | 需 **+10.1%** |
| WACC 9% + tg 3% | 需 **+9.0%** |
| WACC 9% + tg 4% | 需 **+4.5%** |

**翻译**：在库内 10% 口径下，现价要求 FICO 在"按揭退化"之外，连续四年 FCFF 复合 **+14.1%**——比乐观情景（+8~9%）还高一档。在风险匹配 9% 口径下，只需 +4.5~9%，即"乐观情景"即可成立。**这个 80 个百分点的差距，全部来自由谁折现，而不是由生意走向来折现。**

### ④ 交叉验证（给乐观方向留的余地）

| 锚 | 数值 | 含义 |
|---|---|---|
| **FCFE / Ke 交叉** | Ke 10.5% → **$661**；Ke 10% → $708；Ke 11% → $619 | 用股东现金流直接折现，现价**基本等于** Ke 10% 的公允价 |
| **零增长锚** | $1,034M / 10.5% = **$458**（扣 SBC 后 $376） | 现价是零增长价值的 **1.54x** |
| **SOTP 重置** | 非按揭评分 + 软件 + 按揭残值 − 总部费用 ≈ **$383–594** | 清算思维下，市场已把按揭按"大幅衰减但不归零"处理 |

**交叉验证的结论不是"便宜"，而是"没有余量"**：FCFE/Ke 10% 恰好把现价算成公允价（$708）；DCF/10% 说贵 40%。两个模型的差别就是**杠杆怎么算**——FCFE 假设债务永续滚存，FCFF/10% 把 6% 的债务成本全额计入。**在 FY28 有 $1.75B 到期墙的现实下，我更信后者。**
