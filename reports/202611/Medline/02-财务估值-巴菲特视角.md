# 02 财务与估值：巴菲特视角

> **一句话结论**：把 2018 年 340 亿美元 LBO 留下的会计噪音剥掉，Medline 是一台**质量不错、现金流真实、杠杆可控的复利机器**；但公众股东今天付的是 18 倍 EBITDA / 25 倍调整后市盈率，对应自由现金流收益率仅 3.4-4.0%，**没有安全边际**。
> **评分：3.0 / 5.0**

---

## 一、先处理"会计噪音"：GAAP 数字为什么难看

| 失真来源 | 金额/影响 | 性质 |
|---|---|---|
| 商誉 80.7 亿 + 无形资产 133.8 亿 = **214.5 亿** | 占总资产 53.4% | 2018 年 LBO 的购买价格溢价，**不产生现金流** |
| 无形资产年摊销 | 约 7.0 亿/年（9M26 5.29 亿） | 非现金，但**税务上可抵扣**（资产交易结构） |
| 债务利息 | TTM 5.39 亿（9M26 3.73 亿，同比 -42.3%） | IPO 募资偿还 88 亿 term loan 后大幅下降 |
| up-C 结构下 NCI | 9M26 归属 NCI 3.12 亿 | Class B 对应 PE 的 LP 份额，**已在 13.16 亿总股本内** |
| TRA 负债 | **44.03 亿** | 未来税盾的 **85% 归 PE 股东**，真实经济负债 |
| 一次性项 | 关税退款 +3.24 亿、Tracy 火灾 -3.16 亿 | 均不影响长期盈利能力 |

**关键换算**（TTM 或 FY26E，百万美元）：

| 口径 | 净利润 | EPS | 说明 |
|---|---:|---:|---|
| GAAP 归属 | 573 | $0.65 | 被摊销 + 利息 + NCI 压制 |
| **Adjusted（公司口径）** | 约 2,100 | **约 $1.55** | 加回摊销、SBC、一次性项 |
| 一致预期 FY26E | — | $1.57 | 含关税退款约 $0.25 |
| 一致预期 FY26E（剔退税） | — | 约 $1.32 | 可持续经营口径 |

> **巴菲特式提醒**：同一个公司，GAAP 市盈率 61 倍、调整后 25 倍、剔除一次性 30 倍。任何用单一 PE 下结论的分析都不成立——**必须用自由现金流和投入资本回报率做锚**。

---

## 二、回报率：分成"账面"与"生意"两个世界

| 指标 | 数值 | 计算基础 |
|---|---:|---|
| 报告 ROE（归属） | **4.9%** | TTM 归属净利 5.73 亿 / 归属权益 118.0 亿 |
| 报告 ROIC | **6.1%** | FY26E NOPAT 17.5 亿 / 投入资本 285.2 亿（权益+NCI+净债） |
| **剔除商誉/无形后的 ROIC** | **约 24.8%** | 17.5 亿 / （285.2 − 214.5）= 70.7 亿 |
| 增量资本回报（2023→2026E） | 约 25-30% | Adj. EBITDA +5.8 亿，三年 capex 约 15 亿 + 营运资本 |
| 利息覆盖（Adj. EBITDA/利息） | 6.7x | 36.0 亿 / 5.39 亿 |
| 净杠杆 | **2.5x** | 净债 91.4 亿 / TTM Adj. EBITDA 36.0 亿 |
| 毛利率 | 26.1%（9M26）| 同比 -100bp |
| 经营利润率 | 5.8%（9M26）| 同比 -290bp；剔除 Tracy 火灾（3.53 亿）后 7.3% |
| FCF / Adj. EBITDA | **63%**（FY26E 21.1 / 33.5） | 资本开支仅占销售 1.9% |

**结论**：
- **生意本身很好**——剔除购买溢价后 24.8% 的 ROIC，说明它每投入 1 元能赚回 0.25 元税后经营利润，且资本开支极轻（1.9% 销售）。
- **账面很难看**——因为公众股东"继承"了 PE 在 2018 年支付的 340 亿美元价格。**这是买入价格问题，不是生意问题。** 巴菲特会把它归类为"great business, but I'd have to pay for the sponsor's gain"。
- **杠杆可控但不轻松**：2.5x 净杠杆、利息覆盖 6.7x，在医疗分销行业属中性；若 EBITDA 下滑 20%，杠杆升至 3.1x，将限制回购与并购空间。

## 三、现金流质量：三个必须验证的点

### 1）营运资本是"增长税"
- 存货 48.1 亿（占 TTM 销售 15.7%）、应收 37.9 亿（12.4%）——收入每增长 10%，约需多占用 8% 增量销售的营运资本。
- 9M26 经营现金流 21.52 亿中，含"有利的营运资本"与关税退款；**剔除后可持续 OCF 约 17-18 亿**。
- 因此 FCF 的真实基线是 **15.5-18 亿**，而非含退税的 18.8 亿。

### 2）资本开支是"必须花的钱"
- 9M26 capex 3.48 亿（自动化、新 DC、kitting 产能），FY25 5.23 亿；管理层明确要继续投自动化。
- 1.9% 销售的 capex 强度在分销行业里偏低（对比固定资产 47.3 亿、29M sq ft），意味着**未来几年 capex 可能上台阶**（新 DC + 自动化改造），FCF 会被吃掉一部分。这是估值模型里最容易乐观的地方。

### 3）TRA 是"看不见的分红"
- 44.03 亿 TRA 负债：未来税务节省的 85% 支付给 PE 股东。按 15 年支付、折现率 8% 估算，现值约 **25-28 亿**（按 2.6 亿计入模型），相当于每股 **约 $2.0**。
- 巴菲特会直接把这块从内在价值里扣掉——它不是会计科目，而是**真金白银流向别人的现金流**。

## 四、DCF：把增长和利润率拆开算

### 关键假设

| 变量 | 基准情景 | 依据 |
|---|---|---|
| 起点收入（FY26E） | 314.1 亿 | 一致预期 |
| 收入增长（2027-2035） | 7.8% → 3.4% 线性递减（10 年） | 份额提升 + 人口 + SAM 渗透；末期向名义 GDP 收敛 |
| Adj. EBITDA 利润率 | 10.7% → 13.1% | 品牌渗透 + 自动化 + 总部费用摊薄；2026 为关税/费用低谷 |
| 折旧摊销 | 销售的 3.4% | TTM 10.3 亿 |
| 资本开支 | 销售的 1.9% | 历史 1.8-1.9% |
| 营运资本占用 | 增量销售的 6% | 历史 6-8% |
| SBC（视为现金费用） | 销售的 0.35% | TTM 1.08 亿 |
| 现金税率 | 23% | 9M26 有效税率 23.7% |
| **WACC** | **9.0%**（敏感性 8.0-10.0%） | Beta ~1.1、rf 4.2%、ERP 4.5%、债务成本 4.8% 税后 |
| 永续增长 | 3.0% | |
| 扣除项 | 净债 91.4 亿 + TRA 现值 26 亿 | 不扣 NCI（Class B 已在股本内） |

### 结果

| 情景 | 概率 | 核心假设 | 每股价值 |
|---|---:|---|---:|
| **熊市** | 25% | 有机增长降至 5.5%→3%、利润率卡在 11.2%（GPO 价格战 + 关税常态化）、WACC 9.5% | **$19.2** |
| **基准** | 50% | 增长 7.8%→3.4%、利润率 10.7%→13.1%、WACC 9.0% | **$31.5** |
| **牛市** | 25% | 增长 10%→4%、利润率升至 14.5%（品牌渗透 + 溢价能力）、WACC 8.5% | **$49.3** |
| **概率加权** | | | **$32.9** |

### 敏感性矩阵（基准经营假设，每股美元）

| WACC \ 永续增长 | 2.5% | 3.0% | 3.5% |
|---|---:|---:|---:|
| 8.0% | $37.0 | $40.1 | $43.9 |
| 8.5% | $32.9 | **$35.4** | $38.4 |
| 9.0% | $29.5 | **$31.5** | $33.9 |
| 9.5% | $26.6 | $28.2 | $30.1 |
| 10.0% | $24.0 | $25.4 | $27.0 |

> **现价 $39.64 隐含的内部收益率（IRR）约 8.1%**（基准经营假设下让 DCF 等于现价的折现率）。这正好等于我们对这家公司股权资本的要求回报下限——**意味着现价"刚刚够本"，没有任何安全边际**。

### 交叉验证（倍数法）

| 方法 | 倍数 | 隐含每股 |
|---|---:|---:|
| EV / FY27E Adj. EBITDA（37.2 亿） | 15x | $33.5 |
| | **17x** | **$39.2** |
| | 19x | $44.9 |
| P / FY27E Adj. EPS（$1.56） | 22x | $34.3 |
| | **25x** | **$39.0** |
| | 28x | $43.7 |

**倍数法说"公允"，DCF 说"贵 25%"。** 差异的根源是：市场用 EBITDA 估值（忽略利息、税、营运资本、TRA），而 DCF 把这些全部扣掉。对于一门 FCF/EBITDA 只有 63%、且要把 85% 税盾让渡给 PE 的生意，**DCF 更接近真实**。

## 五、估值结论与买卖区间

| 项目 | 数值 |
|---|---:|
| **内在价值中枢（目标价）** | **$37.5**（DCF@8.5% $35.4 权重 40% + EV/EBITDA 17x $39.2 权重 30% + P/E 25x $39.0 权重 30%） |
| 合理区间 | $33 – $42 |
| 现价（2026-11-06） | $39.64（**较目标价高约 6%**） |
| **击球区（买入）** | **≤ $30**（对应 15x FY27E EBITDA、约 19x PE、DCF@9.5% 的熊市上沿） |
| **减持区** | **≥ $48**（牛市 DCF $49.3 下沿、52 周高点 $50.88 附近） |

## 六、巴菲特式评分

| 维度 | 评价 | 得分 |
|---|---|---|
| 生意质量（ROIC 剔除商誉 24.8%） | 优秀 | 4.5 |
| 账面回报（ROE 4.9% / ROIC 6.1%） | 被购买溢价拖累 | 2.0 |
| 现金流真实性（FCF 15.5-18 亿） | 真实，但被营运资本与 capex 侵蚀 | 3.5 |
| 资产负债表（2.5x、6.7x 覆盖） | 可接受，不宽裕 | 3.0 |
| 资本配置（回购 + 降杠杆 + 无股息） | 方向对，但在 25x PE 回购是"用股东钱买贵资产" | 2.5 |
| 管理层可预测性 | 上市首年，指引可信度尚可（Q3 上调收入、维持 EBITDA） | 3.0 |
| **估值（现价无折让）** | 8.1% 隐含 IRR ≈ 要求回报，**零安全边际** | 2.0 |
| **加权** | | **3.0** |

**巴菲特会怎么说**：
> "这是一家我会愿意放在'太贵'篮子里的公司。它的生意我看得懂，现金流我也相信，杠杆不算危险。但它 2018 年被 PE 以 340 亿美元买走，今天市场给它 613 亿美元的企业价值——**PE 赚的钱，就是我多付的钱**。除非它跌到 30 美元以下，否则我宁愿等。"
