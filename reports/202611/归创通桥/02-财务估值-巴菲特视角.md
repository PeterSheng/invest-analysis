## 1. 生意质量：一门高毛利、极轻资产、但被现金"泡住"的好生意

| 指标 | 数值 | 口径 / 判读 |
|---|---|---|
| 毛利率 | **73.4%**（H1'26） | 同比 +2.2pct，**创新高**；TTM 营收 12.0756 亿 |
| TTM 经营利润率 | **22.77%** | 经营溢利 2.7502 / 营收 12.0756 |
| TTM 净利率 | **25.25%** | 净利 3.0488——**高于经营利润率 2.48pct，差额来自利息** |
| **报表 ROE** | **10.25%** | 3.0488 / 权益 29.7567 |
| **剔现金 ROIC** | **32.34%** | 剔现金净利 2.3605 / 剔现金投入资本 7.2988 |
| CapEx / 营收 | **7.6%** | TTM CapEx 0.9226；H1'26 仅 5.2% |
| 应收周转 | **< 10 天** | 应收 0.3558，占营收 2.9% |
| 销售费率 / 研发费率 | 18.2% / **16.8%** | 研发费 **-12.5%**（绝对额 1.2160→1.0637） |
| 有效税率 | 12.2% | — |

**ROE 10.25% 与 ROIC 32.34% 的 22pct 缺口，必须解释清楚，否则整份报告读错。**

权益 29.7567 亿里有 **22.4579 亿是净现金（占 75.5%）**，这部分资产年化只赚 0.7839 亿（税前收益率约 **3.28%** = 0.7839/23.8894）；真正压在生意里的投入资本只有 **7.2988 亿**。于是：

- 报表口径：3.0488 / 29.7567 = **10.25%** → 一个"平庸公司"的数字；
- 剥掉现金：2.3605 / 7.2988 = **32.34%** → 一个"极优公司"的数字。

**同一个生意，因为 46.8% 的市值是现金，ROE 被稀释掉了三分之二。** 这不是生意的问题，是资本结构的问题——而资本结构归管理层决定，这就是本报告第 3 节要审的东西。注意这个 32.34% 没有水分：研发 1.0637 亿是**全额费用化**的（未资本化），所以 7.2988 亿的投入资本是"真实占用资本"，高 ROIC 不是会计制造的。

**判断：是，这是一门好生意——但有三个前提条件。**

1. **毛利率守住 70%+**。73.4% 是历史新高，但它建立在集采尚未全面续约的定价环境上（V7 未到验证时点）。毛利率掉 5pct，经营溢利即从 2.7502 掉到约 2.15（估，按 TTM 营收 12.0756 ×5pct = 0.60），剔现金 ROIC 从 32.34% 跌到约 **25%**（估）。
2. **研发不再继续被压缩**。收入 +31.1% 而研发 -12.5%，经营溢利 +99.2%——**利润弹性里"降费"的成分大于"规模效应"**（数据包 §4 判定：经营杠杆成分 < 50%）。研发费率 16.8% 若再降到 14%，报表会更好看，生意会更差。医疗器材公司的护城河是管线，不是当期费率。
3. **增长引擎能接上**。神经介入 +20.4%（连续两轮减速），外周 +40.3%（加速）。若神经跌破 15% 而外周不能维持 25%+，7.2988 亿资本对应的 32.34% 就无法维持（估）。

物理基础是扎实的：CapEx/营收 7.6%、应收 <10 天、存货/营收 19%、应付 2.4529 亿（占用上游资金）。**这门生意几乎不需要再投入就能增长**——这正是巴菲特最爱的形态（See's Candies 型），也是 32.34% ROIC 的来源。

## 2. 现金流质量：现金转化优秀，但"四分之一的利润不是生意赚的"

| 指标 | 数值 | 判读 |
|---|---|---|
| TTM OCF | **4.6411** | 含已收利息 **0.7839** |
| TTM 净利 | **3.0488** | — |
| **OCF / 净利** | **1.52x** | 表面优秀 |
| TTM CapEx | 0.9226 | 占营收 7.6% |
| TTM FCF（含息） | **3.7185** | = 4.6411 − 0.9226 |
| **已收利息占 OCF** | **16.9%** | 0.7839 / 4.6411 |
| **已收利息占净利** | **25.7%** | 0.7839 / 3.0488 |
| TTM 经营性 FCF（剔息） | **2.9346** | DCF 口径 FCF0 |
| 经营性 FCF / 净利 | **0.96x** | 2.9346 / 3.0488 |
| 经营性 FCF / 剔息净利 | **1.24x** | 2.9346 / 2.3605 |

**第一句必须说重：0.7839 亿利息 = 净利的 25.7%，这部分不是卖支架赚的，是 22.46 亿现金躺在定存里赚的。**

拆开看三件事：

1. **1.52x 的 OCF/净利是"被利息抬起来的"**。剔掉利息后，经营性 FCF 2.9346 只覆盖净利 3.0488 的 **0.96x**——也就是说，扣掉现金利息，利润几乎 1:1 变成现金，**没有"纸面利润"的迹象，但也没有超额现金创造**。用剔息净利做分母才是真实转化率：**1.24x**，仍然健康（>1 意味着折旧摊销与营运资本释放提供了额外现金）。
2. **利息这块钱很脆弱，而且正在被主动削弱**。0.7839 亿对应 23.8894 亿现金类资产、税前 3.28% 的收益率。11-06 那笔交易把 7.58 亿现金换成收益率 **1.84%** 的先健股权（净现金因互换而大体持平，利息收入不会立刻消失，但**同一笔钱的赚钱能力从 3.28% 掉到 1.84%**，年化少收约 0.11 亿税前（估））。若未来现金继续这样部署，"利息贡献 25.7%" 会逐年缩水，净利率 25.25% 会向经营利润率 22.77% 靠拢。
3. **经营性 FCF 2.9346 的质量是"干净"的**。它不含利息（不重复计算现金）、不含一次性项目（无形资产 2.2994 亿是 Optimed 分销权，非现金支出加回后不影响 FCF 口径）、CapEx 0.9226 已全额扣除。与首轮 FCF0 2.98 相差 -1.5%，**两轮口径衔接一致**，说明这个 2.93 是真实现金盈利能力，不是本轮临时算出来的。

**判断：现金流质量"强"，但强度有 25.7% 来自非经营性来源。** 剔息后的 2.9346 才是可以拿去 DCF 的东西——本报告第 4 节所有 DCF 都用它，不用 3.7185。

## 3. ★ 资本配置审计：从"精巧"到"粗放"的单调恶化

### 3.1 三次部署对照

| 时点 | 动作 | 金额 | 定价 | 年化收益率 | 性质判定 |
|---|---|---|---|---|---|
| 2026-01 | Optimed 49% + €500 万可转股贷款 | €1838 万（100% 隐含 3.04 亿） | 未量化 | 渠道入口（不可直接量化） | **期权式**：分步、可转股、留 51% 期权 → **精巧** |
| FY25–H1'26 | 回购股份 | **1.12 亿**（半年 ≈ FY25 全年 94%） | 均价约 20 HKD | 自家股权 **5–9.5%**（估） | **低位回购** → **正确**（但仅约市值 2%） |
| **2026-11** | **认购先健科技 10%** | **7.58 亿**（8.90 亿 HKD @1.60） | 溢价 **18.5%**（对 1.350） | **1.84%** | **买不可控同业、不并表、无协议披露** → **可疑** |

三笔的方向是一条直线：**期权式精巧收购 → 常规低位回购 → 粗放交叉持股。** 这不是"某一笔失误"，是**资本配置能力的单调恶化**——这才是本轮下调的唯一硬理由，也是唯一但决定性的扣分项。

### 3.2 先健 10%：把数字摊开

| 项 | 数值 |
|---|---|
| 认购成本 | **7.58 亿 RMB**（5.56 亿股 @1.60，占先健扩大后 10.00%） |
| 11-20 市值 | 5.56 亿股 × 1.350 = 7.51 亿 HKD = **6.39 亿 RMB** |
| 浮动盈亏 | **-1.18 亿（-15.6%）** |
| 归属净利（10%） | **0.1395 亿/年**（先健 TTM 净利 1.637 亿 HKD，估） |
| **成本收益率** | **1.84%/年**（0.1395/7.58） |
| **成本隐含 PE** | **54.3x** |
| 市价隐含 PE | 45.8x |

一家 PE 45.8x、收益率 1.84% 的资产，用 54.3x 去买，还溢价 18.5%——**买的那一刻就已经亏了 15.6%**（-1.18 亿 = TTM 净利的 38.7%、净现金的 5.3%）。

### 3.3 「负套利」测算：用 1.84% 替换 9.48%–32.34%

| 同一笔 7.58 亿的去处 | 年化收益 | 收益率 |
|---|---|---|
| **实际：先健 10%** | **0.1395** | **1.84%** |
| 留作定存（按实际观察 0.7839/23.8894） | 0.2487（税后 0.2183） | 3.28% |
| **回购自家股票（剔现金盈利收益率）** | **0.7186** | **9.48%** |
| 投入主业（按剔现金 ROIC，上限情形，估） | 2.4513 | 32.34% |

- 相对"回购自家"：每年少赚 **0.5791 亿** = TTM 净利的 **19.0%**；按 10% 资本化 = **5.79 亿价值** = 市值的 **10.8%**、每股 **1.84 HKD**（估）。
- 相对"投入主业"（上限情形）：每年少赚 **2.3118 亿** = 净利的 **75.8%**（估）。
- **连定存都比不过**：1.84% < 3.28%。这不是"回报率偏低"，是"回报率低于无风险替代品"。

管理层用**最有价值的资产（自家 8.37x 剔现金 PE 的股权 + 3.28% 的现金）**，去买**一个自己不控制、不并表、无法干预其资本配置的第三方 10%**。这是"消灭资本回报率"的标准操作。对照 §6.5 三种解释：**若只有股权、无协同协议（V1 未验证，最关键缺口），解释 3（悲观）成立，扣分坐实**。

### 3.4 摊薄量化：每股盈利 -10.8%，而每股现金也是 -10.8%

| 指标 | 交易前 | 完成后 | 变化 |
|---|---|---|---|
| 股本 | 3.2984 亿股 | **3.6964 亿股** | **+12.07%** |
| EPS（TTM 3.0488） | 0.9243 | **0.8248** | **-10.8%** |
| PE（17.07） | 15.73x | **17.63x** | +12%（**估值被动抬升**） |
| 归属权益 | 29.7567 | 36.04（+7.47 净入 −1.18 减值） | +6.28 |
| 报表 ROE | **10.25%** | **8.46%** | **-1.79pct** |
| 剔现金投入资本 | 7.2988 | **8.62** | +1.32 |
| **剔现金 ROIC** | **32.34%** | **27.39%** | **-4.95pct** |
| 每股净现金 | 7.99 HKD | **7.13 HKD**（22.4579/3.6964） | **-10.8%**（与股本同幅摊薄） |
| 每股非经营资产（含先健） | 7.99 HKD | **9.16 HKD** | +1.17（+14.6%） |

两点必须并读：

1. **"每股非经营资产 +1.17 HKD" 是加法错觉。** 净现金本身没变（互换式，净影响 -0.11 亿），股本 +12.07%，所以**每股净现金实际从 7.99 降到 7.13（-10.8%）**；+1.17 全部来自把 6.39 亿先健股权塞进分子。而 6.39 亿是浮亏 1.18 亿后的市价——**先健再跌 15%，这 1.17 就归零**。
2. **每股价值守恒检验**：交易前 每股经营业务定价 =（47.96−22.4579）/3.2984 = 7.7305 RMB = **9.08 HKD**，加净现金 7.99 = 17.07；完成后 =（53.75−28.85）/3.6964 = 6.737 RMB = **7.91 HKD**，加非经营 9.16 = 17.07。**总价值一分没多，只是每股"生意"从 9.08 被摊到 7.91（-12.9%），换成了每股"资产"。**

### 3.5 「负债 +113%」不是财务风险

总负债 3.4383 → 7.3402（**+113%**），看着吓人，必须三分穿透：

| 类别 | 金额 | 判定 |
|---|---|---|
| **有息负债**（短贷 0.8677 + 长贷 0.2460 + 融资租赁 0.3178） | **1.4315** | 占市值（完成口径 53.75）**2.7%**；无债券、无透支 → **财务风险≈0** |
| **或有 / 递延（Optimed）** | **2.7864**（其他非流动 2.6770 + 递延税 0.1094） | 未来**现金流出期权**，非当期债务；1–2 年内可能行权 |
| 经营性占款 | +0.28 | 随收入正常增长 |

真正要盯的不是负债，是**承诺表**：Optimed 剩余 51% 或有对价 **2.68 亿** + 先健 **7.58 亿 = 10.26 亿 = 净现金的 45.7%**（占完成口径市值 19.1%）。**可自由支配的净现金只剩 12.20 亿**——这一条直接决定第 4 节"净现金全额计入"的假设能打几折。

## 4. ★ 估值安全边际：底部很厚，顶部无保证

### 4.1 倍数表（口径锁死：完成口径 3.6964 亿股 / 市值 53.75 亿）

| 指标 | 数值 | 说明 |
|---|---|---|
| 静态 PE（TTM 3.0488） | **15.73x**（现价口径）/ **17.63x**（完成口径） | 后者含摊薄，是"你实际付的价" |
| **剔净现金 PE** | **8.37x** | (47.96−22.4579)/3.0488 |
| **剔全部非经营 PE** | **8.17x** | (53.75−28.85)/3.0488 |
| PB | **1.61x**（完成后 1.49x） | 权益 29.7567 / 完成 36.04 |
| 经营 EV / 经营溢利 | **9.05x** | EV 24.90 / 2.7502 |
| **经营 EV / 经营性 FCF** | **8.48x** | 24.90 / 2.9346 |
| **经营 FCF Yield（剔现金）** | **9.38%** | 2.9346 / 31.2921 |
| **剔现金盈利收益率** | **9.48%** | 2.3605 / 24.90 |
| FCF Yield（含息 3.7185） | 6.92% | 含利息，偏乐观 |
| 盈利收益率 | 5.67% | 3.0488 / 53.75 |

**读法**：17.63x 的静态 PE 与 8.17x 的剔非经营 PE，差了 2.16 倍——**这 2.16 倍全部是"资产"，不是"生意"**。市场用 24.90 亿（每股 7.91 HKD）给一家营收 +27.7%、ROIC 32.34%、经营 FCF 2.9346 亿的公司定价：8.48x 经营 EV/FCF、9.48% 剔现金盈利收益率，**在一个 10% 的 WACC 世界里，只有"未来现金流萎缩"才能自圆其说**（见 4.5 反向 DCF）。

### 4.2 净现金四层估值阶梯（净现金/市值 46.8% ≥ 40%，强制走）

| 层 | 定义 | 每股（HKD） | vs 现价 17.07 |
|---|---|---|---|
| ① 现价 | 市场报价 | **17.07** | — |
| ② **概率加权 IV**（净现金全额计入） | 25/50/25 三情景 DCF + 非经营 28.85 | **26.25** | **+53.8%** |
| ③ **零增长锚** | 经营性 FCF 2.9346 永续零增长（tg 3%）+ 非经营 | **22.88** | **+34.0%** |
| ④ **最坏**（现金按 0 + 悲观情景） | 悲观经营 EV 单独定价、非经营归零 | **12.05** | **-29.4%** |

逐层说：

- **层② 26.25**：三情景加权，**-53.8% 的空间里 60% 以上来自"净现金全额可及 + 三情景假设成立"两个条件**（数据包 §7.7）。所以 **IV 高于现价 ≠ 买入**——这是本报告最重要的一句限定。
- **层③ 22.88 是"最保守的正面锚"**：主业**完全不增长**，2.9346 亿永续 + 28.85 亿资产，仍值 22.88，现价折价 34%。这个锚的可靠性最高，因为它不含任何增长假设，只赌两件事：FCF 不掉、现金能到手。
- **层④ 12.05 是"最保守的负面锚"**：只给主业定价（悲观情景 37.94 亿）、现金与先健全部按 0。**现价 17.07 相对最坏锚有 29% 的缓冲**。
- **底部区间厚、顶部区间虚**：下有 +29%（对最坏）、上有 +53.8%（对加权 IV），但**中间的 24.9 亿主业定价完全取决于"这 22.46 亿现金还会怎么花"**。这就是为什么本报告把第 3 节的资本配置放在第 4 节估值之前。

### 4.3 DCF 三情景（WACC 10% / tg 3% / 5 年显性 / FCF0 = 2.9346）

| 情景 | g1 | 调整 | 经营 EV | IV（HKD） | vs 现价 | 概率 |
|---|---|---|---|---|---|---|
| 悲观 | 0% | 扣 Optimed 或有对价 2.68 | 37.94 | **21.21** | +24.2% | 25% |
| 基准 | 8% | 神经 8% + 外周 25% 混合衰减 | 53.29 | **26.09** | +52.8% | 50% |
| 乐观 | 15% | FDA 双证 + 70 国 + 先健平台化 | 70.73 | **31.62** | +85.2% | 25% |
| **加权** | — | — | — | **26.25** | **+53.8%** | 100% |

- **基准 g1=8% 对照 TTM 营收 +27.7%、H1'26 +31.1%：隐含"5 年从 31% 衰减到 8%"，是明显保守的假设**（基数小、海外 27→70 国、净现金占比高）。
- **但 g1=8% 有一个隐藏前提：钱留在主业或返还股东。** 若继续买 1.84% 的资产，8% 就是空数——所以 DCF 的"保守"与资本配置的"可疑"是同一枚硬币的两面。
- **现价 / 加权 IV = 17.07 / 26.25 = 65%**，即 35% 折价。
- 悲观情景仍 +24.2%（21.21 vs 17.07）：**即使主业零增长、还扣掉 2.68 亿或有对价，现价仍低于 IV**。这是本轮估值结构的核心。

### 4.4 敏感性矩阵（g1=8%，IV in HKD）

| WACC \ tg | 2.5% | **3.0%** | 3.5% |
|---|---|---|---|
| 9% | 27.7 | **29.0** | 30.4 |
| **10%** | 25.2 | **26.1** | 27.1 |
| 11% | 23.3 | **23.9** | 24.7 |

**全表 23.3–30.4，中位数 26.1。** 最苛刻格（WACC 11% + tg 2.5%）仍 23.3，比现价高 **+36%**。**估值的容错来自 46.8% 的现金垫，不来自增长假设**。

注意 WACC 从 9% 拉到 11%、tg 从 3.5% 压到 2.5%，IV 仅从 30.4 降到 23.3（-23%），**远小于现金流折现的常规敏感度**——因为一半价值是现金，而现金不打折。

同时提醒：年化波动率 **38.3%**、β 0.68 但事件日相关性仅 0.33（β 不可作风险代理）。**±15% 以上的估值容错是必须的**——这也解释了为什么现价能贴着 52 周低 16.80（仅 +1.6%）。

### 4.5 反向 DCF：现价在定价什么

| 指标 | 数值 |
|---|---|
| 经营 EV（完成口径） | **24.90 亿** |
| 经营 EV / 经营性 FCF | **8.48x** |
| **现价隐含 5 年 FCF 增速 g1** | **-9.4%**（之后 3% 永续） |
| EV 法隐含可持续 FCF | **1.69 亿 = 当期 2.9346 的 58%** |

**现价隐含"主业 FCF 未来五年复合 -9.4%，且永续只剩 58% 的现金流"。** 这是"主业持续萎缩 + 现金继续被乱花"的双重悲观定价，而不是"便宜"能解释的东西。**换句话说：市场不是不知道这家公司便宜（8.37x 剔现金 PE 是公开信息），市场是不相信这 22.46 亿会回到股东手里。** 这是本轮最关键的单一洞察，也是巴菲特框架下唯一真正需要回答的问题：**资本配置的可信度，能否被一纸协同协议或一次回购计划修复。**

## 6. 「如果不是上市公司，我愿意买整家公司吗」

把结构摆出来（完成口径，市值 53.75 亿）：

| 你买到的东西 | 金额 | 说明 |
|---|---|---|
| 净现金 | **22.46 亿** | 现金类 23.8894 − 有息 1.4315；无受限披露；有息仅占市值 2.7% |
| 主业年赚 | **3.05 亿**（剔息 2.36 亿） | 经营性 FCF 2.9346；CapEx 仅 0.92 亿 |
| **已锁承诺** | **-10.26 亿**（净现金的 45.7%） | Optimed 或有 2.68 + 先健 7.58（后者年赚 0.1395，收益率 1.84%） |
| 可自由支配净现金 | **12.20 亿** | 22.46 − 10.26 |

**答案：有条件的「是」。**

**为什么是"是"**：扣掉 12.20 亿可动用现金，你为"主业 + 已锁承诺"付 41.55 亿；再扣掉已锁承诺的市价（先健 6.39 + Optimed 期权价值未量化，按 0 保守），你为一家年赚 3.05 亿（经营 FCF 2.9346）、ROIC 32.34%、毛利率 73.4%、应收 <10 天、CapEx 7.6% 的生意付约 **35.16 亿** = **11.98x 经营 FCF、8.35% FCF 收益率**（估）。在 10% 的 WACC 下这不贵，而且**作为私人所有者，我可以直接否决"用 7.58 亿买 1.84% 同业"这类交易**——非上市公司身份在这里是优势，不是劣势。
**为什么是"有条件"**——三个条件，缺一即"否"：

1. **集采不破坏 73.4% 的毛利率**（V7 未到验证时点）。毛利率是这门生意 32.34% ROIC 的唯一支柱。
2. **剩下 12.20 亿不再投向 <3.28% 的资产**。若再来一笔"先健式"交易，可动用现金归零，我付的 41.55 亿就变成"为 10.26 亿低回报资产 + 主业"付溢价——那时答案是"否"。
3. **神经介入不失速到负增长**。+20.4% 已连续两轮减速，若转负，2.9346 亿的永续性就要打折，零增长锚 22.88 也不成立。

**一句话：这家公司的资产负债表我愿意买，利润表我愿意买，现金流量表我愿意买；我不敢买的是"管理层下一笔交易"。** 这就是为什么 22.46 亿净现金不能按 100% 计入——数据包 §8.2 给的"现金可及成立度 55–60%（估）"，落在估值上就是 22.88（零增长锚）与 26.25（加权 IV）之间那道 3.37 HKD 的缺口。

## 8. Follow-up：一个最直击痛点的问题

> **先健 10%（7.58 亿、成本收益率 1.84%）+ Optimed 或有对价 2.68 亿，已锁净现金 45.7%。请管理层给出一个可验证的门槛：这笔 1.84% 的资产，在何种商业协同条款（渠道互用、联合研发、订单承诺，须量化到金额或成本节约）下，其综合回报能达到公司自身 9.48% 的剔现金盈利收益率？若答不出这个门槛，为什么不把 7.58 亿用于回购自家 8.37x 剔现金 PE 的股票？**

回购算术（估）：不增发、以现有现金 7.58 亿按 17.07 回购 → 股数 3.2984→2.7771 亿，扣税后少收利息 0.2183 亿，EPS 从 0.8248 增至 **1.0193（+0.19 元 / +23.6%）**。**同一笔钱，一个方向让每股盈利 -10.8%，另一个方向让每股盈利 +23.6%——这是本轮的 34 个百分点之差。**

这道题的答案决定三件事：资本配置分是 2.25 还是 3.00、22.46 亿净现金能否按 100% 计入（→ 22.88 vs 26.25）、以及现价隐含的 -9.4% 五年 FCF 增速是"过度悲观"还是"合理定价"。**V1（是否存在协同协议）是本轮唯一决定性的未验证项。**
