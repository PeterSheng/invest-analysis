## 核心结论（5 条）

1. **利润是省出来的**：Q3'26 OPM 28.77%（+566bp），其中 S&M -16.5% 省下 50.1 亿 = 营业利润增量的 82%；同期营收 +0.06%（Q2 还是 +8.05%）。公司自证「增长是买来的」。
2. **Temu 被逐级加税**：欧盟 €3/件（2026-07-01，欧洲单量 -60%）+ €2/件（2026-11-01）+ DSA 罚 €200M（上限 6% 全球营收 ≈ ¥259 亿）。交易服务 -11.7% 与广告 +12.1% 并存，存在「真收缩 vs 科目搬家」两解（估真实降幅 -5~7%）。
3. **现金看得见、拿不到**：净现金 ¥4,506 亿 = 市值 55%，零股息、回购 0.53%/年、千亿扶持（¥333 亿/年）+ 新拼姆（规划 ¥1,000 亿）不披露 ROI。
4. **估值的真正分歧点**：DCF 给 $215.9（+158%），但 DCF 的两个前提（利润可持续、现金可及）恰是 $83.68 否定的两件事——158% 是分歧本身，不是安全边际。最坏情况（现金按 0 + 悲观）$101.69，仍有 21.5% 垫。
5. **唯一上修开关**：2027-03 的 Q4 财报里出现「首次派息」或「回购 ≥5% 净现金/年」，综合分可跳到 3.75+；若现金继续堆高且回购仍 <1%，答案就是「用股东的钱给第二个创业故事融资」。
