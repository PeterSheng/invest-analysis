# 01 商业模式视角（段永平）— 现代牙科 3600.HK

**报告日期：2026-11-06（价格截至 2026-11-06 13:45）**

段永平的核心三问：**这是门什么生意？别人为什么打不倒它？十年后它靠什么赚钱？**

---

## 1. 这是门什么生意？

一句话：**牙科诊所的"后台工厂"**。

牙医做一颗全锆冠，自己不做——扫描、建模、3D 打印、铸造、车瓷、上釉、抛光这十多道工序全部外包给牙科实验室。现代牙科就是全球这个"外包车间"里最大的那一个。

生意本质拆解：

| 要素 | 现实 |
|---|---|
| 客户 | 牙科诊所/牙医（B 端，分散） |
| 产品 | 定制化义齿（固定+活动占收入 90%+），每颗牙都是"一次性产品" |
| 竞争格局 | 全球 4000+ 家中国加工厂，极度碎片化；MDG 是全球最大集团 |
| 成本结构 | 原材料约占生产成本 80%，但真正的胜负手是**良率与效率** |
| 资本密集度 | CapEx 仅占收入 **1.7%**——轻资产 |
| 现金转化 | OCF/净利 1.15x——先款后货属性 |

**段式判断：这是好生意吗？** 定制化制造，非标、复杂、单价低、周转快，大公司懒得做、小公司做不大——天然适合"整合者"。它不是消费品品牌生意（没有终端定价权），本质是**效率型制造业**。这类生意的天花板是运营能力，不是品牌溢价。

## 2. 护城河：有，但是"运营型"而非"结构型"

| 护城河 | 强度 | 说明 |
|---|---|---|
| 数码化生产体系 | ★★★★ | 2007 年起投入 CAD/CAM，4 个数码化生产中心；国内口内扫描应用第一。数字化让"老师傅手艺"变成"流程标准"——这是 2023 年来毛利率 48.9%→58.1% 爬升 9.2pct 的直接原因 |
| 规模+集采成本 | ★★★ | 全球最大集团采购氧化锆等原材料，小实验室拿不到的价格 |
| 并购整合能力 | ★★★★ | 20 年整合 10+ 实验室品牌（Labocast/Permadental/Elysee/洋紫荆/Southern Cross/Hexa Ceram），买下当地"老牌子"保留客户关系，产能全球调度——香港市场占率 ~55% 就是这么滚出来的 |
| 客户转换成本 | ★★ | 牙医换实验室有摩擦但不高——**这是护城河最薄的一环** |
| 品牌 | ★★★ | 对牙医（B 端）有品牌；对消费者无品牌 |

**段式追问：它的竞争对手会怎样打它？** 义齿行业没有专利壁垒、没有监管牌照壁垒，护城河全在"运营效率+整合能力"。这意味着：**护城河是动态的**——一旦竞争对手数字化追平（伊士曼柯达案例的反面），超额利润会回归。但碎片化行业里，能把数字化+并购做到全球第一的组织能力本身就是稀缺资产。

## 3. 第二曲线：TrioClear 隐形矫治

- 2020 年推出自研品牌，FDA 510(k) 已获批，产线全自动
- 全球隐形矫治市场 $122 亿（2020）且 25%+ CAGR；中国双寡头（隐适美+时代天使 >80%）
- **段式判断**：这不是"憋大招"，是**免费的看涨期权**——义齿加工的核心工艺（口扫→数字化设计→3D 打印牙模→热压膜）与隐形矫治生产是**同一条产线的延伸**。别人做隐形矫治要先建产能，它本来就有。Even if 失败，成本只是营销费用；If 成功，$6B+ 市场多一个低价竞争者。期权费用极低、赔率高。
- 风险：双寡头的品牌与医生教育优势真实存在，TrioClear 目前份额极小，别把它当确定性增长计入估值。

## 4. 管理层与资本配置

- 上市以来持续并购但纪律可见：负债率从 2022 年 34% 降到 26.2%，商誉 11.6 亿占总资产 24%（可控但需持续盯减值）
- CapEx 1.7% + OCF 转化 1.15x + 分红率 ~35%：**赚到的钱大部分是真钱**
- 家族控股背景（吴氏，1954 年香港起家），决策链条短，但接班与治理透明度是港股家族企业的普遍减分项

## 5. 段式结论

> **"假牙生意"不是一个性感生意，但它是一个"看得懂"的生意：需求刚性（牙掉了不会自己长回来）、格局分散（赢家通吃整合）、效率即壁垒（数字化领先 5 年）。**

- 商业模式确定性：**中上**（B 端制造效率生意，无终端定价权）
- 护城河性质：运营型而非结构型——**需要持续验证，不可线性外推**
- 第二曲线：低费率期权，值 10-15% 估值弹性
- 段式一句话：**这生意赚的是辛苦钱，但赚得很稳、很真；买入它不是买品牌，是买一台"全球义齿整合机器"的运转效率。**
