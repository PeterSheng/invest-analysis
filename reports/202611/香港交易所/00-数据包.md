## §2 生意本质与管理层

- **一句话**：港交所不卖"金融"，卖的是**在中国资本管制之下、唯一合规可交易的离岸中国资产"过路权"**——牌照垄断下的成交量税。
- 收入模式：成交额抽成（交易费 + 结算费）+ 上市费 + 市场数据费 + 保证金投资收益（NII）。
- 监管架构：香港政府为最大股东（持股约 5.9%，且《证券及期货条例》限制任何单一股东投票权 ≤5%）；主席由港府委任，CEO 由董事会任命。
- 管理层：主席 **唐家成**（2025-04 接替史美伦）；CEO **陈翊庭**（Bonnie Chan，2024-03 上任，2026-08 获续约 3 年，基本年薪 1,200 万港元，2025 年总薪酬 3,778 万港元）。**非创始人体制**，管理层是职业监管者/运营者，无股权激励主导。
- 战略主线（2026）：① 固定收益及货币（FIC）市场建设；② 上市制度改革（不放松把关，Q1 新股首日上涨比例约九成）；③ 基础设施升级（ODP 衍生品平台、USM 无纸化、新股结算 T+1 已落地）；④ 北向/南向互联互通扩容（2026H1 北向 ADT 同比 +102%）。

## §9 结构性逆风与战略项目（2026H1 官方披露）

**NII（保证金投资收益）面临四重结构性压缩，这是本标的最重要的负面变量：**
1. **降息**：HIBOR 下行 → 保证金收益率下降。
2. **客户保证金框架（CMM）下调**：1.33x → **1.2x（2026-09-21 已实施）** → **1.1x（目标 2027-03）**；保证金基数缩小。
3. **手续费（handling fee）递减**：80bps → 70bps（2026-12-31 生效）→ 每年 -10bps → **50bps（2028 年末/2029 年初）**；向参与者支付的利息增加，NII 减少。
4. **非现金抵押品扩容**：接受北向债券通国债/政策性银行债/财政部离岸债作抵押（2026Q4 目标）→ 现金保证金减少。

2026H1 NII 25.60 亿（-11%）；主会话估 2026 全年 51.2 亿 → 2027E 47 → 2029E 约 38-40 亿。

**对冲这些逆风的结构性增长**：北向通 ADT +102%、IPO 募资 9M 3,880 亿创历史新高、ETP（ETF 日均成交 453 亿）、LME 商品 +27%、衍生品 ODP 平台上线、FIC 平台建设。

## §10 口径约定（全报告唯一口径，子报告引用须标节号）

1. **收入口径** = 港交所"收入及其他收益"（东财 F10 经营收入总额，与公司公告逐期吻合）；**不要**用 akshare 的 263.39 亿（那是"主要业务收入"，不含其他收益）。
2. **PE 主锚 = 正常化 PE（ADT 2,200 亿 → EPS 11.00 → 35x）**；TTM PE 24.66x 只作"峰值盈利 PE"参考，**不得**作为"便宜"的论据。
3. **ROE 必须双口径**：报表 35.4% / 剔除商誉 55.8%；**PB 8.73x 高不是问题**（ROE 35-56% + 90% 派息下的合理 PB），但也不能用 PB 做主要锚。
4. **有息负债 ≈2.25 亿**（含银行贷款、透支、融资租赁）；报表 1,629.9 亿"现金"绝大部分是客户保证金，**禁止**把它算成净现金/安全垫。
5. **收入/净利/股息全部为 HKD**，本标的无人民币折算问题。
6. 2026E 全年为**主会话估算**（Q4 ADT 2,150 亿假设），非公司指引；9M 及以前为实际披露。
7. DCF 类口径：全库统一 **WACC 10% / tg 3%**；本标的另附风险匹配口径（β≈1.1，r=9%）作对照，但**主口径仍是 10%**。
