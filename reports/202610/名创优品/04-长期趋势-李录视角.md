## 一、一句话结论

**文明级赛道（全球性价比消费 + 情绪消费）的 20 年长坡仍在，但"雪"的质地变了：海外引擎半年内失速（利润贡献 35-40% → 10-15%），把 20 年置信度从旧轮 ~70% 打到 ~55%。赛道高分不等于股票高分——中性 IV 19.8 ≈ 现价 19.87，安全边际归零，总分锚死 ≤3.25。旧轮 3.50 → 本轮 3.00。**

## 二、文明级赛道判断：20 年长坡是否仍在？

**判断：在。但长坡上跑的是公司，公司近一年把长坡跑出了波折。**

| 赛道要素 | 现状（数据包口径） | 20 年维度判定 |
|---|---|---|
| 性价比消费渗透率 | 中国自有品牌渗透率 5-10% vs 欧美 30-40%（**沿用旧轮口径**） | 缺口 25-35pct = 长坡核心，未被本轮证伪 |
| 情绪消费 | 泡泡玛特 H1'26 市值 2053.6 亿 HKD；THE MONSTERS 收入 44.54 亿（-7.5%） | 高景气但审美轮换快，"赛道在"≠"某个 IP 永在" |
| 中国内地基本盘 | H1'26 内地收入 64.5 亿（+26.2%，近三年最快）、同店中个位数正增长 | 需求真实存在，长坡的中国段仍在 |
| 海外长坡段 | 海外收入 +14.9%（低于指引）、同店下降低个位数、下半年净关店 50-70 家 | **唯一被本轮证伪的一段** |

1. **长坡的逻辑没有变：**性价比是跨周期的人类需求，渗透率缺口（5-10% vs 30-40%）意味着中国自有品牌模式向全球复制仍有几十年的量可挖——本轮没有任何证据推翻这个文明级判断。
2. **变的是"雪"的质地：**旧轮假设雪是"加盟轻资产滚全球"，本轮看到的是直营重资产（PP&E 72.30 → 85.44 亿、租赁负债 45.8 亿）+ 海外同店半年内由正转负——长坡还在，但滑雪板换成了更重的一副。
3. **情绪消费是长坡上的加速带，不是主路：**赛道高景气（9.1x 市值差为证）与审美轮换快（THE MONSTERS 自身 -7.5%）并存——加速带能提速，也能把没系安全带的车甩出去。

## 三、20 年置信度评估：~70% → ~55%（核心）

**置信度 = 赛道存在性 × 公司能跑到终点的概率。核心变量是海外失速的性质判定。**

| 置信度构成 | 旧轮 | 本轮 | 变动依据 |
|---|---|---|---|
| 赛道 20 年存在性 | 90% | 85% | 长坡未证伪；情绪消费审美轮换添噪 |
| 公司 20 年竞争力 | 70% | 55% | 海外利润贡献 35-40%（2023）→ 10-15%；海外单店模型需重构 |
| 财务长期可信度 | 75% | 50% | 净现金 +35.87 → 净债务 58.3 亿；剔租赁 FCF 仅 7.0 亿 |
| 治理与资本配置 | 60% | 45% | 永辉 CY2025 分摊亏损 8.13 亿、Q2 再转亏；AI 投资浮亏 -5.97 亿 |
| **综合** | **~70%** | **~55%** | — |

### 海外失速：周期性还是结构性？（置信度调整的核心）

| 证据方向 | 事实 | 含义 |
|---|---|---|
| 周期性证据 | 内地同店中个位数正增长；Q4'25 美国同店 +20%+，半年前海外模式曾跑通 | 需求与产品未消失，部分失速可逆 |
| 结构性证据 | 同店 +20% → 转负仅约半年（周期性失速通常渐变）；直营成本刚性（租赁付款 TTM 10.5 亿）；主动净关店 50-70 家 = 自认单店模型需重构；指引经营利润率再降 3-4pct | 扩张节奏与单店经济模型问题，修复需以年计 |
| **判定** | **周期与结构约四六开，结构为主** | 修复窗口 2027 年（关店出清后）；本轮置信度按结构性主导下调 |

**为什么这不是小事：**旧轮 20 年故事的第一引擎就是海外长坡，利润贡献从四成跌到一成 = 拆掉一面承重墙——置信度下调主要扣在这里，而不是扣在赛道上。

## 四、行业天花板与 IP 化第二曲线

| 对比项 | YOYO（名创） | THE MONSTERS（泡泡玛特） |
|---|---|---|
| H1'26 收入 | ~5 亿 | 44.54 亿（-7.5%）= YOYO 的 9 倍 |
| 生命周期 | 2025-06 推出，未经历完整周期 | **自证单 IP 会衰退** |
| 全球化 | 进入 53 个国家 | 审美轮换风险双向存在 |
| 资源投入 | 销售费用 30.45 亿（+39.6%）、乐园店破 100 家、LAND 店 IP 占比超 80% | — |

- **天花板判断一：**名创 IP 化的天花板不是"再造一个泡泡玛特"（市值差 9.1x、单 IP 体量差 9 倍），而是"8485 家店的流量中多大比例转化为高毛利 IP 复购"。全年 10 亿目标 7 月底提前达成 → 约占 TTM 收入 235.5 亿的 4%——**第二曲线刚过 0，离天花板很远，离证伪也很远。**
- **天花板判断二：**THE MONSTERS -7.5% 证明单 IP 天花板会向下。名创的合理路径是 **IP 矩阵**（YOYO + Nommi 2 亿+ 接力 + LAND 店 >80% IP 占比放大器 + 国内规划 1200 家乐园店），而非押注单 IP——矩阵天花板更高，验证周期也更长。
- **天花板判断三：**情绪消费赛道的长期天花板由审美轮换决定——20 年维度上，IP 化是"抬高毛利率上限的期权"，不是"替代零售的根基"。

### Q4'25 → H1'26 方向反转意味着什么

**美国同店 +20%+（Q4'25）→ 海外同店下降低个位数（H1'26），半年内方向反转。三个含义：**

1. **此前的 +20% 含铺货与新店爬坡的水分**——同店剔掉扩张红利即露真面目，说明海外增长相当部分靠开店惯性而非店效内生；
2. **直营化的学习曲线比管理层预期陡**——成本刚性留在自己表内（租赁负债 45.8 亿），同店波动直接打利润，海外利润贡献四成 → 一成即为代价；
3. **对 20 年模型的意义：**海外同店是量价拆分里"价"的那一半，"价"半年内由正转负、"量"（净关店 50-70 家）同步收缩——**海外段从"量价齐升"降级为"先修店效、再谈增长"。**

## 五、竞争格局：三个梯队与两个市场

| 梯队 | 主体 | 规模锚点 | 格局判定 |
|---|---|---|---|
| IP 创造层 | 泡泡玛特 | 市值 2053.6 亿 HKD（名创 232 亿的 **9.1x**）；THE MONSTERS 44.54 亿、星星人 26.5 亿 | 原创情绪价值 + 多 IP 矩阵，20 年壁垒最高 |
| 渠道放大层 | 名创 | 全球 8485 店（海外 >40%）、毛利率 45.0%、YOYO ~5 亿 | **性价比渠道 × IP 放大**的错位生态位，IP 是放大器不是引擎 |
| 潮玩集合层 | TOP TOY（名创系） | 334 店、H1'26 营收 13 亿+（+38%）、连续三季度盈利、淡马锡估值 100 亿 HKD | 名创系第二梯队，2026-04 二次递表，分拆后有望独立定价 |

1. **9.1x 市值差不是估值差，是生态位差：**市场在为"原创情绪价值 + 已验证多 IP 周期"付 9 倍溢价；名创若用开店对标（"他一个月干 300 万，我们要干 300 万"）去追，是在别人主场用别人规则打仗。**20 年维度的最优解是守住渠道放大层，把 IP 当毛利杠杆，而非下场做 IP 公司。**
2. **TOP TOY 是名创系内更接近"情绪消费原生梯队"的资产**：+38% 增速与连续三季度盈利比母公司海外引擎健康得多；分拆若成行，名创保留横跨两个生态位的期权。
3. **竞争格局对 20 年置信度中性偏正**：错位竞争意味着不必在原创赛道正面对决；但 IP 矩阵若始终做不大（占比停在个位数），天花板就锁死在渠道层。

## 六、20 年增长模型（保守假设下的量价拆分）

> 说明：定性框架 + 数据包锚点，非估值模型重算；所有基数均引自数据包。

| 引擎 | 量（20 年，保守） | 价（20 年，保守） | 锚点 |
|---|---|---|---|
| 门店网络 | 8485 店基数上，扩张从"铺量"转为"质选"（下半年净关店 50-70 家） | 同店长期锚 = 内地中个位数正增长，海外修复滞后 1-2 年 | 内地同店中个位数；渗透率缺口 25-35pct |
| IP 收入占比 | YOYO 全年 10 亿目标提前达成，Nommi 2 亿+ 接力 | 占比从约 4%（10 亿 / TTM 235.5 亿）起步，乐园店 IP 占比 >80% 店内放大 | YOYO ~5 亿（H1'26）、53 国、规划 1200 家乐园店 |
| 第二梯队 | TOP TOY 334 店，+38% | 分拆后权益价值显性化 | 淡马锡 100 亿 HKD |

- **基准（置信度 ~55%）**：渠道层温和复利（同店中低个位数 + 门店质选），IP 占比缓慢抬升但停在 10% 以内，海外先修店效再谈扩张——"20 年复合个位数"的世界，现价 8.1x 2026E 经调整 PE 尚可持有，但不激动；
- **乐观（置信度回升至 70%+）**：海外单店模型 2027 年跑通 + 第二个亿级 IP 出现 → 量价重新齐升；
- **悲观（置信度降至 40% 以下）**：海外出清不止（净关店超上限）+ IP 化证伪 → 20 年故事退化为"单一中国的渠道生意"。

## 七、评分：3.00 / 5（旧轮 3.50，下修 0.50）——安全边际检查前置

| 安全边际检查项 | 结果 | 判定 |
|---|---|---|
| 概率加权 DCF | 中性 IV 19.8 HKD ≈ 现价 19.87（-1%） | **安全边际 ≈ 0（边界情况）** |
| FCF Yield | 8.2% > 无风险利率（剔租赁口径仅 3.3%） | 边界通过 |
| 反向 DCF | 隐含 g1 = 7.8%，定价"温和修复"无安全垫 | 不加分 |
| 零增长锚 | FCF 口径股权 109 亿（溢价 1.98x）；剔租赁仅 8 亿 → 现价是纯增长定价 | 警示 |

**规则执行：安全边际 ≤ 0 时，赛道/位置高分不得直接进总分，总分锚 ≤ 3.25。**文明级赛道 4.0 的高分只能经置信度折算后进入总分——这是与旧轮（3.50）最大的评分纪律差异。

| 维度 | 分 | 依据 |
|---|---|---|
| 文明级赛道（20 年长坡） | 4.0 | 渗透率缺口 + 情绪消费长坡仍在；按规则不直接进总分 |
| 天花板与第二曲线 | 3.0 | YOYO ~5 亿刚过 0，路径存在但未跨周期验证；单 IP 衰退先例 |
| 竞争格局 | 3.5 | 错位生态位清晰 + TOP TOY 期权；IP 层天花板未打开 |
| 长期确定性（20 年置信度） | 2.5 | ~70% → ~55%；海外失速以结构性成分主导 |
| 价格与安全边际 | 2.5 | 中性 IV ≈ 现价；FCF Yield 8.2% 与股东收益率 6.8% 是仅有缓冲 |
| **总分** | **3.00** | **锚 ≤3.25 约束下取 3.00；下修主因 = 置信度受损而非赛道证伪** |

**与旧轮差异**：旧轮 3.50 站在"海外长坡 + 估值折价"双支柱上；本轮两支柱同时折损（利润贡献四成 → 一成、同店转负；安全边际归零）——0.50 下修是按规则给的，不是情绪化调整。

### 上修条件（满足任二，回 3.25-3.50；置信度回升至 65%+）

1. **海外失速被证实为周期性**：H2'26 净关店收窄至 50-70 家以内、2027 海外同店转正；
2. **IP 矩阵跨周期**：YOYO 之外出现第二个亿级 IP（Nommi 接力），IP 收入占比向 10% 演进；
3. **资本配置收敛**：能力圈外投资止损，净债务 58.3 亿回到净现金方向；
4. **价格重现边际**：中性 IV 较现价出现 ≥20% 折价。

### 下修条件（触发任一，降至 ≤2.50）

1. **结构性确认**：2027 海外同店继续为负，或净关店超 50-70 家上限；
2. **IP 化证伪**：YOYO 进入衰退（THE MONSTERS 式 -7.5%），且销售费用 +39.6% 换不来第二曲线；
3. **杠杆恶化**：净债务进一步上升，或剔租赁 FCF（7.0 亿）转负；
4. **永辉 Q3 再转亏且无退出安排**。
