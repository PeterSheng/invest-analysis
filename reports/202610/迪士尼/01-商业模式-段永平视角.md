# 迪士尼（DIS）四大师分析 · 01 商业模式 —— 段永平视角

> 分析基准日：2026-10-05（价格取 2026-10-02 收盘 / 10-05 盘中 **$102.36**，市值 **$176.85B**）（数据包 §1）
> 唯一数据源：`00-数据包.md`；不引入外部数据、不重算估值，引用均标注（数据包 §X）
> 框架：段永平三问——**好生意？好管理？好价格？** 先问生意本质，再看人，最后才看价格。

---

## 一、生意本质：一句话定义

**迪士尼 = 以百年独占 IP 为底层资产的「体验变现收租机器」，核心引擎是 Experiences（利润率 ~29%、占分部 OI ~57%），外面套着一层仍在反复折腾的复杂娱乐集团结构。**（数据包 §4）

段永平的标准：最好的生意是"一个产品反复卖、边际成本趋近于零"。迪士尼恰好把**同一个 IP 卖了四遍**：票房收一次、流媒体订阅收一次、商品授权收一次、公园门票+酒店+游轮再收一次。这是它与一般娱乐公司的本质区别——**内容是它的"地租"，不是它的"产品"**。

## 二、正反两面：「复利机器」还是「反复折腾」？

### 正方：IP 授权 + 体验变现的复利机器 ✓

1. **Experiences 是教科书级的好生意**：FY2025 营收 ~$34.8B、分部 OI ~$10.0B、利润率 **~29%**，一家分部贡献三大分部合计利润的 **~57%**（数据包 §4）。IP 是几十年前自创/低价买断的，今天的公园客流是在给百年前的创意收租。
2. **流媒体最烧钱的仗打完了**：DTC 从 FY22 年亏 $4B 到 FY26 年利润 $1B+（数据包 §7）；Q2 FY26 SVOD OI $582M（+88%），利润率**首次破 10%**（数据包 §3）。Disney+ 连续第 6 年提价（§7）——敢连提六年价而不掉用户，是"差异化定价权"的实证。
3. **现金流质量高**：OCF/净利五年均值 ~2.4x（数据包 §6）；有形口径 ROE ~39%（"估"，§6）——业务本体的回报率是顶级的。
4. **利润率逐季扩张**：FY26 Q1 15.4% → Q2 15.5% → Q3 19.3%（数据包 §3），这是本轮基本面最硬的变量。

### 反方：反复折腾的复杂娱乐集团 ✗

1. **含商誉 ROIC 7.11% < WACC 10%**（数据包 §6）：商誉 $74.7B 占总资产 36.5%（Pixar/Marvel/Lucasfilm/21CF 收购堆积）——**买来的 IP 库至今没有赚回买入价**。段永平：扩张若不能持续赚回资本成本，就是毁灭价值。
2. **linear TV 持续衰减**（数据包 §4），拖着 Entertainment 后腿：该分部利润率仅 11.0%，一半收入还在做"苦生意"。
3. **三个分部三种生意**：29% / 11.0% / 16.4%（数据包 §4）——集团平均数把最好生意的成色稀释了。
4. **竞争实证**：环球 Epic Universe 2025-05 开园（数据包 §7），公园的"垄断租金"第一次面对同级对手。

### 本报告判断

**七分复利机器，三分复杂集团。** 核心资产（IP 库 + Experiences）是真护城河，但集团结构确实在稀释资本回报（ROIC 7.11%，§6）。段永平会追问：为什么不把 Experiences 分拆？答案恰是闭环本身——公园的溢价一半来自内容喂养，拆开就只剩"地产+游乐设备"。**闭环是护城河的来源，也是复杂性的宿命**，此题没有两全解，只能用资本回报率长期验证。

## 五、好管理：Iger→D'Amaro 是"对的人"吗？

**加分项 ✓**
1. **Bob D'Amaro（54 岁）2026-03-18 接任，原 Experiences 董事长**（数据包 §7）——接班人出自贡献 ~57% 分部 OI 的利润引擎板块，说明公司把"运营生意本身"置于"资本市场叙事"之上，是标准的运营聚焦信号。
2. **Dana Walden 升任内容主席**（原继任竞争者留任内容线，§7）——闭环的"内容喂养"功能没有被交接削弱。
3. **Iger 留任高级顾问至 2026 年底**（§7）——过渡有缓冲，不是硬着陆。

**减分项 ✗**
1. **Iger 二进宫后交棒三次未成**（§7）：人的问题反复，说明董事会层面从未一次想透——段永平最忌讳"组织反复折腾"。
2. 交接期稳定性待验证：下一验证点 **2026-11-12 Q4 财报 + 全年**（§1）。

**判断**：方向对了（运营派上位），结果未证（三次交棒的信用透支）。管理层 3.00，不冤。

## 六、段永平最关心的问题：这生意十年后还在不在？

**在，而且大概率更好——前提是集团停止折腾。**

1. **体验消费是 AI 冲击不到的确定性**：公园/游轮卖的是"人在现场"；米老鼠近百年代际传承（父母带孩子去，孩子长大再带自己的孩子去）——这是迪士尼最像茅台的地方：情感消费 + 复购 + 提价权（连续 6 年提价，§7）。
2. **流媒体的资源消耗已过顶点**：年亏 $4B → 年利润 $1B+（§7）、SVOD 利润率首破 10%（§3），最贵的战争阶段打完；但内容军备竞赛没有终点——**IP 是资产，单部内容是费用**，内容库每年都要重新花钱养，这是这门生意永恒的"维护成本"。
3. **CapEx 高峰在尾段且投向正确**：FY26 ~$9-10B 中 Experiences 吃掉 $6B 用于新游轮/公园扩建（§4/§7）——资本流向利润率最高的板块，这是正确的再投资方向。

## 七、好价格：合理，但不是便宜

- Forward PE **13.55x**、EV/EBITDA ~10.4x、FCF Yield **4.68%**（数据包 §1）——不贵，也绝不便宜。
- DCF 概率加权内在价值 **$84** vs 现价 $102.36 = **-18%**（数据包 §8）；现价反推隐含前 10 年 FCF 年增 **8.78%**，已接近乐观情景 g1=9%（§8）——价格里几乎没有"意外之喜"的空间。
- 零增长锚 $55/股，现价是其 1.86 倍（§8）——市场为"体验+DTC 双引擎"支付了明确溢价。
- 股息 + 回购合计股东回报 ~3.4%/年、派息率 26%（§1/§6）——对一个"收租机器"来说，还给股东的手笔仍偏小。

段永平："好公司不等于好股票。" $102 买 $84 的价值，赚的是企业成长的钱，不是低估修复的钱。

## 八、最终评分：投资吸引力 **3.25 / 5**

| 项 | 结论 |
|---|---|
| **最终评分** | **3.25 / 5**（与主会话锚定 3.25 一致，0 修正） |
| 生意质量（§四加权） | 3.75 |
| 价格质量 | ~2.75（DCF -18%、隐含增速 8.78% 已打满乐观预期，§8） |
| 综合逻辑 | 好生意（3.75）× 不便宜的价格（2.75）→ **3.25**：进"看得懂"名单，等价格，不追价 |

**上修至 3.50 的条件**（若认为 Experiences 单体已接近茅台式好生意）：
- Q4/年报（2026-11-12）验证交接平稳、Entertainment OI 双位数增长兑现（§7）；
- SVOD 利润率站稳 10% 后继续爬坡，linear 衰减"有序化"而非加速；
- 股价回到概率加权 IV $84 附近（§8），价格从拖累项变贡献项。

**下修至 2.75 的条件**（若认为复杂集团结构致命）：
- 交接期动荡：D'Amaro 战略反复或管理层再震荡；
- 含商誉 ROIC 持续 < WACC 且收购冲动重燃（再造一个 TFCF）；
- linear TV 加速塌方或流媒体军备竞赛重燃（内容开支失控）。

## 九、段永平式犀利结论

1. **这不是娱乐公司，是 IP 收租机器。** Experiences 一个板块：29% 利润率、57% 利润占比（§4）。如果迪士尼只做这一块，它是茅台级的生意。
2. **可惜它不止做这一块。** ROIC 7.11% < WACC 10%（§6）——过去十几年买 IP 的钱还没赚回来。买 IP 是好事，买贵了就是另一回事。
3. **交接三次没换成，"人"的功课没做完。** D'Amaro 出自最赚钱的板块是好信号，但好信号不等于好结果，等 2026-11-12 的答卷。
4. **迪士尼缺的不是新故事，是 Stop Doing List**：把 linear 衰减资产的有序退出写进日程，比任何一部大片都值钱。
5. **价格不给机会也不算坑**：13.55x Forward PE 买一个利润率逐季扩张的生意（§1/§3），持有者继续拿，空仓者不必抢——等 $84 或等交接验证，二者有一个兑现再谈重手。
6. **一句话总评**：好生意、待证明的管理、不便宜的价格——**3.25，值得等，不值得抢。**
