## 二、生意本质：一句话

**信诺是"看病过桥费"生意**：政府和老板们的钱要变成医疗服务，得从它的保险单里过一道（承保价差）；药厂的好药要送到病人手上，得走它的药品管道（Express Scripts + Accredo），药从这过、它抽一道。**一个池子管钱，一张网送药，双轮转。**听起来很美，但过桥费的价目表，一半是自己定的，一半是华盛顿定的。

## 三、品牌与资产对比：谁的生意更"本分"？

| | **Evernorth** | **Cigna Healthcare** |
|---|---|---|
| 是什么 | PBM Express Scripts + 专科药房 Accredo + 止损险 | Medicare Advantage + 商业团险 |
| FY2025 体量 | 调整营收 **$235.0B**(+16%)、税前利润 **$7.2B**(+3%)，占集团利润 ~55% | 税前利润 ~$4.3B，占 ~45% |
| 钱从哪来 | 药走我的管道，我抽一道过路费 | 收保费，赌 MCR（赔付率） |
| 客户是谁 | 药厂、雇主、甚至保险同行 | 政府（CMS）、雇主 |
| 本分程度 | **较本分**：干的是分发服务的活，药走得快省全社会的钱 | 政府定价生意：MCR 每年 CMS 说了算，本不本分不由自己 |
| 护城河性质 | 规模 + 独占（Accredo 特种药近乎唯一分发口） | 牌照 + 精算能力，对病人无品牌溢价 |

**抽成模式 vs 分发模式，护城河差在哪？**

1. **Express Scripts 的传统抽成**（返点、价差），说白了赚的是"信息不透明的钱"。delinking 立法一通过、定价一透明，这笔钱就没了；更狠的是最大客户 UNH 自己建了 Optum——**你的生意建立在"别人愿意让你抽成"之上，这不算硬护城河，算人情债。**
2. **Accredo 的分发独占**是真壁垒：特种药要冷链、要注射指导、要患者管理，全美能干这活的就那几家，药厂绕不开。这是"没我不行"的生意，接近本分。
3. **但数字在报警**：Evernorth 营收 +16%、利润只 +3%，2026 指引利润还要收缩到 ≥$6.9B——**抽成那部分在被上下游两头挤，护城河不是塌方，是在渗水。**
4. **MCR 是另一个坑**：FY25 82.4% → 26Q1 79.8% → 26Q2 84.5%，一个季度跳 4.7pct。承保生意的利润就是价差，价差一收窄，45% 的利润盘子直接晃。

**结论：Evernorth 里最本分的是 Accredo，最不本分的是 PBM 抽成；Cigna Healthcare 是看政府脸色的生意。** 这家公司一半是"没我不行"，一半是"政策说了算"。

## 四、管理层：是不是"对的人"？

- **20+ 年内部人**：Cordani 从体系里长出来，不是空降职业经理人。医保这种靠监管关系吃饭的行当，20 年攒下的人脉和行业理解，就是真资产。
- **2025 年底业务重组**：市场叫它 "business overhaul"，一度恐慌抛售。敢动自己赚钱的存量结构，至少说明没躺在报表上混日子。
- **不分拆 PBM 的取舍**：外头多少人喊着把 Evernorth 单拆出去卖个好估值。管理层不拆——拆了账面好看，但"自家保单导流给自家药房"这个闭环就断了。**肯放弃短期估值幻觉的人，通常在算长账。**
- **扣分项**：2024 年 VillageMD 减值 $1.8B，追风口踩了坑。说明管理层不是不犯错，只是错得不算致命。

**判词：合格偏好的管理者，属于"不会把公司带沟里"的人，但还谈不上"伟大"。**

## 五、段永平式结论：看得懂吗？敢重仓吗？

**生意看得懂，政策看不懂。**
收保费、管药方，都是上百年的老生意，逻辑一页纸讲完。但政府明年给多少 MCR、国会明年会不会把 PBM 拆了——这个我看不透，也不打算假装看得透。**能力圈的边界不在"懂不懂生意"，在"看不看得见十年后的样子"。**

**三个硬事实：**
1. 五年营收 CAGR 12.1% 对利润 CAGR 5.9%——这个行业赚的钱正被通胀和监管一点点磨掉，这不是"生意越来越难做"的语气，这是已经发生的事。
2. 有形权益 **-$29.6B**（商誉 $45.5B + 无形 $26.9B，是 2018 年 $67B 买 Express Scripts 欠的账）。买 CI 买的是现金流，不是资产。
3. 价格端确实便宜：2026E 调整 PE **10.05x**、FCF Yield **11.2%**、OCF/NI **1.60x**（利润是真现金）；反向 DCF 显示市场定价隐含利润年缩 5.1%——**指引若兑现，15% 年化 IRR 是白送的。**

**但敢不敢重仓？不敢。** 理由三条：
- DCF 情景从 **$105 到 $949**，跨度近十倍——连市场都不知道政策会怎么走，这种离散型风险意味着你根本不知道底在哪，跌下去不敢加仓，就不是重仓该有的姿势；
- 护城河在渗水（客户自建 + 立法威胁），不是"十年后肯定更强大"的确定性生意；
- 重仓的前提是睡觉踏实，这生意半夜容易醒（MCR 一跳、法案一过，都是黑箱）。

**一句话：便宜的好价格，平庸偏好的好生意，能力圈边缘——适合拿现金流补偿不确定性的人，不适合买了就不管的人。**
